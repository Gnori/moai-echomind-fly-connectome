# 11. 명령 모음과 용어

> 부록. 처음부터 끝까지 다시 돌리는 순서와, 이 안내서에 나오는 말의 뜻.

## 1. 준비

```bash
uv sync --group dev --extra llm            # 본체(파이썬 3.14) — Qwen 을 쓰려면 --extra llm
cd body && uv sync && cd ..                 # 몸(파이썬 3.12 · FlyGym 1.x)
memory_pressure | tail -1                   # 무거운 실행 전 필수 — 시스템 여유 %
ollama ps                                   # Qwen 올리기 전 — 다른 큰 모델이 올라 있지 않은지
```

## 2. 처음부터 끝까지

| # | 명령 | 장 | 시간 | 가드 |
|---|---|---|---|---|
| 1 | `uv run fly-connectome download` | 01 | 받기(1.1 GB) | — |
| 2 | `uv run fly-connectome graph --rewired-seed 0` | 01 | 약 22 s · 3.5 GB | — |
| 3 | `uv run pytest -m "not heavy"` | 02 | 수 초 | — |
| 4 | `uv run fly-connectome bench fit` | 03 | 후보 8 × 20 시행 · 시간 기록 없음(규칙을 바꿨을 때만) | 여유 40 % |
| 5 | `uv run fly-connectome bench escape --trials 40` | 03 | 약 3.5 분 | 여유 40 % |
| 6 | `uv run fly-connectome bench limits` | 03 | 시간 기록 없음 | 여유 40 % |
| 7 | `uv run fly-connectome collect --name main --seeds 0-59 --workers 3 --threads 4` | 06 | 약 25 분 | 여유 40 % |
| 8 | `uv run fly-connectome collect --name eval --seeds 1000-1011 --workers 3 --threads 4` | 06 | 약 5 분(추정 — 에피소드 12) | 여유 40 % |
| 9 | `uv run fly-connectome dataset pack --name <새 이름> --train main --eval eval` | 06 | 수 초 | — |
| 10 | `uv run fly-connectome train-probe --steps 12` | 08 | 12 걸음 약 3~5 분(걸음당 13~23 s) | **여유 80 %** |
| 11 | `bin/run_full.sh` | 08 · 09 | 학습 둘 약 6~7 시간 + 평가 넷 약 25 분 + 성적표 약 1.5 시간 | 학습 80 % · 평가 65 % |
| 12 | `uv run fly-connectome linear-probe --dataset <이름>` | 09 | 약 30 s(CPU · 채널별 포함) | — |
| 13 | `uv run fly-connectome backup` | 10 | 약 1 분(USB 포함 · 801 MB) | — |

`bin/run_full.sh` 가 하는 것(하나씩 돌릴 때):

```bash
uv run fly-connectome train --brain real
uv run fly-connectome train --brain rewired
uv run fly-connectome eval-caption --brain real    --checkpoint stage1-caption
uv run fly-connectome eval-caption --brain rewired --checkpoint stage1-caption
uv run fly-connectome eval-caption --brain real    --checkpoint final
uv run fly-connectome eval-caption --brain rewired --checkpoint final
uv run fly-connectome scorecard --seeds 2000-2009
```

지금 있는 결과(train-v2)를 다시 평가하려면 `eval-caption` · `scorecard` 에 **`--version train-v2`** 를 붙인다 — 기본은 지금 규칙 판(train-v3)이다.
학습은 끝난 폴더를 덮어쓰지 않는다(`final.safetensors` 가 있으면 시작하지 않음).

⚠️ **무거운 실행은 요구자께 먼저 말씀드린 뒤.** 한 번에 하나(`runs/.heavy.lock`). 띄웠으면 수십 분 간격으로 확인한다.
11 번의 학습 시간은 걸음당 약 7 s 기준 추정(한 뇌 1,917 걸음 ≈ 3.7 시간)이다 — 실측은 섞은 배선 전체 3.3 시간.

## 3. 판 번호 — 무엇을 바꾸면 무엇을 다시 하나

| 바꾼 것 | 판 | 다시 할 것 |
|---|---|---|
| LIF 값 · `w_scale` | `config/sim.yaml` `version` | 03 검산 → 06 자료(새 이름) → 08 학습 → 09 평가 |
| 다가옴 자극 | `config/loom.yaml` | 같음 |
| 과제 · 인코더 · 디코더 | `config/task.yaml` | 06 → 08 → 09 |
| 채널 표 | `config/channels.yaml` | 06(차원이 바뀐다 · 새 이름) → 08 → 09 |
| 학습 규칙 | `train_cli.TRAIN_RULE["version"]` | 08 → 09(결과 폴더 이름이 바뀐다) |
| Qwen 가중치 | `config/llm.yaml` | 08 → 09 |

## 5. 용어

| 말 | 뜻 |
|---|---|
| 커넥톰 · 연결 지도 | 뉴런 사이 연결 지도. 누가 누구에게 시냅스 몇 개로 이어졌나 |
| MaleCNS v1.0 | 수컷 초파리 중추신경계 연결 지도(Janelia FlyEM · 2026-09-03 · CC BY 4.0) |
| Traced | 끝까지 추적된 뉴런(165,122) — 이 프로젝트의 뉴런 집합 |
| 부호 | 연결이 흥분(+1)인지 억제(−1)인지 — 신경전달물질에서 |
| LIF | 뉴런을 "전압이 쌓이다 문턱을 넘으면 한 번 발화"로 줄인 방정식 |
| 발화 · 막전위 · 탈분극 | 뉴런이 신호를 내는 순간 · 뉴런 안 전압 · 쉬는 전위보다 올라간 정도 |
| 불응기 | 발화 직후 잠깐 다시 발화하지 못하는 시간(2.2 ms) |
| 포아송 자극 | 평균 발화율만 정하고 사건 시각은 무작위로 넣는 자극 |
| `w_scale` | 시냅스 세기 배율 — 이 저장소가 정한 유일한 뇌 값(0.25) |
| 섞은 배선(rewired) | 연결 수는 그대로 두고 도착 뉴런만 무작위로 섞은 뇌 — "배선 덕인가"를 가르는 대조군 |
| 거대섬유(GF · DNp01) | 도망 반사를 일으키는 하강 뉴런 |
| LC · LPLC | 시각 투사 뉴런 — 이 프로젝트의 시각 입구 |
| 하강 뉴런 · 상행 뉴런 | 뇌 → 신경삭(명령) · 신경삭 → 뇌(몸 상태) |
| 채널 | LLM 에 넣는 신경 신호 묶음 9개 |
| 단위 | 채널 안에서 뉴런을 묶는 칸(종류 × 좌우 등) — 벡터의 한 자리 |
| 임베딩 | LLM 이 토큰을 받아들이는 숫자 벡터(Qwen 은 5,120 개) |
| 소프트 토큰 | 글자가 아닌데 임베딩 자리에 들어가는 벡터 — 투영기 출력 |
| 투영기 | 초파리 신호를 Qwen 임베딩 공간으로 옮기는 작은 신경망 — **학습되는 유일한 부품** |
| 얼림 | 학습 중에도 그 부품의 가중치를 바꾸지 않는 것 |
| 파인튜닝 | 이미 학습된 모델의 가중치 자체를 더 학습시키는 것 — **이 프로젝트는 하지 않는다** |
| 가중치 지문 | Qwen 전체 가중치에서 계산한 해시 — 학습 전후가 같으면 Qwen 이 안 바뀐 것 |
| 교사 규칙 | 세계 참값을 아는 코드가 정답 행동을 정하는 규칙 |
| 캡션 | 상황을 적은 고정 서식 한 줄 |
| 손실 · 교차 엔트로피 | 정답 글에서 얼마나 먼가 — 낮을수록 가깝다 |
| 기울기 · 역전파 | 틀린 만큼을 거꾸로 보내 어느 쪽으로 고칠지 계산하는 것 |
| 층별 역전파 | 한 층씩 거꾸로 계산하고 그 층 것을 내려놓는 방식 — 메모리를 102 → 32 GB 로 |
| 바퀴(에포크) · 걸음 | 자료 전체를 한 번 도는 것 · 예시 하나로 한 번 고치는 것 |
| 옵티마이저(AdamW) | 기울기로 가중치를 얼마나 고칠지 정하는 부품 — 자기 기억(상태)이 있다 |
| 최빈값 기준선 · 찍기 | 가장 흔한 답만 계속 말했을 때의 정확도 |
| 선형 검사 | Qwen 없이 신호 벡터만으로 직선 분류기가 맞히나 — 신호에 정보가 있는지 |
| 판 번호 | 설정 · 규칙을 잠그는 이름(`sim-v1` · `train-v2` …) — 바꾸면 올린다 |
| 가드 · 잠금 | 무거운 실행을 메모리 여유와 한 번에 하나로 막는 장치 |
