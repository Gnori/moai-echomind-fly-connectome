v1 자료 · v2 판을 다시 돌릴 때(지금 있는 결과): `--dataset fly-loop-v1 --brain rewired` · 평가 · 성적표에 **`--version train-v2`** — 기본은 지금 규칙 판(train-v4)이다.
`bin/run_full.sh` 는 아직 v2 순서(학습 둘 → 캡션 평가 넷 → 성적표 5 구성)다.
학습은 끝난 폴더를 덮어쓰지 않는다(`final.safetensors` 가 있으면 시작하지 않음).

⚠️ **무거운 실행은 요구자께 먼저 말씀드린 뒤.** 한 번에 하나(`runs/.heavy.lock`). 새 종류는 작은 측정(`collect-probe` · `train-probe`)부터. 띄웠으면 수십 분 간격으로 확인한다.

## 3. 판 번호 — 무엇을 바꾸면 무엇을 다시 하나

| 바꾼 것 | 판(지금) | 다시 할 것 |
|---|---|---|
| LIF 값 · `w_scale` · 같은 쪽 방출 | `config/sim.yaml` **sim-v2** | 03 검산 → 06 자료(새 이름) → 08 학습 → 09 평가 |
| 다가옴 자극 | `config/loom.yaml` loom-v1 | 같음 |
| 과제 · 인코더 · 디코더 | `config/task.yaml` **task-v2** | 06 → 08 → 09 |
| 시야 자리 규칙 | `config/retino.yaml` **retino-v1** | `retinotopy build` → 06 → 08 → 09 |
| 채널 표 | `config/channels.yaml` **channels-v2** | 06(차원이 바뀐다 · 새 이름) → 08 → 09 |
| 판정 규칙 | `stats.STATS_RULE` **stats-v2** | 09 판정 다시(자료는 그대로) |
| 압축 · 관문 규칙 | `config/compress.yaml` **compress-v1** | 09 관문 → 08 학습 |
| 학습 규칙 | `train_cli.TRAIN_RULE` **train-v4** | 08 → 09(결과 폴더 이름이 바뀐다) |
| 성적표 판정 | `scorecard.judge` **scorecard-v2** | 09 문구 |
| Qwen 가중치 | `config/llm.yaml` llm-v1 | 08 → 09 |

**옛 판은 `config/archive/<판>.yaml`** 에 남긴다(sim-v1 · task-v1 · channels-v1) — `config.load(name, version="sim-v1")` 로 옛 자료를 다시 돌릴 수 있다.

## 5. 용어

| 말 | 뜻 |
|---|---|
| 커넥톰 · 연결 지도 | 뉴런 사이 연결 지도. 누가 누구에게 시냅스 몇 개로 이어졌나 |
| MaleCNS v1.0 | 수컷 초파리 중추신경계 연결 지도(Janelia FlyEM · 2026-09-03 · CC BY 4.0) |
| Traced | 끝까지 추적된 뉴런(165,122) — 이 프로젝트의 뉴런 집합 |
| 부호 | 연결이 흥분(+1)인지 억제(−1)인지 — 신경전달물질에서 |
| LIF | 뉴런을 "전압이 쌓이다 문턱을 넘으면 한 번 발화"로 줄인 방정식 |
| 발화 · 막전위 · 탈분극 | 뉴런이 신호를 내는 순간 · 뉴런 안 전압 · 쉬는 전위보다 올라간 정도 |
| 불응기 | 발화 직후 잠깐 다시 발화하지 못하는 시간(2.2 ms) |
| 포아송 자극 | 평균 발화율만 정하고 사건 시각은 무작위로 넣는 자극 |
| `w_scale` | 시냅스 세기 배율 — 이 저장소가 결과를 보고 맞춘 유일한 뇌 값(0.25) |
| 같은 쪽 방출(ipsi_release) | sim-v2 — 후각 수용 뉴런의 같은 쪽 연결만 세기 × 1.4(Gaudry 2013 · 문헌 값). 연결 수는 그대로 |
| 섞은 배선 · 재배선(rewired) | 연결 수는 그대로 두고 도착 뉴런만 무작위로 섞은 뇌 — "배선 덕인가"를 가르는 대조군 · `rewired-s<K>` 는 씨앗 K |
| 재배선 앙상블 | 씨앗이 다른 재배선 여럿 — 하나와 비교하면 우연히 약한/강한 것을 골랐을 수 있어 분포와 비교한다 |
| 거대섬유(GF · DNp01) | 도망 반사를 일으키는 하강 뉴런 |
| LC · LPLC | 시각 투사 뉴런 — 이 프로젝트의 시각 입구 |
| 시야 자리 · 망막 지도(retinotopy) | 시야의 어느 자리(고도 · 방위)를 어느 뉴런이 맡나 — retino-v1 은 연결 지도로 LC 마다 **고도**를 계산한다 |
| 기둥 좌표(`assignedOlHex1/2`) | 공식 주석의 시각엽 기둥 자리(육각 좌표) — 기둥 뉴런 23,720 개에만 있다 |
| 중심복합체 · 나침반 봉우리 | 몸 방향 · 이동을 표상하는 회로(EPG · PEN · Δ7 · PFN · hΔB · FC2 · PFL3) · EPG 활동 봉우리 하나가 몸 방향을 따라간다 |
| 공간 채널(space) | channels-v2 의 열째 채널 — 중심복합체와 수평/수직계(HS · VS) · 단위는 instance(구획을 지킨다) |
| 하강 뉴런 · 상행 뉴런 | 뇌 → 신경삭(명령) · 신경삭 → 뇌(몸 상태) |
| 채널 | LLM 에 넣는 신경 신호 묶음 — v1 9 개 · v2 10 개 |
| 단위 | 채널 안에서 뉴런을 묶는 칸(종류 × 좌우 등) — 벡터의 한 자리 |
| 임베딩 | LLM 이 토큰을 받아들이는 숫자 벡터(Qwen 은 5,120 개) |
| 소프트 토큰 | 글자가 아닌데 임베딩 자리에 들어가는 벡터 — 투영기 출력 |
| 투영기 | 초파리 신호를 Qwen 임베딩 공간으로 옮기는 작은 신경망 — **학습되는 유일한 부품**(v2 2층 MLP 3,187만 · v4 선형 수십만) |
| 압축기(PCA) · 관문 | 채널마다 주성분으로 k(16~64) 차원으로 줄이는 것(학습이 아니라 맞춤) · 줄인 벡터로 판정을 통과한 채널만 투영기에 넣는 문 |
| 얼림 | 학습 중에도 그 부품의 가중치를 바꾸지 않는 것 |
| 파인튜닝 | 이미 학습된 모델의 가중치 자체를 더 학습시키는 것 — **이 프로젝트는 하지 않는다** |
| 가중치 지문 | Qwen 전체 가중치에서 계산한 해시 — 학습 전후가 같으면 Qwen 이 안 바뀐 것 |
| 교사 규칙 | 세계 참값을 아는 코드가 정답 행동을 정하는 규칙 |
| 캡션 · 칸 · 틀 | 상황을 적은 고정 서식 한 줄 · 그 안에서 상황마다 달라지는 값 · 늘 같은 글자 |
| 손실 · 교차 엔트로피 | 정답 글에서 얼마나 먼가 — 낮을수록 가깝다 |
| 칸 값 토큰 가중 | train-v4 — 칸 값 토큰의 손실 1 · 틀 토큰 0.1 |
| 기울기 · 역전파 | 틀린 만큼을 거꾸로 보내 어느 쪽으로 고칠지 계산하는 것 |
| 층별 역전파 | 한 층씩 거꾸로 계산하고 그 층 것을 내려놓는 방식 — 메모리를 102 → 32 GB 로 |
| 바퀴(에포크) · 걸음 | 자료 전체를 한 번 도는 것 · 예시 하나로 한 번 고치는 것 |
| 옵티마이저(AdamW) | 기울기로 가중치를 얼마나 고칠지 정하는 부품 — 자기 기억(상태)이 있다 |
| 최빈값 기준선 · 찍기 | 가장 흔한 답만 계속 말했을 때의 정확도 |
| 선형 검사 | Qwen 없이 신호 벡터만으로 직선 분류기가 맞히나 — 신호에 정보가 있는지 |
| 에피소드(씨앗) · 결정 | 과제 하나(먹이 찾기 최대 20 결정) · 그 안의 300 ms 창 하나. 판정의 단위는 **에피소드** |
| 부호 뒤집기 순열(블록 순열) | 에피소드마다 (진짜 − 재배선) 차이의 부호를 뒤집어 "차이 없음"의 분포를 만들고, 관측이 얼마나 드문지 재는 것 |
| Holm 보정 | 여러 칸을 한꺼번에 볼 때 우연한 "앞섬"을 걸러내는 p 값 보정 |
| 부트스트랩 구간 | 에피소드를 다시 뽑아 잰 정확도의 95 % 범위 |
| 통과(pass) | stats 판정 — 앙상블 순위 ≥ 95 % · Holm p < 0.05 · 찍기보다 높음 |
| 판 번호 | 설정 · 규칙을 잠그는 이름(`sim-v2` · `train-v4` …) — 바꾸면 올리고 옛 판은 `config/archive/` |
| 가드 · 잠금 | 무거운 실행을 메모리 여유와 한 번에 하나로 막는 장치 |
