위 1~29 를 한 줄씩 돌리는 대신 **`scripts/`** 를 쓰면 잠금 · 메모리 대기 · 끝 코드 확인(실패면 멈춤)을 스크립트가 한다(`scripts/common.sh`). 순서와 확인값은 [12장 §2](12-재현-절차와-다음-작업.md).

**`--dataset` 기본값 = `config/datasets.yaml` 의 `current`**(지금 `fly-loop-v4` · 2026-09-29 `bf48c2d` 에서 통일 — 그전에는 명령마다 fly-loop-v1 · v2 를 박아 두었다 · [12장 §3](12-재현-절차와-다음-작업.md)). 옛 자료 · 옛 결과는 `--dataset` 을 직접 준다.

v1 자료 · v2 판을 다시 돌릴 때(지금 있는 결과): `--dataset fly-loop-v1 --brain rewired` · 평가 · 성적표에 **`--version train-v2`** — 기본은 지금 규칙 판(train-v4)이다.
**`bin/run_full_v4.sh`** 가 15~19 를 한 번에 돈다(압축 · 관문 → 학습 4 → 캡션 평가 8 → 성적표 7 구성 × 40 씨앗 · 관문 통과 채널이 없으면 끝 코드 4 · `--skip-train` 은 평가 · 성적표만 · 단계마다 메모리 여유 문턱을 기다림). `bin/run_full.sh` 는 v2 순서(학습 둘 → 캡션 평가 넷 → 성적표 5 구성) 그대로다.
학습은 끝난 폴더를 덮어쓰지 않는다(`final.safetensors` 가 있으면 시작하지 않음).

⚠️ **무거운 실행은 요구자께 먼저 말씀드린 뒤.** 한 번에 하나(`runs/.heavy.lock`). 새 종류는 작은 측정(`collect-probe` · `train-probe`)부터. 띄웠으면 수십 분 간격으로 확인한다.

| NPC(R-5138 · 10-12 보류) | `config/npc.yaml` **npc-v4**(v3 + S0b 물체 인식 · v3 비켜서기 4.5 m/s · v2 상자 월드 9412 · 원점 (−76, 260)) | `npc-run` 다시(진짜 · 섞은 배선 · 뇌 없음 같은 씨앗) |
| Qwen 가중치 | `config/llm.yaml` llm-v1 | 08 → 09 |

**옛 판은 `config/archive/<판>.yaml`** 에 남긴다(sim-v1 · task-v1 · task-v2 · task-v2.1 · channels-v1 · channels-v2 · retino-v1 · compress-v1 · compress-v2 · npc-v1 · npc-v2 · npc-v3) — `config.load(name, version="sim-v1")` 로 옛 자료를 다시 돌릴 수 있다.

| 임베딩 | LLM 이 토큰을 받아들이는 숫자 벡터(Qwen 은 5,120 개) |
| 소프트 토큰 | 글자가 아닌데 임베딩 자리에 들어가는 벡터 — 투영기 출력 |
| 투영기 | 초파리 신호를 Qwen 임베딩 공간으로 옮기는 작은 신경망 — **학습되는 유일한 부품**(v2 2층 MLP 3,187만 · v4 선형 수십만) |
| 압축기(PCA) · 관문 | 채널마다 주성분으로 k(16~64) 차원으로 줄이는 것(학습이 아니라 맞춤) · 줄인 벡터로 판정을 통과한 채널만 투영기에 넣는 문 |
| 얼림 | 학습 중에도 그 부품의 가중치를 바꾸지 않는 것 |
| 파인튜닝 | 이미 학습된 모델의 가중치 자체를 더 학습시키는 것 — **이 프로젝트는 하지 않는다** |
| 가중치 지문 | Qwen 전체 가중치에서 계산한 해시 — 학습 전후가 같으면 Qwen 이 안 바뀐 것 |
| 교사 규칙 | 세계 참값을 아는 코드가 정답 행동을 정하는 규칙 |
| 캡션 · 칸 · 틀 | 상황을 적은 고정 서식 한 줄 · 그 안에서 상황마다 달라지는 값 · 늘 같은 글자 |
| 손실 · 교차 엔트로피 | 정답 글에서 얼마나 먼가 — 낮을수록 가깝다 |
| 칸 값 토큰 가중 | train-v4 부터 — 칸 값 토큰의 손실 1 · 틀 토큰 0.1 |
| 입력 크기 맞춤(unit_scale) | compress-v3 — 압축 뒤 채널마다 학습 나눔의 평균 크기로 나눠 모든 뇌 · 채널을 크기 1 로. 축 사이 비율은 그대로 |
| 채점 평가(eval-v2) | 정답을 넣고 칸마다 후보의 첫 토큰 가능도를 비교하는 빈칸 채우기 — 서식을 배웠는지와 무관하게 값을 읽었는지만 잰다 |
| 기울기 · 역전파 | 틀린 만큼을 거꾸로 보내 어느 쪽으로 고칠지 계산하는 것 |
| 층별 역전파 | 한 층씩 거꾸로 계산하고 그 층 것을 내려놓는 방식 — 메모리를 102 → 32 GB 로 |
| 바퀴(에포크) · 걸음 | 자료 전체를 한 번 도는 것 · 예시 하나로 한 번 고치는 것 |
| 옵티마이저(AdamW) | 기울기로 가중치를 얼마나 고칠지 정하는 부품 — 자기 기억(상태)이 있다 |
| 최빈값 기준선 · 찍기 | 가장 흔한 답만 계속 말했을 때의 정확도 |
| 선형 검사 | Qwen 없이 신호 벡터만으로 직선 분류기가 맞히나 — 신호에 정보가 있는지 |
| 에피소드(씨앗) · 결정 | 과제 하나(먹이 찾기 최대 20 결정) · 그 안의 300 ms 창 하나. 판정의 단위는 **에피소드** |
| 부호 뒤집기 순열(블록 순열) | 에피소드마다 (진짜 − 재배선) 차이의 부호를 뒤집어 "차이 없음"의 분포를 만들고, 관측이 얼마나 드문지 재는 것 |
| Holm 보정 | 여러 칸을 한꺼번에 볼 때 우연한 "앞섬"을 걸러내는 p 값 보정 |
| 부트스트랩 구간 | 에피소드를 다시 뽑아 잰 정확도의 95 % 범위 |
| 통과(pass) | stats 판정 — 앙상블 순위 ≥ 95 % · Holm p < 0.05 · 찍기보다 높음 |
| 판 번호 | 설정 · 규칙을 잠그는 이름(`sim-v2` · `train-v5` …) — 바꾸면 올리고 옛 판은 `config/archive/` |
| 가드 · 잠금 | 무거운 실행을 메모리 여유와 한 번에 하나로 막는 장치 |
