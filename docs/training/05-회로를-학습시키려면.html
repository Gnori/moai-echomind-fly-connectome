05. 회로를 학습시키려면 (후보)

1부 초파리 뇌 · 마지막 장. ⚠️ 이 장은 구현된 것이 아니라 후보를 정리한 것이다. 요구사항(R)이 없고, 착수하려면 요구자 승인이 먼저다. 배경: 연구 노트 04 §학습 · 06 §2.6 · 07 지능은 누구 것인가.

1. 지금 회로가 배우지 않는 까닭

까닭 설명
데이터에 학습 규칙이 없다 연결 지도는 "지금 누가 누구와 이어졌나"다. 도파민 뉴런이 발화하면 어떤 시냅스가 얼마나 바뀌는지는 들어 있지 않다
조절 물질은 부호 0 이다 도파민 · 옥토파민 · 세로토닌 뉴런의 연결은 01장에서 0 으로 껐다 — 빠른 흥분/억제가 아니기 때문
이 프로젝트의 구도 초파리 회로 = 인코더(앞) · LLM = 생성기(뒤). 인코더는 고정하고 가운데 다리(투영기)만 가르치는 설계다(요구자 결정)

그래서 지금 구성에서 판단을 배우는 것은 투영기와 Qwen 쪽이고, 초파리 회로는 "감각을 처리해 신호를 만드는" 고정 인코더다. 연구 노트 07 의 판정도 같다 — "초파리의 지능을 보고 싶다면 LLM 을 빼고, 빠져 있는 학습 규칙을 채우는 쪽".

2. 회로를 배우게 하는 길 — 세 가지

길 무엇을 바꾸나 초파리 배선의 뜻이 남나 필요한 대조군 무게
가. 매개변수 더 맞추기 w_scale 처럼 전역 값 몇 개(적응 · 종류별 게인 · 전기 시냅스) 남는다 — 배선은 그대로 섞은 배선 · 규칙을 결과 전에 적기 가볍다(03장과 같은 방식)
나. 버섯체 가소성 케니언 세포 → 버섯체 출력(KC→MBON) 시냅스만, 도파민 뉴런 발화에 따라 남는다 — 바뀌는 곳이 생물학적으로 "배우는 자리" 한 곳 무작위 보상 · 규칙 없음 · 섞은 배선 중간
다. 기울기로 회로 가중치 학습 2,556만 연결 세기 전부(또는 일부)를 대리 기울기로 흐려진다 — 배운 뒤에는 "초파리 배선"이 아니다 섞은 배선에서 같은 학습 · 학습 전 배선과 비교 무겁다

가. 매개변수 더 맞추기 (학습이라기보다 보정)

03장의 방식을 넓히는 것이다. 후보:

  • 전기 시냅스(F-006) — 청각 → 거대섬유(JO→GF 27 연결)를 전기 결합으로 바꿔 "문턱 아래"를 재현. FLYCNS 는 합 3 mV 로 맞췄다.
  • 발화 적응 — config/sim.yaml 의 adaptation 자리. 출처 있는 종류에만 켠다.
  • 기준 행동을 도망 반사 하나에서 둘 이상으로 늘린다(예: 냄새 쪽 돌기).

절차는 같다: 규칙을 먼저 적고(FIT_RULE 처럼 판 번호) → 후보를 돌리고 → 규칙대로 고르고 → 섞은 배선 대조로 확인 → 판을 잠근다. 판이 바뀌면 06장 학습 자료도 새로 모아야 한다.

나. 버섯체 가소성 — "초파리가 배운다"에 가장 가까운 길

부품 무엇
배우는 자리 KC(케니언 세포 4,064) → MBON(버섯체 출력 97) 시냅스
가르치는 신호 도파민 뉴런(PAM · PPL1 약 340)의 짧은 발화(100~300 ms) — "좋았다 / 나빴다"
규칙 예: KC 와 도파민이 같이 발화하면 그 KC→MBON 시냅스를 약하게(초파리 혐오 학습의 알려진 방향). 규칙은 데이터에 없어 문헌에서 가져와 가정으로 명시한다
보상은 누가 과제 결과(먹이 도착 · 부딪힘)를 코드가 판정 — 또는 연구 노트 07 의 방향 3: LLM 을 보상 판정자로(LLM 이 행동을 대신 정하지 않고 "잘했다 / 위험했다"만 판정)
읽는 곳 04장의 value 채널(MBON)이 이미 있다 — 지금은 "고정 편향"만 담는다

⚠️ 알려진 실패 사례가 있다 — DOOMFLY 가 KC→MBON11 연결 4,184 개에 가소성 규칙을 얹었지만 학습 입증에는 실패했다(연구 노트 03). 그래서 "무작위 보상" · "규칙 없음" 대조군을 반드시 같이 돌린다. 이 둘보다 나아야 "배웠다"고 쓴다.

해 본 결과(2026-10-06 → 10-07 · 03장 6.4): 회로 학습으로 MBON 을 살린 뒤(진짜 30/97 대 재배선 0/97) 규칙을 얹으니 짝짓기 · 구획 특이적 약화는 나왔다(보상 구획 −64 % · 처벌 DAN 이면 처벌 구획만 −65 % · 어긋난 보상 · 표 섞기 · 끔은 ≤ 25 %). 그러나 짝 안 지은 냄새도 같이 약해져(−37 % 대 −40 %) 냄새 특이성은 접었다 — 촉각엽에서 활동이 번져 냄새끼리 PN 이 0.83 겹친다. 재배선은 MBON 이 침묵해 대조가 되지 못했다. 쓸 수 있는 말은 "도파민 짝짓기는 구획 특이적으로 MBON 반응을 약하게 한다"까지 · "냄새-보상 연합을 배운다"는 쓰지 않는다.

다시 연 결과(2026-10-12 → 10-13 · 03장 6.5): 촉각엽 흥분성 LN → PN 을 ×0.5 로 줄여(모형 수정 · 강한 uPN 57 → 21 %) KC 를 다시 맞추고(kc-mbon-al · 손실 0.535) η 를 이 뇌에서 다시 보정하니(0.002 · CS+ 만 · 다른 씨앗) 진짜 배선에서 결과 전 잠근 대조 여섯이 모두 통과했다 — 짝지은 냄새 −71 % · 안 지은 냄새 −19 % · 처벌 DAN 이면 처벌 구획 −85 % · 어긋난 보상 −1 % · 표 섞기 −19 % · 끔 −1 %. 섞은 배선은 MBON 이 침묵해 비교할 수 없었다. 쓸 수 있는 말은 "촉각엽을 고치고 KC 를 다시 맞춘 진짜 배선 위에서, 선언한 짝짓기 규칙이 냄새 · 구획 특이적 약화를 낸다(섞은 배선은 비교 불가)"까지 · "초파리 뇌가 배운다" · "섞은 배선보다 낫다"는 쓰지 않는다. 단서: η 는 이 뇌에서 보정 · CS− 와 표 섞기가 기준 25 % 에 가까움 · 구획 특이성 상당 부분은 규칙 설계 · 촉각엽 ×0.5 는 모형 수정 · 행동으로는 아직 안 이음.

섞은 배선과 비교(10-13 · 부분 섞기 pr-a): 한 갈래만 섞고 나머지는 진짜로 둔 뇌에 같은 매개변수를 얹어 짝짓기 특이성 SI(CS+ 감소 − CS− 감소 · 씨앗 10)를 쟀다 — 진짜 0.513 대 PN → KC 섞기 0.35 · 0.41 · 0.49(p 0.002 · 통과 · 섞으면 처벌 구획도 −23~−28 %) · KC → MBON 섞기 0.46 · 0.48 · 0.47(p 0.010 · 통과 · 차 작음 · 결과 전 예상 "같음"과 다름). 쓸 수 있는 말은 "진짜 PN → KC 배선이 (그 갈래만) 섞은 배선보다 냄새 특이적 연합 약화를 낸다(같은 매개변수)"까지 · "초파리 뇌가 배운다"는 쓰지 않는다. 단서: 같은 매개변수 대조(같은 절차 아님) · p 는 같은 뇌 안 씨앗 · 섞은 인스턴스 셋 · 행동 연결 없음 — 03장 6.5.

가치로 읽기(10-14 · A1 · 몸 없이): 위 표 "읽는 곳"(MBON)을 가치 숫자 하나로 읽어 봤다(닫힌 고리의 value 채널과는 따로 · 뇌만) — MBON01~19 발화에 신경전달물질로 정한 부호(글루탐산 −1 · 아세틸콜린 · GABA +1)를 곱해 더한 가치 V 가 짝짓기 뒤 짝지은 냄새 쪽으로 옮기나(결과 전 잠금 · 씨앗 10). 보상 짝짓기 +114(10/10) · 처벌 DAN −124(뒤집힘) · 어긋난 보상 · 표 섞기 · 끔 −12 · −21 · −1 · 무작위 부호 20 벌 모두 진짜보다 작음 → 주 기준 넷 통과. 쓸 수 있는 말은 "회로가 만든 가치를 손으로 정한 읽기가 (몸 없이) 짝지은 냄새 쪽으로 옮긴다"까지 · "버섯체 출력이 행동을 정했다"는 쓰지 않는다(몸 행동 A2 는 10-14 하지 않기로 함 · 성공 가능성 낮음). 단서: PN → KC 섞기(67~84)보다는 크지만 KC → MBON 섞기(122~162)보다는 작다 — 섞은 뇌의 MBON 반응이 1.4 배 커서 생기는 날 값 차이로, 크기로 나누면 구별되지 않고 읽는 법마다 순서가 뒤집힌다(결과 뒤 탐색) · 부호는 손으로 정함. 섞은 뇌마다 다시 맞추는 "같은 절차" 판은 작은 시험(pnkc-s0 5 세대 손실 4.92 · 기준 ≤ 3)을 못 넘어 본 학습을 하지 않았다 — 03장 6.5.

다. 기울기로 회로 가중치 학습

LIF 의 발화는 계단 함수라 그대로는 미분되지 않는다 — 대리 기울기(surrogate gradient)로 역전파한다. 가능하지만 이 프로젝트의 원칙과 부딪힌다:

  • 학습이 끝난 회로는 더 이상 MaleCNS 배선이 아니다 → "초파리 뇌"라는 말의 근거가 약해진다.
  • 섞은 배선도 같은 학습을 하면 비슷해질 수 있다 → 대조군이 더 까다롭다.
  • 2,556만 연결 × 시간 걸음(300 ms = 3,000 걸음)의 역전파는 메모리가 크다 → 작게 먼저 재고, 무엇에 비례하는지 본다(CLAUDE.md 무거운 실행 규약).

3. 권하는 순서

  1. 2부의 전달 문제를 먼저 푼다 — 지금 막힌 곳은 회로가 아니라 전달이다(10장). 회로를 바꾸면 무엇이 좋아졌는지 가르기 어려워진다. (R-7469 G1 확정 순서도 같다: 판정 기준 → 냄새 좌우 → 3차원 입력 → 자료 v2 → 압축 관문 → 작은 투영기 → 판정 → 그다음 F-006 · F-007. 1부에서 먼저 한 것은 감각 쪽 결함 측정(04장 3.2 · sim-v2)과 3차원 재료(04장 3.1 · 5.4)뿐이다.)
  2. 그다음 가(전기 시냅스) — 가볍고, 알려진 불일치(청각)를 고친다.
  3. 초파리 쪽 지능을 보려는 목적이면 나(버섯체 가소성) 를 별도 요구사항으로. 대조군 둘(무작위 보상 · 규칙 없음)을 설계에 먼저 넣는다.
