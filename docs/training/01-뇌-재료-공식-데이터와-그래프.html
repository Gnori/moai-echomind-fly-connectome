01. 뇌 재료 — 공식 데이터와 그래프

1부 초파리 뇌 · 첫 장. 코드: src/moai_echomind_fly/data.py · graph.py · 설정 config/sources.yaml. 증거: W core 3.1 · 3.2 · 배경: 연구 노트 01 · 08.

1. 이 장에서 하는 일

초파리 뇌 시뮬레이션의 재료는 연결 지도(커넥톰) 하나뿐이다. 누가 누구에게 시냅스 몇 개로 이어졌는지, 각 뉴런이 어떤 신경전달물질을 쓰는지가 전부다. 학습된 가중치 같은 것은 없다 — 시냅스 개수가 곧 연결 세기의 근사다.

순서 무엇 명령 결과물
1 공식 파일 3개를 받아 공식 MD5 로 검증 uv run fly-connectome download data/raw/*.feather · data/raw/SHA256SUMS
2 뉴런 · 부호 · 연결 표로 컴파일 uv run fly-connectome graph --rewired-seed 0(재배선 여럿은 --rewired-seeds 0-4) data/graph/traced-v1.* · traced-v1.rewired-s<K>.*
3 (2026-09-23) 시각 투사 뉴런마다 시야 고도를 연결 지도로 계산 uv run fly-connectome retinotopy build data/graph/traced-v1.retino-v1.json — 04장 3.1

2. 공식 파일 3개 받기

출처는 Janelia FlyEM 의 MaleCNS v1.0(2026-09-03 공개 · CC BY 4.0)이다. 구글 클라우드 저장소의 평면 파일을 그대로 받는다.

키 파일 크기 내용
annotations body-annotations-male-cns-v1.0-minconf-0.5.feather 14,483,314 B 뉴런마다 종류 이름 · 부류(superclass · class · subclass) · 좌우 · 신경 · 암수 차이 표시 등
neurotransmitters body-neurotransmitters-male-cns-v1.0.feather 43,282,834 B 뉴런마다 신경전달물질 — consensus_nt 칸을 쓴다
weights connectome-weights-male-cns-v1.0-minconf-0.5.feather 1,051,241,946 B (출발 뉴런, 도착 뉴런, 시냅스 수) 1.5억 행

무결성 확인이 먼저다. 기준은 저장소가 객체마다 주는 공식 MD5(config/sources.yaml 의 md5_b64)다. 받은 뒤 우리가 계산한 SHA-256 은 data/raw/SHA256SUMS 에 남기고, 그래프 메타데이터에도 적는다. 크기가 다르거나 MD5 가 다르면 받기가 실패한다(시험 tests/test_data_verify.py).

3. 그래프 컴파일 — 네 가지 결정

fly-connectome graph 는 약 22 초 · 최대 3.5 GB 로 끝난다(runs/graph.log). 그 안에서 내리는 결정이 네 가지다.

3.1 어느 뉴런을 쓰나 — status == "Traced"

주석 파일에는 211,577 행이 있지만 끝까지 추적된 뉴런(Traced)은 165,122 개다. 나머지는 조각이거나 확인 대기다. 뉴런 번호(bodyId)를 오름차순으로 정렬해 그래프 인덱스 0 … 165,121 을 붙인다.

3.2 연결의 부호 — 신경전달물질로

LIF 모델에서 연결은 흥분(+) 이거나 억제(−) 다. 부호는 consensus_nt(뉴런 예측 · 종류 · 문헌을 합친 칸)에서 온다.

신경전달물질 뉴런 수 부호 근거
아세틸콜린 103,718 +1 초파리 중추의 주 흥분성 전달물질
글루탐산 29,296 −1 초파리 중추에서는 GluCl 을 통해 억제(Liu & Wilson 2013)
GABA 22,055 −1 억제
히스타민 5,910 −1 억제(Hardie 1989)
도파민 · 옥토파민 · 세로토닌 392 · 101 · 48 0 조절 물질 — 빠른 흥분/억제로 볼 수 없어 연결을 끈다
미정 · 행 없음 3,100 · 502 0 모르는 것은 0 으로 두고 그렇게 적는다

⚠️ 왜 consensus_nt 인가 — 뉴런 단위 예측(predicted_nt)을 그대로 쓰면 케니언 세포 4,058 개가 도파민으로 잘못 붙어 버섯체 입력이 통째로 꺼진다(연구 노트 08). 컴파일 뒤 케니언 세포 4,064 개의 부호가 전부 +1 인지 시험이 확인한다(test_kenyon_cells_are_excitatory).

3.3 연결 — Traced 사이만, 같은 쌍은 합친다

연결 원본 151,856,684 행 가운데 양 끝이 모두 Traced 인 연결 25,563,197 개를 남긴다(시냅스 합 124,025,046). 같은 (출발, 도착) 쌍이 여러 번 나오면 시냅스 수를 더한다(이번 판에는 0 개). 자기 자신으로 가는 연결은 101 개.

3.4 저장 형식 — 출발 뉴런 순 정렬(CSR)

파일 내용
traced-v1.neurons.parquet 뉴런마다 bodyId · 부호 · 주석 칸 16개(종류 · 부류 · 좌우 · 신경 · 암수 표시 · fru/dsx …) · nt
traced-v1.edges.npz row_ptr(뉴런 i 의 연결이 어디서 시작하나) · dst(도착) · count(시냅스 수)
traced-v1.json 메타데이터 — 개수 · 부호 규칙 · 신경전달물질 분포 · 원본 SHA-256

엔진이 쓰는 연결 세기는 부호 × 시냅스 수 × 0.275 mV × w_scale 이다(02장 · 03장).

4. 대조군 — 섞은 배선(rewired)

"결과가 초파리 배선 덕인가, 아니면 그냥 뉴런이 많고 연결이 많아서인가"를 가르려고 같은 재료로 전선만 무작위로 섞은 뇌를 하나 더 만든다.

무엇을 섞나 무엇을 지키나
모든 연결의 도착 뉴런 배열을 무작위 순열로 섞는다(graph.rewire(g, seed)) 뉴런마다 나가는 연결 수 · 들어오는 연결 수 · 시냅스 수 분포 · 출발 뉴런의 부호 · 주석 전부

그래서 섞은 배선에서도 "시각 뉴런", "하강 뉴런" 같은 이름표와 개수는 그대로다 — 누가 누구에게 이어졌나만 사라진다. 시험 test_rewired_preserves_in_and_out_degree 가 들고 나는 연결 수 보존을 확인한다. 씨앗 0 을 기본으로 쓴다(traced-v1.rewired-s0).

재배선은 여럿이어야 한다(2026-09-23 · R-7469 F-001) — 하나와 비교하면 우연히 약한/강한 재배선을 골랐을 수 있다. graph --rewired-seeds 0-19 로 씨앗 범위를 한 번에 만들고(재배선 하나 수 초 · 파일 약 200 MB 씩 · 메타에 씨앗 · 규칙 · 자기 연결 수), 자료 v2 는 씨앗 0~4 다섯을 같은 입력으로 돌린다(06장). 판정은 이 앙상블 분포와 비교한다(09장 2절). 자료를 모을 때는 그래프 파일을 미리 만들지 않아도 된다 — collect 가 graph.rewire(g, seed) 로 그때 만든다.

이 대조군은 이 프로젝트 모든 단계에서 쓰인다 — 03장의 도망 반사(섞은 배선은 침묵해야 한다) · 06장의 학습 자료(모든 뇌에 같은 입력) · 09장의 판정(앙상블) · 성적표(rewired · rewired-s<K> 구성).
