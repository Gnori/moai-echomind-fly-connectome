09. 평가와 대조군

2부 Qwen 연결 · 넷째 장. 코드: src/moai_echomind_fly/loop/train_cli.py(eval-caption) · scorecard.py · linear_probe.py · stats.py · compress.py · bump.py. 증거: W loop 3.3 ~ 3.5 · 근거: 연구 노트 12 §5.

▶ 2026-09-23 판정 규칙이 코드가 됐다 — stats-v2(재배선 앙상블 · 에피소드 순열 · Holm · 부트스트랩) · compress-v1(채널별 압축 + 선형 관문) · scorecard-v2(재배선 투영기 여럿). R-7469 F-001 · F-003 · F-004.

1. 네 가지 잣대

손실이 내려갔다는 것만으로는 아무것도 말할 수 없다(08장 3절 — 틀 글자만 맞혀도 내려간다). 그래서 네 가지로 잰다.

잣대 묻는 것 Qwen 무게
선형 검사 신호 자체에 정보가 있나(Qwen · 투영기 없이) — 그리고 재배선 앙상블보다 나은가 안 씀 CPU 약 30 s(v1 · 재배선 1)
압축 관문 채널별로 줄인 벡터에서도 그런가 → 어느 채널을 투영기에 넣나 안 씀 CPU
캡션 평가 Qwen 이 신호를 읽어 상황을 말하나 씀 29 GB · 약 6 분
성적표 신호로 몸을 잘 움직이나 · 다른 방식보다 나은가 씀 29 GB · 약 1.5 시간(5 구성 × 10 씨앗)

그리고 모든 잣대에서 진짜 배선을 재배선과 나란히 놓는다 — v1 은 재배선 하나, v2 부터는 앙상블(선형 검사 · 관문 5 개 · 투영기 ≥ 3 개).

2. 판정 규칙 — stats.STATS_RULE(판 stats-v2)

"진짜 배선이 앞선다"를 코드로 정해 두었다. 결과를 보기 전에 적은 규칙이다(R-7469 F-001).

요소 규칙 왜
비교 대상 자료에 든 모든 재배선 뇌(앙상블) 하나면 우연히 약한/강한 재배선을 골랐을 수 있다(연구 노트 12 [19])
통계 단위 에피소드(씨앗) — 결정들은 몇 에피소드에 몰려 독립이 아니다 결정 단위로 세면 p 가 과장된다
p 값 같은 평가 결정에서 (진짜 맞힘 0/1 − 재배선들이 맞힌 비율)을 에피소드마다 합 → 부호 뒤집기 순열(한쪽) · 에피소드 ≤ 16 이면 2ⁿ 경우를 전부 센다(정확) · 많으면 몬테카를로 10,000 귀무가설(차이 없음)에서는 에피소드마다 부호가 뒤집혀도 같다
다중 비교 Holm 보정 — 가족 = 판정 대상 칸 전부 채널 × 칸 수십 쌍을 한꺼번에 본다(우연한 "앞섬"이 섞인다)
구간 정확도 95 % 구간 = 에피소드 부트스트랩 2,000 회 표본 100 개의 오차는 약 ±10 %p(연구 노트 12 [18])
통과 앙상블 순위 ≥ 95 % 그리고 Holm p < 0.05 그리고 찍기(최빈값)보다 높음
판정에서 빼는 것 운동 채널(하강 뉴런은 교사 명령을 받는 회로라 정답이 샐 수 있다 · 0.610 대 찍기 0.590) · 냄새 쪽 칸(v2 · 한 창에서는 입력부터 좌우가 잡음 아래 — 04장 3.2) · 전 채널 묶음(all · 운동을 품는다) 판정 밖이어도 값은 파일에 남는다

시험 tests/test_stats.py(9 개): 부호 뒤집기 순열(정확 · 몬테카를로) · Holm 단조 · 심은 신호만 에피소드 단위로 통과 · 제외 칸은 보정 · 판정 밖 · 압축 k 규칙 · 봉우리 위상 · 칸 값 구간 · 성적표 앙상블 판정.

3. 선형 검사 — fly-connectome linear-probe

캡션 평가가 찍기 수준일 때 어디가 막혔는지 가르는 도구다 — 그리고 v2 부터는 2절 규칙으로 판정까지 한다.

uv run fly-connectome linear-probe --dataset fly-loop-v2 [--judge-only] [--permutations 10000]   # CPU · runs/linear-probe-*.json
방법 내용
분류기 선형(능선 회귀 · 이중 형태 — 차원 3.2만 > 표본 581 이라 581 × 581 행렬만 푼다)
전처리 학습 자료 평균으로 중심화(안 하면 크게 떨어진다 · 실측)
규제 세기 학습 자료 안에서 5 겹 교차검증으로 {0.01 … 10⁴} 중 고름
정확도 학습에 안 쓴 eval 나눔에서 · 진짜와 재배선 전부를 같은 방법으로
파일 brains(뇌마다 전 채널 fields · 채널별 per_channel) + cells("채널|칸" 마다 진짜 · 찍기 · 재배선 분포(값 · 평균 · 5/95 %) · 순위 % · 순열 p · Holm p · 95 % 구간 · judge · pass)
결과 뜻
찍기보다 높다 신호에 정보가 있다 → 투영기 · 학습(전달) 이 Qwen 에 못 넘긴 것
찍기와 같다 신호(또는 특징 만드는 법)에 정보가 없다 → 앞쪽(1부) 을 고쳐야 한다
통과(2절) 그 채널 · 칸에서 진짜 배선이 재배선 앙상블을 앞선다 — 이것만 "초파리 배선 덕"의 근거로 쓴다

4. 압축 관문 — fly-connectome compress fit · gate(판 compress-v2 · v1 은 결과를 본 뒤 고쳤다)

3.2만 차원을 통째로 넣으면 선형 검사도 찍기 수준이 된다 · 채널별로 64 차원까지 줄여도 진짜 배선이 앞선다(연구 노트 12 §1.1 ① — 시각 → 물체 쪽 0.705/0.571 · 몸 → 다리 0.600/0.448) → 차원 ≫ 표본의 표준 처방(채널별 압축).

uv run fly-connectome compress fit  --dataset fly-loop-v2     # 뇌마다 · 채널마다 PCA(학습 나눔으로만) → runs/compress-fly-loop-v2-compress-v1/<뇌>.npz · meta.json
uv run fly-connectome compress gate --dataset fly-loop-v2     # 압축 특징으로 2절 판정 → gate.json(통과 채널 · 칸)
규칙(config/compress.yaml) v1(결과 보기 전에 적음 · config/archive/compress-v1.yaml) v2(결과 뒤 고침 · 4.1)
방법 PCA · 중심화 같음
남길 차원 k 설명 분산 ≥ 0.95 인 가장 작은 k — 단 16 ≤ k ≤ 64 모든 뇌 · 모든 채널에 같은 64(k_fixed · 차원이 64 보다 작은 채널은 그대로)
맞추는 자료 학습 나눔(train)만 · 뇌마다 따로(재배선 5 개도 같은 규칙으로) 같음
관문 압축 특징으로 선형 검사 + 2절 판정 → 한 칸이라도 통과한 채널만 train-v4 로 · 통과 0 이면 F-005 를 하지 않는다 같음
파일 runs/compress-<자료>-<판>/ — <뇌>.npz(채널마다 mean · components [k, d] · explained) · gate.json(채널 × 칸 판정 · passed_channels · passed_cells) · meta.json(규칙 · 고른 k · 설명 분산 · 자료 체크섬) 같음 · 학습 규칙(TRAIN_RULE.compress)이 어느 판을 읽을지 정한다

시험: k 규칙(test_compress_fit_picks_k_by_variance_rule) · 압축 관문은 선형 검사와 같은 판정 코드를 쓴다(linear_probe.run(transform=)).

odor_side · odor_level 냄새 쪽 · 세기(냄새 쪽은 판정 밖 · 값은 남긴다)
legs 다리 접촉 개수

결과는 runs/projector-<뇌>-<판>/eval-caption-<저장본>.json(정확도 · 기준선 · 예시 8 개). --version 으로 어느 판의 투영기를 잴지 고른다(기본 = 지금 규칙 판 train-v4 · 지금 있는 결과는 --version train-v2). 성적표도 같다.

읽는 법: 기준선보다 확실히 높아야 "읽었다". 그리고 진짜 배선이 재배선들보다 높아야(2절 규칙 · 재배선 투영기 ≥ 3) "초파리 배선 덕에 읽었다".

6. 성적표 — fly-connectome scorecard(판 scorecard-v2)

uv run fly-connectome scorecard --seeds 2000-2009                                              # v2 결과 구성(재배선 하나)
uv run fly-connectome scorecard --seeds 2000-2039 --configs vector,text,no_circuit,rewired-s0,rewired-s1,rewired-s2,no_llm   # v4 예정

같은 씨앗(학습 · 평가 자료에 없는 것)을 여러 방식으로 돌린다.

구성 앞(인코더) 뒤 가르는 것
vector(본 설계) 진짜 배선 → 채널 벡터 → (v4: 압축) → 투영기(학습) Qwen —
text 진짜 배선 → 글 요약(채널마다 발화율 상위 단위) Qwen(학습 없음) 벡터가 글보다 나은가
no_circuit 세계의 원시 숫자(물체 방위 · 크기 · 냄새 농도 · 다리 힘) Qwen(학습 없음) 초파리 뇌를 거치는 것이 도움이 되나
rewired / rewired-s(대조군) 재배선 씨앗 K → 채널 벡터 → 투영기(똑같이 학습) Qwen 초파리 배선 덕인가 — v4 는 최소 3 개
no_llm 진짜 배선 → 하강 뉴런 그대로(명령 없음) 없음 Qwen 이 더한 것이 있나
지표 뜻
reach_rate 먹이 도착률(주 지표 · 에피소드 부트스트랩 95 % 구간 reach_ci95)
final_food_mm_mean 끝났을 때 먹이까지 평균 거리
avoid_rate 다가오는 물체를 안 부딪힌 비율 — 판정에 쓰지 않는다(가만히 있는 no_llm 만 0 · 움직이면 전부 1.0 · 가르는 힘 없음)
schema_violations 행동 JSON 형식 위반(위반이면 직전 행동 유지)

문구 규칙 — 코드가 정한다 (R 2.0-6 · scorecard.judge)

재배선 투영기 수 규칙
하나(v2 결과) scorecard-v1: vector 의 도착률 또는 회피율이 rewired 보다 높으면 "앞섰다"
여럿(v4) scorecard-v2: vector 의 도착률이 재배선 전부보다 높고(순위 100 %) 씨앗별 쌍 차이(vector − 재배선 평균)의 부호 뒤집기 순열 p < 0.05 
wording = "초파리 배선 벡터가 섞은 배선보다 나았다" if beats \
     else "섞은 배선 대조를 이기지 못했다 — '초파리 뇌'라는 말을 쓰지 않는다"

scorecard.json 에 judge(규칙 · 순위 · p · 구간) · vector_beats_rewired · wording 이 그대로 남는다. 보고서는 이 문구를 따른다 — 사람이 고쳐 쓰지 않는다.

⚠️ 정직 목록: no_circuit 에는 영상 이미지를 주지 않는다(mlx-lm 은 Qwen 의 글 부분만 올린다) · 걷기 리듬은 FlyGym 제어기가 만든다.

7. 공간 채널 — 나침반 봉우리 검사 (fly-connectome inspect bump --dataset fly-loop-v2)

3차원(F-008)의 첫 판정이다. 공간 채널의 EPG 구획 위상이 참값 몸 방향을 따라가나 — 원형 상관 · 에피소드 순열 · 진짜 대 재배선 순위(04장 5.4). 통과든 실패든 runs/bump-check-*.json 에 기록한다.

결과(runs/bump-check-20260923-195413.json · 19:53 · EPG 단위 16 · 학습 + 평가 3,297 결정):

뇌 EPG 발화가 있는 결정 봉우리 길이 중앙 원형 상관 절댓값 p
진짜 배선 0 / 3,297 0 0 1.0
재배선 s0 105 0 0 1.0
재배선 s1 · s2 · s3 0 0 0 1.0
재배선 s4 793 0 0.021 0.58

→ 진짜 배선의 EPG 는 한 번도 발화하지 않았다 — 봉우리 없음(실패로 기록). 예상된 한계다: 이 모델은 쉬는 상태가 침묵이고 신경조절 · 전기 시냅스가 없으며, 시각 입구가 다가옴뿐이라 방향 단서가 회로에 들어가지 않는다. 재배선에서 발화한 것은 무작위 배선이 시각 입력을 EPG 에 우연히 이은 것이고 방향과 상관이 없다(s4 |r| 0.021 · p 0.58). → F-006(회로 학습)의 space 목표(config/physiology.yaml · physiology-v1)로 넘긴다 — 봉우리가 서게 만드는 것이 회로 학습의 목표 중 하나가 된다.

8. 판정 순서

선형 검사(stats)에서 통과 칸이 있나?  ── 없음 ──► 1부(신호 · 채널 · 인코더)를 고친다
        │ 있음   (v2 자료: 8 칸 ✅ · 3.2)
        ▼
압축 관문 통과 채널이 있나?  ── 없음 ──► 압축 규칙 · 자료 양을 본다(F-005 를 하지 않는다)
        │ 있음   (v2 자료: 시각 · 촉각 · 미각 · 몸 ✅ · 4.1)   ◄── 지금 여기: train-probe → 요구자 확인 → 학습 4
        ▼
캡션 평가가 찍기 수준?  ── 예 ──► 2부 전달(투영기 · 손실 · 자료 양)을 고친다   ◄── v1 자료 · train-v2 는 여기서 막혔다
        │ 아니오
        ▼
성적표에서 vector 가 재배선 앙상블을 앞서나(scorecard-v2)?  ── 아니오 ──► 문구 규칙 발동 · 원인을 가른다
        │ 예
        ▼
"초파리 배선 벡터가 섞은 배선보다 나았다" — 보고 가능
