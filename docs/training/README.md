# 초파리 뇌 학습 안내서

> 2026-09-23 · 저장소 `moai-echomind-fly-connectome` · 요구사항 R-3340(C 단계 결과) · **R-7469(다음 학습 · 진행 중)**.
> 이 안내서는 **"초파리 뇌를 돌려 LLM 에 잇기까지 무엇을, 어떤 순서로, 어떻게 하는가"** 를 처음부터 끝까지 적은 것이다.
> 순서는 요구자가 정했다 — **먼저 초파리 뇌(1부), 그다음 Qwen 연결(2부).**
> 숫자는 전부 실제 실행 기록(`runs/` · `data/`)에서 옮겼고, 어느 파일에서 왔는지 같이 적었다.

## 먼저 알아 둘 한 가지 — 무엇이 "학습"되나

이 프로젝트에는 부품이 셋 있고, **학습(기울기로 가중치를 고치는 일)을 하는 것은 가운데 하나뿐**이다.

| 부품 | 무엇 | 학습하나 | 그 대신 무엇을 하나 |
|---|---|---|---|
| **초파리 뇌** | MaleCNS v1.0 연결 지도 16.5만 뉴런 · 2,556만 연결을 LIF 방정식으로 돌린 것 | **안 한다** | 공식 데이터를 그대로 **만들고**, 방정식을 기준 구현과 **맞추고**, 배율 하나(`w_scale`)를 미리 적은 규칙으로 **고르고**, 알려진 반사로 **검산**한다. 2026-09-23 부터 문헌 값 하나(같은 쪽 방출 × 1.4 · `sim-v2`)와 시야 자리 대응(`retino-v1` · 계산)이 더해졌다 — [1부](01-뇌-재료-공식-데이터와-그래프.md) |
| **투영기** | 초파리 신호 벡터 → Qwen 입력 자리로 옮기는 작은 신경망 — v1 자료 결과(train-v2)는 2층 MLP 3,187만 매개변수 · 지금 판(train-v5)은 **채널별 압축(PCA · 크기 맞춤 · 맞춤) → 선형** 133만 | **이것만 학습** | [2부](06-학습-자료-모으기.md) |
| **Qwen3.8-27B** | 받아 둔 언어 모델(Uncensored MLX 8bit 파생판) | **안 한다**(얼림) | 학습 전후 가중치 지문이 같은지 확인한다 |

그래서 1부에서 말하는 "초파리 뇌 학습"은 정확히는 **뇌를 준비하고 · 맞추고 · 검산하는 일**이다.
회로 자체를 배우게 하는 방법은 아직 구현되지 않았고, 후보를 [05장](05-회로를-학습시키려면.md)에, 정의를 R-7469 F-006 · F-007 에 두었다.

```
[1부 초파리 뇌]
 공식 파일 3개 ──► 그래프(진짜 배선 · 재배선 여럿) ──► LIF 엔진(sim-v2) ──► w_scale 맞추기 ──► 도망 반사 검산
   (01장)                (01장)                       (02장)              (03장)              (03장)
                                   │
                                   ▼  감각(고도 · 시야 자리) → 뇌 → 신호 벡터 10채널(공간 포함) (04장)
[2부 Qwen 연결]
 교사가 몸을 몰며 자료 모으기 ──► 판정(stats) · 압축 · 관문 ──► 투영기 ──► 2단계 학습(캡션 → 행동) ──► 캡션 평가 · 성적표(앙상블)
        (06장)                        (09장)                  (07장)          (08장)                        (09장)
                                                                                                             │
                                                                                                             ▼
                                                                                               학습 기록 · 결과 · 다음 (10장)
```
