# 초파리 뇌 학습 안내서

> 2026-09-23 · 저장소 `moai-echomind-fly-connectome` · 요구사항 R-3340.
> 이 안내서는 **"초파리 뇌를 돌려 LLM 에 잇기까지 무엇을, 어떤 순서로, 어떻게 하는가"** 를 처음부터 끝까지 적은 것이다.
> 순서는 요구자가 정했다 — **먼저 초파리 뇌(1부), 그다음 Qwen 연결(2부).**
> 숫자는 전부 실제 실행 기록(`runs/` · `data/`)에서 옮겼고, 어느 파일에서 왔는지 같이 적었다.

## 먼저 알아 둘 한 가지 — 무엇이 "학습"되나

이 프로젝트에는 부품이 셋 있고, **학습(기울기로 가중치를 고치는 일)을 하는 것은 가운데 하나뿐**이다.

| 부품 | 무엇 | 학습하나 | 그 대신 무엇을 하나 |
|---|---|---|---|
| **초파리 뇌** | MaleCNS v1.0 연결 지도 16.5만 뉴런 · 2,556만 연결을 LIF 방정식으로 돌린 것 | **안 한다** | 공식 데이터를 그대로 **만들고**, 방정식을 기준 구현과 **맞추고**, 배율 하나(`w_scale`)를 미리 적은 규칙으로 **고르고**, 알려진 반사로 **검산**한다 — [1부](01-뇌-재료-공식-데이터와-그래프.md) |
| **투영기** | 초파리 신호 벡터 → Qwen 입력 자리로 옮기는 작은 신경망(3,187만 매개변수) | **이것만 학습** | [2부](06-학습-자료-모으기.md) |
| **Qwen3.8-27B** | 받아 둔 언어 모델(Uncensored MLX 8bit 파생판) | **안 한다**(얼림) | 학습 전후 가중치 지문이 같은지 확인한다 |

그래서 1부에서 말하는 "초파리 뇌 학습"은 정확히는 **뇌를 준비하고 · 맞추고 · 검산하는 일**이다.
회로 자체를 배우게 하는 방법은 아직 구현되지 않았고, 후보만 [05장](05-회로를-학습시키려면.md)에 정리했다.

## 전체 흐름

```
[1부 초파리 뇌]
 공식 파일 3개 ──► 그래프(진짜 배선 · 섞은 배선) ──► LIF 엔진 ──► w_scale 맞추기 ──► 도망 반사 검산
   (01장)                (01장)                    (02장)          (03장)              (03장)
                                   │
                                   ▼  감각 → 뇌 → 신호 벡터 9채널 (04장)
[2부 Qwen 연결]
 교사가 몸을 몰며 자료 모으기 ──► 투영기 ──► 2단계 학습(캡션 → 행동) ──► 캡션 평가 · 성적표 · 선형 검사
        (06장)                    (07장)          (08장)                        (09장)
                                                                                  │
                                                                                  ▼
                                                                    학습 기록 · 결과 · 다음 (10장)
```

## 지금 상태 (2026-09-23)

| 단계 | 상태 |
|---|---|
| 1부 — 뇌 만들기 · 맞추기 · 검산 | ✅ 통과(조건부 — 청각 → 거대섬유가 생체와 다름) |
| 2부 — 자료 · 학습 · 평가 · 성적표 | ✅ 다 돌았다 · ❌ **진짜 배선이 섞은 배선을 이기지 못했다**(먹이 도착 0.2 대 0.2) |
| 원인 | 신호에는 정보가 있다(선형 검사에서 진짜 배선이 더 높음). **3.2만 차원을 통째로 넣는 전달 방식**이 그 차이를 묻는다 — [10장](10-학습-기록과-다음.md) |

> 이 결과 때문에 규칙(R 2.0-6)이 발동해 있다 — **이 판의 결과로는 "초파리 뇌 덕분"이라고 쓰지 않는다.**
