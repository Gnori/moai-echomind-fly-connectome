00 · 초파리 뇌 쉽게 보기 — 무엇이고, 무엇을 배우고, LLM 과 이으면 무엇이 좋아지나

이 장은 전문 지식 없이 읽도록 쓴 요약이다(2026-10-04 · 요구자 요청 "내가 이해할 수 있게 · 전문 용어도 풀어서"). 숫자는 모두 실제로 잰 값이고, 아직 재지 않은 것은 "기대(가설)" 라고 따로 표시했다. 더 깊은 내용은 01~12장, 진행 상황은 인수인계.

0. 한 장 요약

질문 짧은 답
이게 뭔가? 실제 수컷 초파리 한 마리의 뇌 배선도 전체를 컴퓨터에서 전기 신호로 돌리는 것. 그 신호를 LLM(Qwen) 에 넣어 함께 일하게 하려는 연구
역할 나누기 초파리 뇌 = 감각과 반사를 맡는 "몸의 뇌" · LLM = 생각하고 말하는 "머리"
지금 확실히 되는 것 다가오는 것을 보면 도망치는 반사 — 진짜 배선에서만 일어난다(진짜 40/40 · 섞은 배선 0/120)
안 되는 것 사물 종류 알아보기(사람 · 의자 · 바위 구분) · 스스로 걷기 시작하기 · 냄새로 배우기(아직)
LLM 과 이은 결과 LLM 이 뇌 신호를 읽고 행동할 수는 있다. 하지만 "세상 숫자를 그냥 글로 주는 것"보다 나은 점은 아직 못 보였다
지금까지 확인된 실제 효과 ① 반사는 LLM 없이 처리 ② LLM 을 부르는 횟수를 82 % 줄여도 성적이 떨어지지 않음(그러나 "언제 부를지"를 뇌가 잘 고른 것인지는 아직 증명 못 함)
다음에 배울 것 ① 냄새 학습 살리기 ② 눈 회로 맞추기 ③ 뇌 신호를 LLM 에 더 작고 알맞게 넘기기

1. 초파리 뇌란 — 이 프로젝트에서

1.1 재료: 배선도(연결 지도)

  • 과학자들이 수컷 초파리 한 마리의 신경계를 아주 얇게 썰어 전자현미경으로 찍고, 모든 신경세포(뉴런)와 그 연결을 하나하나 따라 그렸다. 이것을 연결 지도(커넥톰) 라고 한다. 우리는 공개된 판(MaleCNS v1.0)을 쓴다.
  • 크기: 뉴런 16만 5천 개 · 연결 2,556만 개 · 뉴런 종류 1만 1천여 가지.
  • 비유: 도시의 전선 배선도. 어느 집(뉴런)에서 어느 집으로 전선(연결)이 몇 가닥 가는지, 그 전선이 "켜라(흥분)"인지 "꺼라(억제)"인지가 다 적혀 있다.

1.2 엔진: 뉴런을 단순한 전기 식으로 돌린다

  • 뉴런 하나하나를 "물이 차면 넘치는 컵" 처럼 계산한다. 들어오는 신호가 쌓이다가 문턱을 넘으면 "탁" 하고 신호(발화 · 스파이크)를 내보내고 다시 비운다. 이 식을 LIF(새는 통합 후 발화)라 부른다.
  • 출처: Shiu 등 2024 년 논문의 모형(공개 · MIT 허가). 이 모형으로 실제 초파리 실험 결과 일부(먹이 맛 → 입 내밀기 등)를 재현했다고 보고됐다.
  • 맥 한 대의 그래픽 칩(GPU)으로 돌린다. 원래 프로그램(Brian2)과 발화가 완전히 같게 나오는 것을 확인했다.

1.3 입력과 출력

무엇 비유
입력(감각) 눈 · 더듬이(냄새) · 다리(촉각)에 해당하는 뉴런 약 4,500 개에 "얼마나 세게 자극이 왔나"를 넣는다 눈과 코로 들어오는 신호
출력(하강 뉴런) 뇌에서 몸으로 내려가는 명령 뉴런 — 걷기(DNp09) · 돌기(DNa02) · 도망(거대섬유 DNp01) 뇌가 근육에 보내는 지시
신호 벡터 뇌 곳곳(시각 · 냄새 · 촉각 · 몸 · 운동 · 공간 등 11 갈래)의 뉴런 활동을 숫자 약 3만 3천 개로 요약 뇌 속 상황을 찍은 스냅사진

1.4 정직 장치: "섞은 배선" 대조군

  • 진짜 배선과 뉴런 수 · 연결 수는 똑같지만, 누가 누구와 이어졌는지를 무작위로 섞은 가짜 뇌를 3 개 만든다.
  • 모든 시험을 진짜 뇌와 가짜 뇌에 똑같이 한다. 진짜가 가짜보다 통계적으로 확실히 나을 때만 "초파리 뇌 덕분"이라고 쓴다.
  • 왜? 뉴런이 이만큼 많으면 아무렇게나 이어도 어느 정도 정보는 흘러간다. "진짜 초파리 배선이라서" 된 것인지를 가려야 한다.
  • 이 규칙에 따라 지금까지 여러 번 "이기지 못했다" 고 기록했다(아래 4장).

2. 이 뇌가 지금 할 수 있는 것 · 없는 것 (실측)

2.1 실제 초파리라면

초파리는 "그게 무엇인지"는 모르지만 "나에게 무엇인지"는 구분한다.

  • 잘하는 것: 다가오는 큰 것 → 도망 · 작게 움직이는 것 → 쫓아감(짝) · 냄새 수십 가지 구분 · 냄새와 좋고 나쁨을 연결해 배우기 · 무늬와 장소 기억 · 색과 밝기.
  • 못 하는 것: "의자" "사람" 같은 개념 · 사람과 개 구분(둘 다 "크고 다가오는 것") · 모양 알아보기(눈 해상도가 한쪽에 약 800 칸뿐).

2.2 우리 모형(지금)

무엇 숫자
✅ 된다 도망 반사 — 공이 다가오면 거대섬유가 켜짐. 섞은 배선은 한 번도 안 켜짐 진짜 40/40 · 섞은 배선 0/120 (에코월드 상자 월드)
⚠️ 정보는 있으나 진짜만의 것 아님 무언가 있다 · 왼쪽/오른쪽 · 다가온다 — 뇌 신호로 읽히지만 섞은 배선도 같다 있다 0.760 대 섞은 0.743 · 0.733 · 0.743
⚠️ 턱걸이 가까운가(1.5 m 안) 0.696 대 0.626 · 0.622 · 0.676 (통계 기준 0.05 에 0.049)
❌ 안 된다 사람인지 아닌지 0.649 대 0.621 · 0.617 · 0.629 (차이 없음 · 예상대로)
❌ 모형에 없다 배고픔 같은 내부 상태 · 기분을 바꾸는 신경조절물질(도파민 등의 느린 효과) · 스스로 시작하는 행동 쉬는 상태가 "완전 침묵"이라 아무것도 안 넣으면 아무것도 안 한다
❌ 아직 안 된다 냄새를 좋고 나쁨과 연결해 배우기 — 배우는 자리(버섯체 출력 뉴런)가 침묵 아래 3장

⚠️ 사물 시험에서 종류를 못 가린 것은 뇌 탓만이 아니다. 지금은 물체마다 "어느 쪽 · 얼마나 크게 · 얼마나 빨리 커지나" 세 숫자만 계산해 넣는다. 그래서 같은 크기로 다가오면 사람이든 바위든 뇌에는 같은 입력이 간다. 종류를 물으려면 눈(광수용체)에 그림을 넣어야 한다(5장 ②).

3. 무엇을 학습하나

3.1 원칙 — 배선은 건드리지 않는다

  • 연결 2,556만 개는 그대로 둔다. 배선을 학습으로 바꾸면 "진짜 초파리 배선이라 됐다"를 섞은 배선과 비교할 수 없게 된다.
  • 대신 배선 위의 손잡이 몇십~몇백 개만 돌린다.

3.2 학습의 세 종류

종류 무엇을 바꾸나 비유 상태
① 맞추기(조정) 뉴런 종류별 성질(얼마나 빨리 반응 · 얼마나 쉽게 발화) · "이 종류 → 저 종류" 연결 묶음 세기(몇 배) 배선은 두고 전구 밝기와 스위치 감도를 조절 도구 완성 · 한 번 실행
② 뇌가 스스로 배우기(가소성) 냄새 뉴런(KC) → 출력 뉴런(MBON) 연결이 상(보상) · 벌(처벌) 신호에 따라 세지거나 약해짐 — 실제 초파리가 냄새를 기억하는 방식 경험이 길을 닦음 코드 완성 · 출력이 침묵해 아직 못 배움
③ 뇌 밖 학습 뇌 신호를 LLM 이 알아듣는 말로 바꾸는 투영기(4장) · 뇌 신호로 걷기/돌기를 고르는 빠른 정책 통역사 교육 여러 번 실행

3.3 지금까지 해 본 것

학습 결과 섞은 배선과 비교
도망 반사 범위 이미 목표를 만족 → 학습 필요 없음 반사 자체가 진짜 배선만의 것
냄새 뉴런 "드물게 켜지기" (냄새마다 KC 뉴런의 5~10 % 만 켜져야 냄새끼리 헷갈리지 않는다 — 실제 초파리 측정값) 1.0 % → 4.8 % (KC 끼리 연결을 2.1 배로) 섞은 배선도 4.7 % 로 똑같이 맞춰짐 · 새 냄새 일반화는 섞은 배선이 오히려 나음(2/5 대 4/5) → 진짜만의 성과 아님
냄새 학습 출력(MBON) 여전히 침묵 —

4. LLM 과 어떻게 잇나

4.1 큰 그림 — 이미지 생성의 반대

 [세계]  →  [초파리 뇌]  →  [투영기(통역)]  →  [LLM Qwen]  →  [행동 · 말]
  공 · 냄새    감각 · 반사      뇌 신호 → LLM 의      생각 · 판단
  · 사람 …    (몸의 뇌)        "단어" 몇 개
  • 그림 그리는 AI 는 글 → 그림이다(글을 이해하는 부분이 앞, 그림 만드는 부분이 뒤).
  • 우리는 세계 → 초파리 뇌(앞, 감각을 정리) → LLM(뒤, 생각과 말) 이다. 사진을 읽는 AI(LLaVA 같은 것)가 사진을 "단어 비슷한 것"으로 바꿔 LLM 에 넣는 것과 같은 자리에 사진 대신 초파리 뉴런 활동을 넣는다.

4.2 구체적으로

  1. 0.3 초마다 뇌를 돌리고, 뇌 속 11 갈래(시각 · 냄새 · 촉각 · 몸 · 운동 · 공간 …)의 활동을 숫자로 요약한다(약 3만 3천 개).
  2. 투영기가 갈래마다 숫자 묶음을 LLM 의 "단어 한 개" 크기(숫자 5,120 개)로 바꾼다. 이것을 소프트 토큰이라 한다 — 글자는 아니지만 LLM 이 단어처럼 받아들이는 입력.
  3. LLM 은 이 "뇌 단어"들을 보고 지금 상황을 말로 쓰거나(캡션 · 예: "왼쪽에서 무언가 다가옴") 행동을 고른다(걷기 · 돌기 · 멈추기).
  4. 고른 행동은 다시 초파리 뇌의 걷기 · 돌기 명령 뉴런에 들어가 몸을 움직인다.
  5. 학습되는 것은 투영기뿐이다. 초파리 배선도, LLM 도 그대로다.

4.3 두 층 — LLM 은 느리니까 필요할 때만

LLM 은 한 번 생각하는 데 수 초가 걸린다. 공이 날아오는데 LLM 을 기다리면 늦는다.

층 누가 얼마나 빨리 무엇
반사 초파리 뇌 그 자체 즉시(0.1 초 단위) 도망 · 멈춤
빠른 정책 뇌 신호를 읽는 작은 계산(회귀) 즉시 냄새 쪽으로 걷기 · 돌기
깊은 판단 LLM 수 초 낯선 상황 · 목표 바꾸기 · 말하기
  • "언제 LLM 을 부를지"는 뇌 신호가 평소와 다르게 크게 바뀔 때(놀람 신호)로 정했다.

5. 이으면 실제로 무엇이 좋아지나

5.1 지금까지 확인된 효과

효과 숫자 정직한 한계
반사는 LLM 없이 즉시 도망 반사 진짜 40/40 · 섞은 0/120 피하기 동작까지 성공한 것은 아님(상자 월드에서 부딪힘 비율은 진짜도 1.00 — 반사가 0.1 초 늦고 사람 몸이 커서)
LLM 호출 줄이기 호출 −82 % · 걸린 시간 −51 % · 먹이 도착 0.575(늘 부를 때 0.350) 무작위로 같은 횟수만 불러도 0.55 → "뇌가 부를 때를 잘 골랐다"는 증명 못 함. "덜 불러도 된다"까지만
LLM 이 뇌 신호로 상황 읽기 물체 있음 0.735(섞은 0.672 · 0.703 · 0.683) · 냄새 쪽 0.530(섞은 0.476 · 0.506 · 0.502) 진짜가 이김 — 그러나 작은 차이
LLM 이 뇌 신호로 행동 먹이 도착 0.46(섞은 0.19 · 0.33 · 0.42 · 씨앗 100 · 통계 통과) 같은 자료의 다른 판(v7)은 통과 못 함 · 세계 숫자를 그냥 글로 준 경우 0.47 과 같다 → 뇌를 거쳐서 더 좋아지지는 않았다

한 줄 결론: 지금은 "초파리 뇌를 거치면 LLM 이 더 잘한다"는 증거가 아직 없다. 반사와 호출 줄이기만 실제로 쓸모가 확인됐다.

5.2 되면 생길 효과 — 기대(가설), 아직 안 잼

되면 효과 무엇을 학습해야
냄새 학습이 살아나면 NPC 가 경험으로 "이 냄새 = 좋음/위험"을 배워 LLM 없이 행동이 바뀐다. LLM 은 "왜 그쪽으로 가는지"만 말로 설명 버섯체 출력 뉴런이 침묵하는 원인 찾기 → 가소성
눈 회로가 맞춰지면 움직이는 것 / 가만있는 것 · 큰 것 / 작은 것 · 밝은 면(물?)을 뇌가 먼저 가려 LLM 에 넘김. LLM 은 그 위에서 "사람이다 · 의자다"를 판단 눈 그림 입력(광수용체 R7 · R8 · L1~L3 은 연결 지도에 있음) + 움직임 검출 회로 맞추기
뇌 신호를 작게 넘기면 지금 3만 3천 개 숫자를 통째로 넣으면 표본(수백~수천)보다 투영기 손잡이(3,190만)가 너무 많아 진짜 · 가짜 차이가 사라진다. 꼭 필요한 갈래만 작게 넘기면 LLM 이 뇌 정보를 더 잘 씀 투영기 다이어트(갈래 고르기 · 압축)
스스로 걷기를 정하면 지금 걷기는 고정 명령이 거의 그대로 지나간다. 뇌가 냄새 · 시각으로 방향을 정하면 "뇌가 몸을 움직인다" 고 말할 수 있다 명령을 더 위쪽 회로에 넣기 · 감각 → 명령 경로 맞추기

5.3 에코월드 NPC 에 붙이면 (단계 R-5138)

단계 무엇 상태
S0 연결 — NPC 한 명을 초파리 뇌로 ✅
S1 반사 — 공이 오면 반응 ✅ 반응은 진짜만 · ⚠️ 피하기는 못 넘음
S0b 사물 인식 ⚠️ 정보는 있으나 진짜만의 것 아님(가까움만 턱걸이)
S2 빠른 정책으로 걷고 피하기 ⬜
S3 목표(냄새 대신 장소)로 가기 ⬜
S4 LLM 은 사건 때만 — 반사 · 걷기는 뇌, 판단은 LLM ⬜

⚠️ 속도 문제: 뇌 계산이 실제 시간보다 느리다(대조군 포함 뇌 넷을 돌린 S0b 에서 약 16 배 — 뇌 하나면 약 4 배로 추정 · 아직 안 잼). 그래서 지금 NPC 는 세계를 멈춰 놓고 0.3 초씩 진행한다. 실제 게임처럼 실시간으로 돌리려면 뇌를 줄이거나(필요한 부분만) 더 빠른 계산이 필요하다.

6. 다음에 할 일 (제안 · 결정 대기)

순서 일 왜 크기
1 냄새 학습 출력이 왜 침묵하나 찾기 이것이 살아야 "뇌가 배운다"가 시작됨 가벼움 → 맞추기는 무거움
2 눈에 그림 넣기 + 움직임 검출 맞추기 사물 구분(실제 초파리 수준: 움직임 · 크기 · 밝기)을 제대로 물으려면 큼(에코월드에서 NPC 눈 그림을 받아야 함 — 월드 세션과 상의)
3 투영기 다이어트 LLM 과 잇는 곳이 막힌 곳으로 드러남 중간
4 NPC S2~S4 위 셋이 되면 그 위에 단계마다

모든 일은 결과 전에 판정 기준을 적고, 섞은 배선과 나란히 재고, 이기지 못하면 이기지 못했다고 적는다.
