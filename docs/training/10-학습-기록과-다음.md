## 5. 백업 — git 밖에 있는 것

`data/` 와 `runs/` 는 `.gitignore` 로 빠져 있다 — 커밋되지 않고, **이 맥에만 있다.**

| 무엇 | 다시 만들 수 있나 | 비용 |
|---|---|---|
| `data/raw/` 공식 파일(1.0 GB) | ✅ `download` | 받기 |
| `data/graph/`(397 MB) | ✅ `graph --rewired-seed 0` · `retinotopy build` | 약 22 s · 1 s |
| `data/datasets/fly-loop-v1/`(75 MB) | ⚠️ 같은 커밋 · 같은 판이면 같은 자료 | 약 30 분 |
| `data/datasets/fly-loop-v2/`(예정) | ⚠️ 같음 | 약 7 시간(일꾼 3) |
| `runs/projector-*/`(투영기 · 로그) | ⚠️ train-v2 는 초기값에 씨앗이 없어 **똑같이는 안 나온다**(train-v3 부터 초기값 씨앗 · 끝 저장본의 비트 단위 재현은 아직 재 보지 않음) | 학습 수 시간 |

| 자리 | 까닭 |
|---|---|

대상은 `data/datasets` 와 `runs`(공식 파일 · 그래프는 다시 만들 수 있어 뺀다). 복사는 **지우지 않고**(원본에서 지운 파일도 남는다),
복사 뒤 파일마다 SHA-256 을 원본과 대조해 둘 곳에 `MANIFEST.sha256` · `BACKUP.md` 를 남긴다.
첫 백업 2026-09-23 10:39 — 198 개 · 801 MB · 두 곳 모두 **198/198 같음**(USB 52 s).
**학습 · 평가 · 성적표를 새로 돌린 뒤에는 한 번 돌린다**(6절) — 자료 v2 를 묶은 뒤에도.

되살리기: `rsync -rlt <백업>/runs/ runs/` · `rsync -rlt <백업>/data/datasets/ data/datasets/` → 저장소 뿌리에서 `shasum -a 256 -c <백업>/MANIFEST.sha256`.

## 6. 이 대장을 쓰는 법

학습을 새로 돌리면:

1. 1.1 표에 한 줄 — 이름 · 뇌 · 규칙 판 · 자료 · 시각 · 걸음 · 메모리 · 상태
2. 1.2 · 1.3 에 손실과 저장본 sha256(`shasum -a 256 runs/projector-*/*.safetensors`)
3. 평가 · 성적표를 돌렸으면 2 절에 — **재배선과 나란히** · `scorecard.json` 의 `judge` 와 `wording` 그대로
4. 판정 · 측정(선형 검사 · 관문 · 봉우리 · 작은 측정)은 4.1 표에 한 줄 — 파일 경로와 함께
5. 연구 노트 11장 8.5 절과 인수인계에도 한 줄(같은 커밋에서 HTML 다시 만들기)
6. `uv run fly-connectome backup` — 새 저장본을 두 곳에 복사 · 대조
