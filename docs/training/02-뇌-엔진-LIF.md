# 02. 뇌 엔진 — LIF 방정식

> 1부 초파리 뇌 · 둘째 장. 코드: `src/moai_echomind_fly/sim.py` · 설정 `config/sim.yaml`.
> 증거: [W core 2 · 3.3](../requirements/20260921-233859-3340_fly-connectome-closed-loop-core_walkthrough.md) · 배경: [연구 노트 09 LIF 모델](../research/fly-connectome/09-LIF-모델.md).

## 1. 왜 방정식이 따로 필요한가

연결 지도는 **정적인 배선도**다. 전기가 어떻게 흐르는지는 들어 있지 않다.
그래서 뉴런 하나하나에 가장 단순한 발화 모형 — **LIF(leaky integrate-and-fire, 새는 적분 후 발화)** — 을 붙인다.
이 저장소는 **Shiu et al. 2024**(Nature · 초파리 전뇌 LIF · 참조 구현 MIT)의 방정식과 값을 그대로 쓰고, PyTorch 로 다시 구현했다(코드 복사 없음).

## 2. 방정식

뉴런마다 막전위 `v`, 시냅스 입력 `g`(선택: 적응 `A`) 세 값을 0.1 ms 간격으로 적분한다.

```
dv/dt = (v0 − v + g − A) / t_mbr      (불응기에는 멈춤)
dg/dt = −g / tau                       (불응기에는 멈춤)
dA/dt = −A / tau_A                     (적응 — 기본 꺼짐)

v > v_th 이면 발화 → v = v_reset, g = 0, A += b_adapt, 불응기 t_rfc 동안 쉼
발화는 t_dly 뒤 도착 → 도착 뉴런의 g += 부호 × 시냅스 수 × w_syn × w_scale
외부 자극(포아송) 사건마다 v += poisson_kick
```

한 걸음 안의 순서는 Brian2 기본 일정(적분 → 문턱 → 시냅스 전달 → 리셋)과 같게 맞췄다.

## 3. 매개변수와 출처 — `config/sim.yaml` (판 `sim-v2` · 옛 판 `config/archive/sim-v1.yaml`)

| 값 | 크기 | 뜻 | 출처 |
|---|---|---|---|
| `v0_mV` · `v_reset_mV` | −52 mV | 쉬는 전위 · 발화 뒤 되돌아가는 전위 | Kakaria & de Bivort 2017 |
| `v_th_mV` | −45 mV | 문턱 | 같음 |
| `t_mbr_ms` | 20 ms | 막 시간 상수(얼마나 빨리 새나) | 같음 |
| `tau_syn_ms` | 5 ms | 시냅스 입력이 사라지는 속도 | Jürgensen et al. 2021 |
| `t_rfc_ms` | 2.2 ms | 불응기 | Lazar et al. 2021 |
| `t_dly_ms` | 1.8 ms | 시냅스 전달 지연 | Paul et al. 2015 |
| `w_syn_mV` | 0.275 mV | 시냅스 하나의 세기 | Shiu 가 FlyWire 에 맞춘 값 |
| **`w_scale`** | **0.25** | MaleCNS 에 맞춘 배율 — **이 저장소가 결과를 보고 맞춘 유일한 뇌 값**(아래 `ipsi_release` 는 문헌 값을 그대로 넣은 것) | [03장](03-뇌-맞추기와-검산.md)의 규칙 fit-v1 |
| `poisson_kick_mV` | 68.75 mV | 자극 사건 하나의 세기(= 0.275 × 250) | Shiu: "250 이면 발화하기에 충분" |
| `dt_ms` | 0.1 ms | 적분 간격 | Brian2 기본 |
| `adaptation` | 없음 | 발화 적응 — 출처 있는 종류에만 켤 수 있게 자리만 있다 | — |
| **`ipsi_release`**(sim-v2) | 후각 수용 뉴런 · 같은 쪽 × 1.4 | 같은 쪽 가지로 가는 연결만 세기를 올린다 — 연결 수 · 상대는 그대로 | Gaudry et al. 2013 Nature 493:424(같은 쪽 가지가 스파이크마다 약 40 % 더 방출) |

⚠️ 이 값들은 **판 번호로 잠근다.** 하나라도 바꾸면 `version` 을 올리고, 03장의 검산을 다시 돌리고, 그 판으로 모은 학습 자료(06장)도 새로 모아야 한다(채널 벡터가 달라진다).
`sim-v1 → v2`(2026-09-23)는 후각 수용 뉴런에서 **나가는** 연결만 바꾼다 — 도망 반사 검산(시각 → 거대섬유)에는 후각 뉴런이 침묵이라 영향이 없고, 다시 돌리지 않았다. 학습 자료는 새로 모은다(`fly-loop-v2` · 06장). 시험 `tests/test_sim_ipsi.py` 가 규칙이 걸리는 연결만 바뀌는지 확인한다.

**sim-v3(2026-10-01 · 회로 학습 준비)** — sim-v3 매개변수 파일(`cellparams.py` `CellParams` · `config/fit.yaml` · `09df530`): 범위(scope) 안 **종류마다 막 시간 상수 · 문턱**, 범위 안 **종류 쌍마다 연결 배율 α ≥ 0**. 연결 수 · 부호 · 상대 · `w_scale` · `ipsi_release` 는 바꾸지 않는다. `Engine(cell=…)` 으로 넣고, **`cell` 이 없으면 지금(sim-v2)과 같은 길**이다. 처음 값(`init`)은 sim-v2 와 같아 **발화가 완전히 같다**(시험 `tests/test_cellparams.py` `test_init_params_give_identical_spikes`). 범위 · 경계는 `config/fit.yaml`(`escape-small` 매개변수 44). 학습 절차는 [03장 6절](03-뇌-맞추기와-검산.md) · 배경은 [연구 노트 09 §7](../research/fly-connectome/09-LIF-모델.md).

## 4. 기준 구현과 "발화 하나까지" 맞추기

새로 짠 엔진이 Shiu 모델과 같은지 확인하는 것이 뇌를 쓰기 전 첫 관문이다.
작은 그래프에서 Brian2(Shiu 가 쓴 시뮬레이터) 판과 우리 엔진을 같은 씨앗으로 돌려 **발화 (시각, 뉴런) 목록 전체**를 비교한다(`tests/test_sim_parity.py`).

처음에는 갈렸다 — 우리 839 발화, Brian2 817 발화. 갈라진 첫 뉴런의 궤적을 따라가 보니 원인은 하나였다.

> **불응기 중에 도착한 시냅스 입력을 Brian2 는 버린다.** `(unless refractory)` 변수에 조건부 쓰기가 걸려
> 적분뿐 아니라 시냅스 쓰기도 막힌다. 우리 엔진은 그것을 쌓고 있었다.

엔진을 그렇게 고친 뒤 **발화 목록이 완전히 같다.** 함께 확인하는 시험:

| 시험 | 확인하는 것 |
|---|---|
| `test_engine_matches_brian2_shiu_equations` | Brian2 와 발화 목록 동일 |
| `test_silent_without_stimulus` | 자극이 없으면 침묵(이 모델은 쉬는 상태가 침묵이다) |
| `test_silence_removes_influence` | 뉴런을 "침묵"시키면 그 뉴런의 영향이 사라진다 |
| `test_same_seed_same_spikes_cpu` | 같은 씨앗이면 같은 발화 |

## 5. 속도와 장치

| 장치 | 뇌 전체 1,000 ms 모의 | 발화 |
|---|---|---|
| CPU | **4.3 s** | 11,213 |
| MPS(맥 GPU) | 9.0 s | 11,213 — 비트 단위로 같다 |

발화가 드문 뇌라 CPU 가 더 빠르다 → **기본 장치는 CPU**. 메모리는 그래프를 올린 프로세스 몇 GB 수준이다.

## 6. 이 방정식이 못 하는 것 (알고 쓴다)

| 한계 | 까닭 | 이 프로젝트의 대응 |
|---|---|---|
| 빛을 광수용체에 넣으면 아무 데도 안 퍼진다(발화 0) | 쉬는 상태가 침묵이라 "억제를 푸는" ON 경로의 이중 반전을 못 낸다 | 시각 입구를 LC/LPLC(시각 투사 뉴런)로 옮겼다 — [04장](04-감각-넣기와-신호-읽기.md) |
| 먹기(미각 → MN9)가 재현되지 않는다 | 같은 이유 — 억제를 푸는 경로 | 미각 채널은 읽기만 한다 |
| 청각 → 거대섬유가 **발화**한다(생체는 문턱 아래) | 전기+화학 혼합 시냅스를 화학으로만 둔 탓(JO→GF 27 연결) | 전기 시냅스(F-006)는 미구현 — 정직 목록에 적는다 |
| 학습 · 신경조절이 없다 | 연결 지도에 시냅스를 바꾸는 규칙이 없다 | [05장](05-회로를-학습시키려면.md) · R-7469 F-006 · F-007 |
| 냄새끼리 **특이적인** 냄새 기억을 못 낸다(2026-10-07) | 촉각엽에서 활동이 번져 냄새마다 투사 뉴런(PN)의 약 44 % 가 켜진다 — 해부로는 0.04 겹치는 냄새가 발화로는 **0.83** 겹침. 그래서 KC 도 냄새끼리 겹쳐 도파민 짝짓기가 짝 안 지은 냄새까지 약하게 한다(−37 % 대 −40 %). 실제 초파리 PN 은 냄새마다 일부만 반응한다(쉬는 상태 침묵 · 촉각엽 억제 균형이 맞춰지지 않음 — 짐작 · 안 잼) | 냄새 특이성은 **접음** — 회로 학습 범위(KC · APL · MBON · PN→KC)로 못 고침 · 쓸 수 있는 말은 "MBON 냄새 반응은 진짜 배선에서만" · "구획 특이적 약화"까지 · [03장 6.4](03-뇌-맞추기와-검산.md) |
| 냄새 **좌우**를 한 결정 창(300 ms)에서 못 읽는다 | 후각 수용 뉴런이 양쪽 촉각엽으로 반반 간다(같은 쪽 51.7 % · 반대쪽 47.7 %). `sim-v2` 로 같은 쪽 방출을 올려도(× 1.4) 실제 입력의 좌우 차(두 더듬이 상대 차 중앙 4.4 %)가 발화 잡음보다 작다 — 투사 뉴런 좌우 부호 0.508(v1 · v2 같음) | 냄새 쪽 칸을 판정에서 뺀다(`stats-v2`) · 측정은 [04장 3.2](04-감각-넣기와-신호-읽기.md) · 시간을 두고 읽는 방식은 후보 · **2026-09-26**: 센서가 작은턱수염이었고(4.4 % · 0.508 은 그 기준) · 한쪽 100 % 입력이면 투사 뉴런이 좌우를 나르나 차가 2~4 % · 조향 DNa02 는 침묵 · 국소 뉴런 LN4 는 5~10 % · 1 s 이상에서 가름 → task-v4 에서 처음 찍기와 구별([04장 3.3](04-감각-넣기와-신호-읽기.md)) |
