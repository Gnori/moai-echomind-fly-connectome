06. 학습 자료 모으기

2부 Qwen 연결 · 첫 장. 코드: src/moai_echomind_fly/loop/{teacher,collect,episode}.py · datasets.py. 형식 정본: docs/datasets.md · 자료 카드 data/datasets/<이름>/README.md(git 밖).

▶ 2026-09-23 자료 v2(fly-loop-v2)를 모으는 중 — 요구사항 R-7469 F-002. 지금 있는 결과는 전부 v1 로 낸 것이다(10장).

1. 무엇을 모으나

투영기는 "이런 뇌 활동이면 이런 상황 · 이런 행동" 을 배운다. 그러려면 (뇌 신호, 정답) 짝이 필요하다.

짝의 한쪽 어디서
뇌 신호 04장의 채널 벡터 — v1 은 9 채널 31,950 차원 · v2 는 10 채널 33,402 차원(공간 채널) — 진짜 배선과 재배선 뇌 모두(v1 은 재배선 1 개 · v2 는 5 개)
정답 ① 캡션 세계 참값에서 코드가 만든 상황 설명 글
정답 ② 행동 세계 참값을 아는 교사 규칙이 낸 행동 JSON
(v2) 감각 입력 결정마다 자극 뉴런의 발화율(stim.npz) — 나중에 재배선을 더 늘릴 때 몸을 다시 안 돌리기 위해

정답은 사람이 쓰지 않는다. 몸 시뮬레이터가 아는 참값(물체가 어디 있나 · 냄새 원이 어느 쪽인가)에서 코드가 만든다.

왜 v2 인가 — 셋

까닭 v1 v2
표본이 적다 — 581 결정에 차원 31,950 · LLM 연결에 성공한 문헌 사례는 최소 수천 개(연구 노트 12 §2) 학습 60 · 평가 12 에피소드 학습 300 · 평가 40 에피소드(결정 약 3 천 · 350)
대조군이 하나 — 우연히 약한/강한 재배선을 골랐을 수 있다 · 재배선은 앙상블로 비교하는 것이 기준(연구 노트 12 §5) 재배선 씨앗 0 하나 재배선 씨앗 0~4 다섯 · 같은 감각 입력
입력에 3차원이 없다 물체는 방위 · 크기 · 확대 속도만 물체 고도 · 시야 자리별 LC 입력 · 몸 자세 · 위치 · 방향 · 공간 채널(04장 · task-v2 · retino-v1 · channels-v2)

여기에 냄새 좌우 규칙 sim-v2(02장 · 04장 3.2)도 v2 부터 들어간다.

2. 교사 규칙 — loop/teacher.py

교사가 몸을 모는 동안 결정 창마다 기록한다. 규칙은 전부 코드에 선언돼 있고 자료 meta.json 의 teacher_rules 에 그대로 실린다. v1 과 v2 가 같다.

2.1 행동 정답 (위에서부터 먼저 맞는 것)

조건 행동
다가오는 물체가 다가오고 각 크기 ≥ 20°(위협) 물체 반대쪽으로 돌며 달린다 {"walk":1.0,"turn":"right","turn_strength":1.0,…}(물체가 왼쪽이면 right)
먹이까지 ≤ 2 mm 멈춘다 {"walk":0.0,"stop":true,…}
냄새(두 더듬이 평균 ≥ 0.05)가 있고 방향이 ±15° 안 곧장 {"walk":0.8,"turn":"none",…}
냄새가 있고 옆쪽 그쪽으로 {"walk":0.6,"turn":"left","turn_strength":0.5,…} — 세기 = min(1, 방위 절댓값 ÷ 90°)
그 밖 {"walk":0.5,"turn":"none",…}

2.2 캡션 정답 — 고정 서식 한 줄

다가오는 물체: <없음 | 쪽 · 거리 · 움직임> / 먹이 냄새: <없음 | 쪽 · 세기> / 다리 접촉: N개 / 소리: 있음|없음 / 암컷 대용 물체: <없음 | 쪽>
칸 값 문턱(선언)
쪽 앞 · 왼쪽 · 오른쪽 ±15° 안이면 "앞"
거리 가까움 · 중간 · 멀리 각 크기 ≥ 30° · ≥ 10°
움직임 다가옴 · 머묾 확대 속도 > 0
냄새 세기 강함 · 약함 평균 농도 ≥ 0.5 · ≥ 0.05
소리 · 암컷 이번 과제에는 늘 "없음" 자리만 있다

예: 다가오는 물체: 왼쪽 · 중간 · 다가옴 / 먹이 냄새: 오른쪽 · 강함 / 다리 접촉: 6개 / 소리: 없음 / 암컷 대용 물체: 없음

v2 에서도 캡션 서식은 그대로다 — 3차원 칸(물체 고도 · 몸 방향 · 위치 · 기울기)은 참값에만 남기고, 3차원 캡션(caption-v2)은 F-008 5단계에서.

⚠️ 교사 규칙이 곧 결과를 정한다. 규칙이 쉬우면 무엇이든 배우기 쉽다. 그래서 재배선 벡터로 똑같이 학습한 대조군과 나란히 잰다(09장).

3. 모으기 — fly-connectome collect

3.1 먼저 작게 잰다 — collect-probe

새 종류의 무거운 실행은 작게 먼저 재고 무엇에 비례하는지 본다(CLAUDE.md). 뇌가 둘에서 여섯으로 늘었으니 시간 · 메모리를 먼저 쟀다.

uv run fly-connectome collect-probe --seeds 0-1 --rewired-seeds 0-4    # 저장 없음 · 약 4 분

runs/collect-probe-20260923-111821.json: 뇌 6 · 결정당 12.0 s(몸 3.1 + 뇌 8.9 · 혼자 돌 때) · 일꾼 하나 3.4~3.6 GB(최대 4.3) · 추정 학습 300 에피소드 3.3 h + 평가 40 에피소드 0.45 h(일꾼 3). → 요구자 확인("지금 시작") 뒤 수집.

3.2 수집

# v1 (2026-09-22): 재배선 하나
uv run fly-connectome collect --name main --seeds 0-59     --workers 3 --threads 4
uv run fly-connectome collect --name eval --seeds 1000-1011 --workers 3 --threads 4
# v2 (2026-09-23): 재배선 다섯 · 조각 이름은 v2main · v2eval (v1 조각을 덮지 않는다)
uv run fly-connectome collect --name v2main --seeds 0-299     --rewired-seeds 0-4 --workers 3 --threads 4
uv run fly-connectome collect --name v2eval --seeds 1000-1039 --rewired-seeds 0-4 --workers 3 --threads 4
옵션 뜻
--workers 3 씨앗을 세 조각으로 나눠 자식 프로세스 셋이 돈다(부모가 무거운 실행 잠금을 쥔다) → runs/dataset-v2main-w0 … w2
--threads 4 일꾼마다 CPU 스레드 수
--graph traced-v1 · --rewired-seed 0 v1: 두 뇌 = 진짜 배선 · 그 씨앗으로 섞은 배선
--rewired-seeds 0-4 v2: 진짜 + 재배선 다섯 — 뇌마다 features-rewired-s<K>.npz

한 번 도는 동안 한 에피소드에서 일어나는 일:

  1. 씨앗으로 과제를 뽑는다(냄새 원 위치 · 다가오는 물체 유무 · 시각 · 방향 · v2: 고도).
  2. 몸을 초기화하고, 결정마다 모든 뇌에 같은 감각 입력을 넣는다. 몸은 진짜 배선 뇌의 하강 뉴런을 따른다.
  3. 창이 끝나면 뇌마다 채널 특징 · 세계 참값 · 캡션 · 교사 행동 · (v2) 감각 입력을 한 줄로 남긴다(DatasetWriter).
  4. 교사 행동이 다음 결정의 명령이 된다.

시간: v1 학습용 60 에피소드 약 25 분(일꾼 3). v2 는 일꾼 셋이 같이 돌면 결정당 17~18 s(혼자 잰 12 s 보다 느리다 — CPU 를 나눠 쓴다) · 시간당 약 48 에피소드 · 2026-09-23 11:21 시작 → 14:07 에 147/300 · 18:30 쯤 끝 예상(runs/collect-v2-*.log). 가드: 평소 문턱(메모리 여유 40 %) · 한 번에 하나(runs/.heavy.lock). 띄웠으면 수십 분 간격으로 본다.

4. 묶기 — 오래 둘 자리로

runs/ 는 실행 기록을 쌓는 임시 자리다. 조각을 합쳐 data/datasets/<이름>/ 에 묶는다.

uv run fly-connectome dataset pack --name fly-loop-v2 --train v2main --eval v2eval
uv run fly-connectome dataset verify fly-loop-v2      # 체크섬 대조 — "온전"
uv run fly-connectome dataset list
파일 내용 v2 에서 달라진 것
train/ · eval/ features-real.npz 채널 이름 → float32 [결정 수, 차원] 채널 10 개
features-rewired.npz / features-rewired-s<K>.npz 재배선 뇌의 같은 것 v1 은 하나(= s0) · v2 는 씨앗마다 하나. 읽기는 둘 다 받는다(rewired → s0)
stim.npz rates float32 [결정, 구간 3, 자극 뉴런] · stim_idx 새로 — 감각 입력
samples.jsonl 결정마다 seed · decision · t_ms · truth · caption · teacher_action · reflex_bins truth 에 looming_elevation_deg · heading_deg · pos_xy · body_euler_deg
episodes.jsonl 에피소드마다 도착 · 시간 · 물체 · 부딪힘 같음
meta.json 판 번호 · 코드 커밋 · 채널 단위 이름 · 감각 대응표 · 교사 규칙 rewired_seeds 목록 · 판에 retino 추가
README.md · SHA256SUMS 자료 카드 · 체크섬 같음 
from moai_echomind_fly import datasets
feats, rows = datasets.load("fly-loop-v2", "train", "rewired-s3")   # "real" · "rewired"(= s0) · "rewired-s<K>"
datasets.rewired_brains("fly-loop-v2")                              # ["rewired-s0", …, "rewired-s4"]

같은 이름은 덮어쓰지 않는다(pack 이 거부). 설정 판이나 채널 표가 바뀌면 새 이름으로 묶는다.

6. 이 자료의 한계

  • v1: 표본이 적다(581 결정에 차원 31,950 — 55 배) · v2 로 약 5 배 늘지만 차원(33,402)에는 여전히 못 미친다 → 그래서 채널별 압축 + 관문(09장)을 거쳐 투영기에 넣는다.
  • 칸마다 답이 치우쳐 있다 — 예: v1 평가 자료에서 "물체 있음"의 최빈값이 0.667, "냄새 쪽"이 0.543. 찍기만 해도 이만큼 나온다.
  • 소리 · 암컷 칸은 늘 "없음"이라 배울 것이 없다.
  • 냄새 쪽은 한 창에서 입력부터 좌우가 잡음 아래(04장 3.2) — v2 에서도 판정에서 뺀다.
  • 같은 에피소드 안의 결정들은 독립 표본이 아니다 → 판정은 에피소드 단위(09장 stats).

7. 확인 체크리스트

  • [ ] collect-probe 로 결정당 시간 · 메모리를 먼저 쟀다(뇌 수가 바뀌었을 때)
  • [ ] 교사 도착 = 에피소드 수(교사가 과제를 풀 수 있어야 정답이 의미가 있다)
  • [ ] dataset verify → 온전
  • [ ] meta.json 의 판 번호가 지금 config/*.yaml 과 같다 · rewired_seeds 가 의도한 목록
