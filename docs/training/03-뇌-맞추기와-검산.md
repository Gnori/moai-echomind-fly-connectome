# 03. 뇌 맞추기와 검산

> 1부 초파리 뇌 · 셋째 장. 코드: `src/moai_echomind_fly/bench/escape.py`(`FIT_RULE` · 채점) · `bench/limits.py` · `protocols.py` · 설정 `config/sim.yaml` · `config/loom.yaml`.
> 증거: [W core 3.4 ~ 3.6](../requirements/20260921-233859-3340_fly-connectome-closed-loop-core_walkthrough.md).

## 1. 초파리 뇌에서 "학습"에 가장 가까운 일

초파리 회로의 가중치는 연결 지도가 정한다. 우리가 고르는 뇌 값은 **`w_scale` 하나**뿐이다 —
MaleCNS 는 Shiu 가 맞춘 FlyWire 와 시냅스를 세는 방식이 달라서, 같은 0.275 mV 를 그대로 쓰면 뇌가 너무 세게(또는 약하게) 반응한다.

이 값을 고르는 일이 이 프로젝트에서 **초파리 뇌 쪽 "학습"에 해당하는 유일한 단계**다. 그런데 기울기로 고치는 것이 아니라
**후보 몇 개를 돌려 보고 규칙으로 하나를 고르는** 방식이다. 그래서 가장 중요한 원칙이 하나 있다.

> ⚠️ **규칙은 결과를 보기 전에 적는다.** 결과를 보고 규칙을 바꾸면 "맞춘 것"이 아니라 "고른 것"이 된다.
> 고른 값은 판 번호(`sim-v1`)로 잠그고, 바꾸려면 규칙 판을 올린다.

(2026-09-23 `sim-v2` 는 `w_scale` 을 건드리지 않았다 — 문헌 값 하나(후각 수용 뉴런 같은 쪽 방출 × 1.4 · Gaudry 2013)를 그대로 넣은 것이라 "맞춘 값"이 아니다. 02장 3절.)

## 2. 무엇으로 맞추나 — 도망 반사

기준 행동은 초파리의 **도망 반사**다: 물체가 빠르게 다가오면(looming) 시각 투사 뉴런 LC/LPLC 가 발화하고, 그것이
**거대섬유(GF = DNp01)** 를 발화시켜 뛰어오른다. 생리 기록이 많아 채점 기준을 숫자로 적을 수 있다(von Reyn et al. 2014 등).

### 2.1 자극 — `config/loom.yaml`(판 `loom-v1`)

| 값 | 크기 | 뜻 |
|---|---|---|
| 자극 뉴런 | LC17 · LC12 · LPLC2 · LC26 · LC15 · LC4 · LPLC1 · LC16 · LC6 · LC21 · LC18 · LC9 · LC11 (13종) | 다가옴에 반응하는 시각 투사 뉴런 |
| 종류별 상대 세기 | LC17 1.0 · LC12 0.94 · LPLC2 0.87 … LC11 0.31 | Turner et al. 2022(eLife) 칼슘 영상의 사구체별 최대 반응을 가장 큰 값으로 나눈 것 |
| `peak_hz` | 5 Hz | 상대 세기 1 일 때 발화율 — FLYCNS 가 선언한 값 그대로(**맞추지 않음**) |
| 시행 구조 | 쉼 300 ms → 폭발 60 ms → … | 시행마다 게인이 로그정규(σ 0.3687)로 흔들린다 |

### 2.2 채점 기준 — 다섯 항목

| 항목 | 기준 | 근거 |
|---|---|---|
| 반응당 발화 | 반응한 GF 하나당 **1~2 회** | 단일 GF 기록 |
| 반응 확률 | **0.5~1.0** | 다가옴 대부분이 문턱 근처 |
| 잠복 | 첫 GF 발화 **10~60 ms** | |
| 뇌 전체 조용함 | 자극받지 않은 뉴런 평균 **< 0.05 Hz** | 뇌 전체가 들끓으면 안 된다 |
| **섞은 배선 침묵** | 섞은 배선의 GF 반응 확률 **< 0.1** | 반사가 배선 덕인지 가른다 |

## 3. 맞추기 규칙 fit-v1 — 결과 보기 전에 적은 것

```python
FIT_RULE = {
    "version": "fit-v1",
    "w_scale_grid": [0.2, 0.25, 0.3, 0.35, 0.4, 0.5, 0.75, 1.0],
    "peak_hz": 5.0,
    "trials": 20,
    "pick": "실제 배선 네 항목(발화 1~2 · 반응 0.5~1 · 잠복 10~60 ms · 뇌 전체 < 0.05 Hz)을 "
            "모두 통과한 값 중 이어진 통과 구간의 가운데 값(둘이면 작은 쪽). "
            "고른 값은 40 시행 + 섞은 배선 대조로 확인 뒤 sim-v1 로 잠근다.",
}
```

명령: `uv run fly-connectome bench fit` (무거운 실행 · 가드 통과 뒤).

### 6.1 다음 — 회로 학습 1 단계 (R-7469 F-006 · `circuit_fit.py` · `f3f2e0a` · **아직 실행 안 함**)

`w_scale` 하나를 고른 이 장의 일을, **세포 종류 단위 매개변수 수십 개**로 넓히는 것이다(sim-v3 · [02장 3절](02-뇌-엔진-LIF.md)).

| 항목 | 내용 |
|---|---|
| 배우는 것 | 범위 `escape-small` — 다가옴 LC/LPLC 13 종 + DNp01 · 02 · 04 · 11 의 막 시간 상수 · 문턱 + 출력 쌍 10 개 α = **매개변수 44**(`config/fit.yaml` · 결과 전에 확정) |
| 방법 | **CMA-ES**(기울기 없음 · 정방향만 · Hansen 2016) — 로그 공간 θ · 처음 걸음 0.3 · 개체 수 4 + ⌊3 ln P⌋(= 15) · 세대 100 · 평가 한 번 = 다가옴 20 시행 |
| 손실 | **physiology-v1 도망 5 항목**(2.2 의 채점 기준 · 범위 안이면 0) + **λ‖θ − θ₀‖²**(λ 0.01 · 처음 값에서 멀어지지 않게) |
| 대조 | 평가마다 **같은 매개변수를 섞은 배선에도 넣어** 한 번 더 잰다(대조 항 · 섞은 배선은 거대섬유가 침묵해야 한다) |
| 명령 | 먼저 `uv run fly-connectome fit-probe --scope escape-small --trials 2,4`(평가 한 번의 시간 · 메모리를 시행 수 둘로 재어 무엇에 비례하는지) → 요구자 확인 → `uv run fly-connectome fit --scope escape-small --method cmaes`([11장](11-명령-모음과-용어.md)) |
| 무게 | 뇌 전체 LIF × 개체 수 × 세대 — 기록 없음(`fit-probe` 로 먼저 잰다) |
