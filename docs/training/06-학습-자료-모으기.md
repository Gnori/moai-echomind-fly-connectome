# 06. 학습 자료 모으기

> 2부 Qwen 연결 · 첫 장. 코드: `src/moai_echomind_fly/loop/{teacher,collect,episode}.py` · `datasets.py`.
> 형식 정본: [docs/datasets.md](../datasets.md) · 자료 카드 `data/datasets/fly-loop-v1/README.md`(git 밖).

## 1. 무엇을 모으나

투영기는 **"이런 뇌 활동이면 이런 상황 · 이런 행동"** 을 배운다. 그러려면 **(뇌 신호, 정답)** 짝이 필요하다.

| 짝의 한쪽 | 어디서 |
|---|---|
| 뇌 신호 | 04장의 채널 벡터 9개(31,950 차원) — **진짜 배선 · 섞은 배선 두 뇌 모두** |
| 정답 ① 캡션 | 세계 참값에서 코드가 만든 상황 설명 글 |
| 정답 ② 행동 | 세계 참값을 아는 **교사 규칙**이 낸 행동 JSON |

**정답은 사람이 쓰지 않는다.** 몸 시뮬레이터가 아는 참값(물체가 어디 있나 · 냄새 원이 어느 쪽인가)에서 코드가 만든다.

## 2. 교사 규칙 — `loop/teacher.py`

교사가 몸을 모는 동안 결정 창마다 기록한다. 규칙은 전부 코드에 선언돼 있고 자료 `meta.json` 의 `teacher_rules` 에 그대로 실린다.

### 2.1 행동 정답 (위에서부터 먼저 맞는 것)

| 조건 | 행동 |
|---|---|
| 다가오는 물체가 **다가오고** 각 크기 **≥ 20°**(위협) | 물체 **반대쪽**으로 돌며 달린다 `{"walk":1.0,"turn":"right","turn_strength":1.0,…}`(물체가 왼쪽이면 right) |
| 먹이까지 **≤ 2 mm** | 멈춘다 `{"walk":0.0,"stop":true,…}` |
| 냄새(두 더듬이 평균 ≥ 0.05)가 있고 방향이 **±15° 안** | 곧장 `{"walk":0.8,"turn":"none",…}` |
| 냄새가 있고 옆쪽 | 그쪽으로 `{"walk":0.6,"turn":"left","turn_strength":0.5,…}` — 세기 = min(1, 방위 절댓값 ÷ 90°) |
| 그 밖 | `{"walk":0.5,"turn":"none",…}` |

### 2.2 캡션 정답 — 고정 서식 한 줄

```
다가오는 물체: <없음 | 쪽 · 거리 · 움직임> / 먹이 냄새: <없음 | 쪽 · 세기> / 다리 접촉: N개 / 소리: 있음|없음 / 암컷 대용 물체: <없음 | 쪽>
```

| 칸 | 값 | 문턱(선언) |
|---|---|---|
| 쪽 | 앞 · 왼쪽 · 오른쪽 | ±15° 안이면 "앞" |
| 거리 | 가까움 · 중간 · 멀리 | 각 크기 ≥ 30° · ≥ 10° |
| 움직임 | 다가옴 · 머묾 | 확대 속도 > 0 |
| 냄새 세기 | 강함 · 약함 | 평균 농도 ≥ 0.5 · ≥ 0.05 |
| 소리 · 암컷 | 이번 과제에는 늘 "없음" | 자리만 있다 |

예: `다가오는 물체: 왼쪽 · 중간 · 다가옴 / 먹이 냄새: 오른쪽 · 강함 / 다리 접촉: 6개 / 소리: 없음 / 암컷 대용 물체: 없음`

> ⚠️ **교사 규칙이 곧 결과를 정한다.** 규칙이 쉬우면 무엇이든 배우기 쉽다. 그래서 **섞은 배선 벡터로 똑같이 학습한 대조군**과 나란히 잰다(09장).

## 3. 모으기 — `fly-connectome collect`

```bash
# 학습용: 씨앗 0~59 (60 에피소드)
uv run fly-connectome collect --name main --seeds 0-59 --workers 3 --threads 4
# 평가용: 씨앗 1000~1011 (12 에피소드) — 학습에 쓰지 않는다
uv run fly-connectome collect --name eval --seeds 1000-1011 --workers 3 --threads 4
```

| 옵션 | 뜻 |
|---|---|
| `--workers 3` | 씨앗을 세 조각으로 나눠 자식 프로세스 셋이 돈다(부모가 무거운 실행 잠금을 쥔다) → `runs/dataset-main-w0 … w2` |
| `--threads 4` | 일꾼마다 CPU 스레드 수 |
| `--graph traced-v1` · `--rewired-seed 0` | 두 뇌 = 진짜 배선 · 그 씨앗으로 섞은 배선 |

한 번 도는 동안 한 에피소드에서 일어나는 일:

1. 씨앗으로 과제를 뽑는다(냄새 원 위치 · 다가오는 물체 유무 · 시각 · 방향).
2. 몸을 초기화하고, 결정마다 **두 뇌에 같은 감각 입력**을 넣는다. 몸은 진짜 배선 뇌의 하강 뉴런을 따른다.
3. 창이 끝나면 두 뇌의 채널 특징 · 세계 참값 · 캡션 · 교사 행동을 한 줄로 남긴다(`DatasetWriter`).
4. 교사 행동이 다음 결정의 명령이 된다.

시간: 학습용 60 에피소드 약 25 분(일꾼 3). 가드: 평소 문턱(메모리 여유 40 %) · 가벼움.

## 4. 묶기 — 오래 둘 자리로

`runs/` 는 실행 기록을 쌓는 임시 자리다. 조각을 합쳐 **`data/datasets/<이름>/`** 에 묶는다.

```bash
uv run fly-connectome dataset pack --name fly-loop-v1 --train main --eval eval
uv run fly-connectome dataset verify fly-loop-v1      # 체크섬 대조 — "온전"
uv run fly-connectome dataset list
```

| 파일 | 내용 |
|---|---|
| `train/` · `eval/` `features-real.npz` · `features-rewired.npz` | 채널 이름 → float32 [결정 수, 차원] |
| `samples.jsonl` | 결정마다 `seed` · `decision` · `t_ms` · `truth` · `caption` · `teacher_action` · `reflex_bins` |
| `episodes.jsonl` | 에피소드마다 도착 · 시간 · 물체 · 부딪힘 |
| `meta.json` | 판 번호 · 코드 커밋 · 채널 단위 이름 · 감각 대응표 · 교사 규칙 |
| `README.md` · `SHA256SUMS` | 자료 카드 · 체크섬 |

같은 이름은 덮어쓰지 않는다(`pack` 이 거부). **설정 판이나 채널 표가 바뀌면 새 이름**으로 묶는다(`fly-loop-v2` …).

## 6. 이 자료의 한계 (10장의 원인과 이어진다)

- **표본이 적다** — 581 결정에 차원 31,950. 차원이 표본의 55 배다.
- **칸마다 답이 치우쳐 있다** — 예: 평가 자료에서 "물체 있음"의 최빈값이 0.667, "냄새 쪽"이 0.543. 찍기만 해도 이만큼 나온다.
- 소리 · 암컷 칸은 늘 "없음"이라 배울 것이 없다.
