> 세션 이름 `echomind-fly-research` — 요구자가 띄운 **가벼운 일 전용 세션**. 전체 진행과 남은 일 표는 조율 세션(`echomind-fly`)의 [인수인계](./echomind-fly-connectome-handoff.md).
> **이 파일에는 아직 안 끝난 것만 둔다**(요구자 10-18 *"이미 다 끝난건 없어져야지"* · *"정말 필요한것만"*). 끝나면 지우고, 기록은 보관 파일로.
> 끝난 기록(일 1~19 · 잰 값 · 남긴 파일 · 열린 질문 후보 · 틀린 것 · 커밋)은 [보관 파일 09-23 ~ 10-18](./archive/handoff/echomind-fly-research-handoff-20260923-20261018.md).
> 마지막 갱신 2026-10-18.

## 역할 · 경계

- **조율 세션이 보낸 일감만** 한다(요구자 09-28). 남은 일을 스스로 고르지 않는다.
- 한다: 문헌 조사 · 그래프 조회(수 초~수십 초) · 연구 노트와 HTML · 이 파일과 보관 파일.
  하지 않는다: 무거운 실행 · 코드 · 설정 · 그 밖의 `docs/requirements/` — 코드 고침이 필요하면 조율 세션에 먼저 알린다.
- 교신은 일감 한 번 · 결과 한 번(커밋 해시). 자기 파일만 경로를 하나씩 커밋 · Claude 트레일러 없이.
- 습관: 그래프 조회는 `uv run --no-sync` · 노트를 고치면 `uv run --no-project --with markdown==3.11.0 python docs/research/fly-connectome/build.py`(깨진 링크 0) ·
  확인 수준 기호 뒤에 괄호를 붙이지 않는다(쓴 뒤 `grep -n '](' 파일 | grep -v '\.md)'`) · 수치와 서지는 원문에서 확인한 것만 · 커밋 전 `git status` 로 내 파일만.
