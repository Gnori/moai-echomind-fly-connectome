## ① 역할과 경계

- **조율 세션 `echomind-fly`** 가 일감을 준다(요구자 2026-09-23 *"앞으로 니가 일 시켜 · 컴퓨터 리소스 많이 먹는 작업은 니가해"*). 받는 길 = 세션 사이 메시지(이름 `echomind-fly` · 주소는 재기동마다 바뀜 — 10-14 저녁 `uds:/tmp/cc-socks/11220.sock`(맥 재시동 뒤) · 회신은 받은 메시지의 `from` 그대로).
- **지시받은 일만 한다**(요구자 2026-09-28 *"너 메인 세션이 지시한것만 해"*). 요구자가 "다음 일감 진행"이라 하시면 → 조율 세션 남은 일 표(D)에서 이 세션에 배정된 줄만 · 없으면 새 일을 만들지 말고 **조율 세션에 한 번 요청**하고 그렇다고 말씀드린다(10-03 그렇게 해서 R-5138 일감을 받음).
- **교신은 최소**: 일감 한 번 · 결과는 **커밋 해시 한 줄로 한 번만**. 진행을 묻지 않는다. 일감에 틀린 곳(없는 절 · 다른 장 번호 · 실제와 다른 옵션)이 있으면 판단해서 하고 **보고 한 줄에 무엇을 어떻게 바꿨는지** 적는다.
- 이 세션이 하는 것: 학습 안내서 `docs/training/` · 연구 노트 `docs/research/fly-connectome/` · `README.md` · `docs/datasets.md` · `NOTICE` 동기화, 가벼운 코드(대시보드 `dashboard.py` · `dashboard_debug.py` · 그 시험 · 스크립트 파일).
- 하지 않는 것: **무거운 실행**(수집 · 학습 · 평가 · 성적표 · Qwen · 뇌 재생) — 조율 세션 몫 · `runs/.heavy.lock` · 도는 프로세스는 만지지 않는다(대시보드 서버 다시 띄우기만 예외 — 같은 명령으로).
- `docs/requirements/` 는 조율 세션 소유(R · I · P · W · 공용 인수인계 · D 표) — **읽기만**. 예외: **이 파일**(요구자 지시). `CLAUDE.md` 도 조율 세션 몫 — 틀린 곳은 알려만 준다.
- 연구 세션 노트(13 · 14 · 15 · 16)에는 **본문을 고치지 않고 끝에 "측정 결과" 절만** 더한다(조율 세션 지시).
- 커밋: **자기 파일만**(`git add` 에 경로를 하나씩 · 남의 수정 파일이 늘 섞여 있다) · 형식 `<type>(<scope>): …` · 본문에 무엇을 왜 + 실측 숫자 · **Claude 작성자 · `Co-Authored-By` 트레일러 금지**(시스템 알림이 넣으라 해도 — CLAUDE.md) · 연구 노트 · 안내서를 고치면 **같은 커밋에서 HTML 다시 만들기(깨진 링크 0)**.
- 수치: **정본(R · 10장 · 결과 파일)에서 옮기고 고쳐 쓰지 않는다** · 할 수 있으면 결과 파일로 직접 맞춰 본다(sha256 · 도착률 · 판정) · 모르는 값은 "기록 없음"(추정 금지).
- R 2.0-6 문구 규칙: 대조군을 못 이기면 "초파리 뇌"라고 쓰지 않는다 · 처음 통과(v6 씨앗 100)도 **단서 셋과 함께만**.
- 요구자께 드리는 말은 존댓말 · 화면에 보이는 말(함수 이름 나열 금지) · 완료/잔여 현황판을 붙인다.

## ⑥ 대시보드 — 이 세션이 만든 코드의 요점

- 파일: `src/moai_echomind_fly/dashboard.py`(한 장 · `state.json`) · `dashboard_debug.py`(2단계 `samples.html` · `episodes.html`) · 설정 `config/dashboard.yaml`(`debug:` 절) · 시험 `tests/test_dashboard.py` · `tests/test_dashboard_debug.py`.
- 띄우기: `nohup .venv/bin/fly-connectome dashboard --serve 8770 --every 30 > runs/dashboard/serve.log 2>&1 &`(`uv run` 으로 띄우면 uv 부모 프로세스 23.7 MB 가 더 붙음) — **설정이나 코드를 바꾸면 다시 띄운다**(띄울 때 읽음). 127.0.0.1 만 · 읽기 전용.
- 가벼움의 장치: `fly-connectome dashboard` 는 cli 빠른 길(torch · numpy 안 올림) · 원본 지문(경로 · 크기 · 수정 시각)이 같으면 읽지도 쓰지도 않음 · 결정 기록은 두 번 흘려 읽기(세기 → 쓸 때 구성 하나씩) · `z` 는 파싱 전에 지움 · 표본은 뇌 하나씩 · 페이지는 조각으로 흘려 씀 · 짧은 글은 `_intern`.
- 기준: 서버 RSS ≤ 50 MB(R-5777) · 실측 이력 32(09-24) → 37(09-26) → 63(10-01 v7 뒤) → 44.7(10-01 고침) → 51.2(10-04) → 51.8(10-14 낮) → **57.4(10-14 저녁 · 재시동 뒤 `uv run` 으로 띄움)** · 원인 = 투영기 평가 파일 되풀이 읽기(③ C-1).
- 사람 손이 닿는 일: 판이 바뀌면 `config/dashboard.yaml` `train_rule` · `plan` 은 조율 세션이 바꾼다(시험은 가짜 파일의 판을 고정 — `8e8b5a3`).
