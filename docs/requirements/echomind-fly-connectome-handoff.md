1. **초파리 회로 신호에는 과제 정보가 있고, 진짜 배선이 더 많다** — 선형 검사(8 칸 통과) · **캡션 판정(Qwen 을 거쳐도 물체 있음 · 다리 접촉은 진짜가 재배선 셋을 이김)**.

4. **평가는 서식이 아니라 값을 재야 한다** — 생성 평가는 서식을 잰다(v4: 값 맞히고도 0 점). 채점 평가(eval-v2.1)가 정본 · 판정 칸 넷(물체 있음 · 쪽 · 움직임 · 다리).
