  시험 세 걸음의 최대치(90 GB)만 보고 "평탄하다"고 여겼다. 걸음이 쌓이며 캐시가 불어나는 것은 **짧은 시험으로는 안 보인다.**
  → 긴 실행은 ① 수십 걸음 동안 메모리 추이를 먼저 재고 ② 실행 중에도 감시해 넘치면 저장하고 멈추게 하고 ③ 중간 점검 알림을 **처음부터 짧게**(수십 분) 건다.

- **(2026-09-22) 학습 한 걸음을 메모리 추정 없이 두 번 돌렸다 — 최대 약 90 GB.** 가드는 "실행 전 여유"만 보고 실행 중 최대치를 모른다.
  Qwen 역전파처럼 새 종류의 무거운 실행은 **먼저 작은 크기로 최대 메모리를 재고**, 규칙(여유 40 %)에 맞는지 확인한 뒤 돌린다.
- **(2026-09-22) "학습은 원래 90 GB" 로 받아들이고 요구자께 메모리 규칙을 풀어 달라고 했다.** `grad_checkpoint` 를 켜도 꺼도 90 GB 였는데
  그게 무엇에 비례하는지 재지 않았다. 재 보니 토큰 수에 정확히 비례했고(0.32 GB/토큰) 층별 역전파로 32 GB 가 됐다.
  → 숫자가 커 보이면 **규칙을 풀어 달라기 전에 무엇에 비례하는지부터** 잰다(길이 두 개면 충분하다).
- **(2026-09-22) 채널 벡터에 직접 자극한 뉴런을 넣었다** — Qwen 이 우리 입력을 되읽는 지름길이었다. pilot 에서 찾아 뺐다(R 1.3-9).
- **(2026-09-22) 여러 곳을 한 스크립트로 바꾸다 한 줄이 어긋나 일부만 바뀐 채 커밋했다**(`0b61e46a` 메시지가 내용보다 많음) → 바로잡는 커밋을 따로 했다. 바꿈 검사가 전부 통과한 뒤에만 커밋한다.

- **(2026-09-21) 연구 노트 설계를 바꾸면서 "바뀐 점"에 적지 않았다.** 06 은 §3.2 소프트 프롬프트(회로 벡터 → Qwen 임베딩)와
  §6.2 MLX 가중치 실행을 설계해 두었는데, R 초판에서 소프트 프롬프트를 "선택"이라며 빼고 LLM 을 Ollama API 로 바꿨다.
  요구자가 *"정리해 둔 문서가 그렇게 설계되어 있지 않았어?"* 로 짚었다. → 원문과 다르게 잡는 것은 **전부** R 1.3 표에 올린다.

  청각 → GF 는 **문턱 아래**가 정답. 도망 채점 기준(GF 반응 확률 0.5~1.0 · 발화 1~2 · 잠복 10~60 ms · 뇌 전체 < 0.05 Hz · 섞은 배선 < 0.1)은

- **Ollama**: `qwen3.8:27b-mlx`(18 GB) 설치돼 있음. 라이브 에이전트 7개는 전부 클라우드 모델(2026-09-21 기준) — 그래도 Qwen 을 올리기 전에 `ollama ps` 를 확인한다.
- **맥**: M5 Max · 128 GB · 디스크 여유 717 GB.
- **파이썬 3.14 지원**: flygym 2.1.0 · torch 2.14.0 · mujoco 3.13.0 · brian2 2.10.1 · pyarrow 25.0.1.
- **공식 파일 크기**: annotations 14,483,314 B · neurotransmitters 43,282,834 B · weights 1,051,241,946 B. 무결성 = GCS 공식 MD5(`config/sources.yaml`).
- **Brian2(=Shiu 기준 구현)는 불응 중 도착한 시냅스 입력을 버린다** — `(unless refractory)` 가 조건부 쓰기(`set_conditional_write`)라서. 우리 엔진도 그렇게 한다(이걸 빼면 대조가 갈린다).
- **sim-v1 = w_scale 0.25**(fit-v1 규칙 — `bench/escape.py FIT_RULE`) · loom-v1 = peak 5 Hz. 다시 맞추지 말 것 — 바꾸려면 규칙 판을 올린다.
- **속도**: 뇌 전체 1,000 ms = CPU 4.3 s · MPS 9.0 s(결과 비트 단위 같음) → 기본 CPU. 도망 채점 40 시행 = 한 쪽 약 106 s.
- **광수용체 자극은 아무 데도 안 퍼진다**(발화 0) · **청각 115개 150 Hz 는 GF 를 발화시킨다**(생체는 문턱 아래 — 혼합 시냅스를 화학으로만 둔 탓 · JO→GF 27 연결).
- **MCP SDK 는 2.x**(`MCPServer` · 결과 필드 `is_error` · `structured_content` · `Tool.input_schema`) — 1.x 이름(`FastMCP` · `isError`)으로 쓰면 안 된다.
- **stdio MCP 서버에서는 표준 출력에 아무것도 찍지 않는다**(프로토콜 통로) — 로그는 표준 에러.
- **Qwen 직접 로드**: 8.1 s · 28.6 GB · 해독 약 10 tok/s · 입력 읽기 약 400 tok/s · 도구 호출 형식은 `<tool_call><function=…><parameter=…>`(JSON 아님).
- **소프트 토큰 자리 = `<|vision_pad|>`(248055)** — Qwen 이 원래 이미지 임베딩을 끼우는 자리. 선형 어텐션 층은 `model.train()` 이면 미분 가능한 경로.

- **몸 물리는 느리다**: 모의 100 ms = 벽시계 약 1.6 s(실시간의 1/16). 결정 하나(뇌 둘 포함) ≈ 7.5 s.
