## 1. 요구사항 분석

### 1.1 문제 정의

**As-Is (R-3340 C 단계 결과 · 2026-09-23)**:
- 초파리 회로는 **학습하지 않는다**(배선 고정 · 전역 `w_scale` 하나). 학습하는 것은 투영기(3,187만 매개변수)뿐, Qwen 은 얼림.
- 성적표: 진짜 배선 `vector` 0.2 = 섞은 배선 `rewired` 0.2(먹이 도착) → R 2.0-6 문구 규칙 발동("초파리 뇌"라고 쓰지 않는다).
- 캡션 평가: 네 저장본 모두 찍기 수준 · 두 뇌 구별 안 됨 · 섞은 배선의 손실이 오히려 낮다.
- 선형 검사(Qwen 없이): 9 채널 한꺼번에는 찍기 수준 · **채널별로는 진짜 배선이 높다**(시각 네 칸 · 몸 → 다리).
- 이번에 잰 것(`runs/why-analysis-20260923.json`):
  시각 · 몸 채널을 **64 차원으로 줄여도 차이가 남는다**(시각 → 물체 쪽 0.705 / 0.571 · 몸 → 다리 0.600 / 0.448) ·
  후각 투사 뉴런의 **좌우 차로는 냄새 쪽을 못 맞힌다**(0.48~0.50 · 찍기) · 운동 채널의 교사 명령 누설은 약하다(0.610 · 찍기 0.590).
- 판정의 힘이 약하다: 대조군이 섞은 배선 **하나** · 평가 105 결정(오차 약 ±10 %p [18]) · 성적표 씨앗 10 · 채널 × 칸 54 쌍 다중 비교.

**해결하고자 하는 문제**:
1. **초파리 신호가 Qwen 에 전달되는지**를 가를 수 있게 만든다(전달 방식 · 손실 · 자료 양).
2. **판정을 믿을 수 있게** 만든다(대조군 앙상블 · 통계).
3. 투영기로는 못 고치는 **감각 쪽 결함**(냄새 좌우)을 1부에서 고친다.
4. 그다음 **초파리 회로 자체가 배우는** 단계(세포 유형 단위 · 버섯체 가소성)로 간다.

### 1.2 목표

- 진짜 배선이 **재배선 앙상블**보다 캡션 칸 정확도(보정된 유의)와 먹이 도착에서 앞서는지 **판정 가능한** 실험을 만든다 — 앞서면 "초파리 배선 벡터가 섞은 배선보다 나았다"를 쓸 수 있고, 못 앞서면 그렇게 쓴다(R 2.0-6 유지).
- 초파리 회로가 **커넥톰 정체성을 지킨 채** 배우는 첫 판(세포 유형 단위)을 만든다.

### 1.3 제약 조건

- **Qwen 은 계속 얼린다**(파인튜닝 아님 · 가중치 지문 확인 유지).
- **커넥톰 정체성**: 연결 하나하나의 가중치는 학습하지 않는다(유형 단위 매개변수만 · [20]). 바꾸는 매개변수는 판 번호로 잠근다.
- **무거운 실행 규약**(CLAUDE.md · `config/guard.yaml`): 새 종류의 무거운 실행은 **작게 먼저 재고 무엇에 비례하는지** 본다 · 요구자 확인 뒤 · 한 번에 하나 · 실행 중 감시 · 수십 분 간격 확인.
- **대조군은 모든 학습에 똑같이**: 진짜 배선에 한 학습은 재배선에도 같은 절차 · 같은 씨앗으로.
- 기존 결과 보존: `fly-loop-v1` · `projector-*-train-v2` 는 그대로(새 판은 새 이름) · 학습 · 평가 뒤 `fly-connectome backup`.
- 라이선스 없는 저장소 코드 복사 금지(DOOMFLY 등) · 규칙은 원 출처와 함께 인용.

### 2.2 기능 상세 및 인수 기준

#### F-001: 판정 기준 강화

- **왜**: 대조군이 섞은 배선 **하나**라 우연히 약한/강한 재배선을 골랐을 수 있다 — 재배선은 앙상블로 비교하는 것이 기준이다 [19].
  평가 105 결정은 오차가 약 ±10 %p [18] · 결정들이 몇 에피소드에 몰려 독립이 아니다 · 54 쌍 비교는 우연한 "앞섬"이 섞인다(실제로 청각 → 물체 있음은 섞은 배선이 0.790 으로 높았다).
- **어떻게**: 차수 보존 재배선 씨앗 N 개(기본 20 · 선형 검사용) · 채널별 선형 검사를 앙상블 전부에 · **에피소드 단위 블록 순열** p 값 · Holm 보정(채널 × 칸) · 부트스트랩 95 % 구간.
  캡션 평가 · 성적표에도 같은 통계를 붙인다(투영기 학습은 비싸므로 재배선 투영기는 최소 3 개).
- **대조군 · 성공 기준**: 이 기능 자체가 기준이다. 진짜 배선이 "앞선다"의 정의 = **재배선 앙상블 분포의 상위 5 % 이고 보정 후 p < 0.05**.
- **인수 기준**:
  - [x] `fly-connectome graph --rewired-seeds 0-19` 로 N 개 재배선을 만들 수 있고 각 그래프 메타에 씨앗 · 규칙이 남는다
  - [x] 선형 검사 결과 파일에 채널 × 칸마다 진짜 값 · 앙상블 분포(평균 · 5/95 % 구간) · 블록 순열 p · Holm 보정 p 가 남는다

- **왜**: LLM 연결에 성공한 문헌 사례는 최소 **수천 개** 규모다 [5][7] · 581 개로는 투영기 학습도 판정도 약하다 ·
  "0.74 대 0.59"를 두 집단으로 가르려면 집단당 약 150 개가 든다(추정 · 연구 노트 12 §5) · 먹이 도착 차이를 보려면 조건당 약 40 회.

#### F-003: 감각 입출력 결함 고치기 (1부)

#### F-004: 채널별 압축 + 선형 관문

- **왜**: 3.2 만 차원을 통째로 넣으면 선형 검사도 찍기 수준이 된다 · 채널별로 **64 차원까지 줄여도 진짜 배선이 앞선다**(연구 노트 12 §1.1 ①) ·

- **어떻게**: 채널마다 PCA 와 PLS 를 **학습 자료로만** 맞춘다(k ∈ {16, 32, 64} 중 규칙으로 고름 — 결과 보기 전에 적는다) · 압축기는 판 번호와 함께 저장 ·

#### F-005: 작은 투영기 + 칸 토큰 손실 (규칙 판 `train-v4`)

- **왜**: 투영기 3,187만 대 표본 581 — 재료보다 다리가 너무 크다 · 인코더 표현이 좋으면 **선형 사상 하나로도** 된다 [4] ·
  캡션 틀 글자는 입력과 무관한 상수라 그 손실은 신호 학습에 기여하지 않고 손실값만 낮춘다 — "서식은 완벽 · 칸은 틀림"과 "섞은 배선 손실이 더 낮음"이 이것으로 설명된다 [2].
- **어떻게**: 입력 = F-004 압축 벡터(관문 통과 채널만) · 채널당 **선형 k → 5,120 토큰 1 개** · 손실 = **칸 토큰에만**(캡션 · 행동 둘 다 · 틀 토큰은 가림) ·

- **무게**: 무거움. 입력 토큰이 줄어(자리 18 → 통과 채널 수) 걸음당 메모리는 지금(32 GB) 이하로 예상 — **train-probe 로 먼저 잰다**. 뇌 4 개 학습 + 캡션 평가 + 성적표(씨앗 40 × 구성) — 시간은 측정 뒤 산정해 요구자 확인.
- **대조군 · 성공 기준**: 캡션 칸 정확도가 **찍기를 넘고 재배선 투영기들보다 앞선다**(F-001 기준) · 성적표 먹이 도착이 재배선 앙상블보다 높다(구간 겹치지 않음). 못 앞서면 R 2.0-6 그대로.
- **인수 기준**:
  - [ ] 손실 가림 시험(틀 토큰에 기울기 0 · 칸 토큰에만)
  - [ ] train-probe 측정 기록(걸음당 시간 · 최대 메모리)
  - [ ] 네 투영기의 `meta.json`(규칙 · 압축기 · 자료 · Qwen 지문 같음)
  - [ ] 캡션 평가 · 성적표(F-001 통계 포함) · 문구 규칙 결과 기록 · 백업

#### F-006: 세포 유형 단위 회로 학습 (1부)

- **왜**: 연결 하나하나를 학습하면 "초파리 배선"이 아니게 된다. **세포 유형별 매개변수 수백~수천 개만** 배우는 것이 커넥톰 정체성을 지키는 표준 해법이다 —
  Lappalainen 2024 는 시냅스 수 · 부호를 고정하고 734 개만 배워 초파리 시각 회로의 알려진 반응을 재현했다 [20][21].
  단, 커넥톰만으로는 동역학이 정해지지 않고(퇴화) 과제 성능만으로 맞추면 생물학적 해가 보장되지 않는다 [23] → **알려진 생리(도망 반사 등)를 목표에 함께** 넣는다.
- **어떻게**(2026-09-23 조사 뒤 확정 — [연구 노트 13 §2](../research/fly-connectome/13-회로-학습-설계-조사.md) · [I v2 §7](./20260923-104151-7469_fly-learning-next_interface-design.md)): 학습 매개변수 = 종류별 막 시간 상수 · 문턱(이득은 퇴화라 두지 않음) · 종류 쌍 배율(α ≥ 0 · 부호 못 뒤집음) — scope 로 잠금(`escape-small` ≤ 50 → `space` 125 → `escape` 2,125 · 뇌 전체 18 만은 하지 않음) ·
  **1단계 기울기 없음(CMA-ES · P ≤ 50 · 정방향만)** → **2단계 희소 대리 기울기 + 잘림 BPTT + √T 체크포인트**(기울기는 scope 뉴런에만) → 막히면 온라인 흔적 · 속도 근사는 이식 검증 뒤에만 ·
  목표 = 생리 제약 `physiology-v1`(도망 5 항목 · Turner 조율 · EPG 봉우리 82° · KC 5~10 % …) + 관문 칸 해독 + 초기값 규제 · 씨앗 앙상블 5~10 · **`fit-probe` 로 창 두 길이 메모리 · 시간을 재고 무엇에 비례하는지 확인 뒤 요구자 확인.**
- **대조군 · 성공 기준**: **같은 학습을 재배선 그래프에도 똑같이** · 학습 뒤에도 진짜 > 재배선 앙상블(F-001) · 도망 반사 통과 유지. 과제 성능만 오르고 재배선도 똑같이 오르면 실패로 기록.
- **인수 기준**:
  - [ ] 학습 매개변수 목록 · 개수 · 판 번호(`sim-v2` 계열) · 연결 가중치 불변 확인
  - [ ] 작은 측정 기록(부분 그래프 · 메모리 비례 관계)
  - [ ] 진짜 · 재배선 학습 결과 표 · 도망 반사 재채점

#### F-008: 3차원 공간 (1부 → 2부)

- **왜**: 지금 세계는 평평한 바닥이고 물체에는 **고도가 없다**(방위 · 크기 · 확대 속도만) · 시각 입구는 LC/LPLC 를 **좌우 두 덩어리**로만 켠다 — 입력에 3차원이 없으면 무엇을 배워도 3차원이 아니다.

  알려진 실패 사례(DOOMFLY — 학습 입증 실패)가 있어 **대조군을 설계에 먼저** 넣는다.
- **어떻게**(2026-09-23 조사 뒤 확정 — [연구 노트 13 §3](../research/fly-connectome/13-회로-학습-설계-조사.md) · [I v2 §8](./20260923-104151-7469_fly-learning-next_interface-design.md)): KC → MBON **61,210 연결**(그래프 실측)의 배율 m ∈ [0.1, 1] 만 · 규칙 `plasticity-v1` = KC 흔적(τ 5 s 선언) × 구획 DAN 신호(τ 0.2~0.5 s) 곱셈형 약화(앞 짝짓기만) · 구획은 "MBON 에 시냅스 최다 DAN 종류"로 자료에서(문헌 명명법과 일치) · η 는 Hige 2015 감소폭(50~90 %)으로 보정 · DAN 은 세계 사건(먹이 도착 → PAM 보상 · 부딪힘 → PPL1 처벌)으로 직접 자극 · `task-v3`(냄새 둘 CS+/CS−) · 1차 기준 = `value` 채널 CS+/CS− 선형 해독 · **먼저 잰다**(KC 발화 비율 5~10 % · MBON 반응 · DAN 효과 · η).
- **대조군 · 성공 기준**: ① 가소성 끔 ② **무작위 보상** ③ 재배선 — **PN → KC 를 섞는다**(KC → MBON 만 섞는 것은 약함) ④ DAN ↔ 구획 바꿔치기(정서가 뒤집혀야 규칙이 구획을 쓰는 증거) ⑤ 학습 전 — 학습 뒤 CS+/CS− 해독이 찍기를 넘고 ①②③ 모두보다 높고(stats-v2) ④ 에서 뒤집히면 "배웠다". 행동(하강 뉴런)은 경로가 살아 있을 때만 2차.
