## 1. 요구사항 분석

### 1.1 문제 정의

**현재(As-Is — 코드 기준 사실)**
- 결정(모의 300 ms)마다 **무조건** Qwen 을 부른다(`loop/episode.py` · 성적표 모든 구성). Qwen 한 번 = 벽시계 약 2.5~5 s(v6 성적표 `latency_s_mean`).
  모의 시간은 Qwen 이 생각하는 동안 멈춰 있어 **실험 결과에는 영향이 없지만 실시간이면 쓸 수 없는 속도**다.
- 초파리 회로가 스스로 처리하는 것(빠른 길)은 **거대섬유(DNp01) 도망 반사 하나**뿐(`decoder.drive` — 발화하면 그 구간 반사 우선) + 걷기 리듬(몸 제어기).
- 회로만으로는 먹이 쪽으로 돌지 못한다 — 조향 하강 뉴런 DNa02 가 침묵(R-7469 M1 · 150 Hz 에도 0 Hz) · 성적표 `no_llm` 먹이 도착 0.
- 설계(연구 노트 06 §4~5)는 "회로는 밀리초 단위로 계속 · 언어 모델은 수 초에 한 번 느린 판단만 · 반사가 먼저"였다 — 구현이 비교 실험을 공정히 하려고 이를 단순화한 채 남았다.

**해결할 문제**: 깊은 생각이 필요 없는 결정까지 LLM 에 보내 느리고, 초파리 뇌를 "앞단 처리기"로 충분히 쓰지 못한다.

### 1.2 목표(To-Be)

| 층 | 무엇 | 누가 | 시간 |
|---|---|---|---|
| **1 반사** | 즉시 · 생각 없이(도망 · 부딪힘 직전 멈춤 · 먹이 닿으면 멈춤) | 초파리 회로(+ 규칙) | 수~수십 ms |
| **2 익숙한 행동** | 가볍게 계속(냄새 쪽으로 걷기 · 방향 유지) | **초파리 신호 → 작은 빠른 읽기 장치**(지금은 조향 경로가 침묵이라 회로 대신 이것 · F-006 회로 학습 뒤 회로로 옮김) | 수 ms(선형) |
| **3 깊은 판단** | 필요할 때만(충돌 · 새 상황 · 애매함 · 목표 변화) | **Qwen**(투영기로 초파리 신호를 받음) | 수 초 |

LLM 은 **사건이 있을 때만** 부르고, 그 사이에는 마지막 판단을 유지한 채 1 · 2 층이 몸을 몬다.

### 1.3 제약 조건

- **구도 유지**: 초파리 회로 = 앞(인코더) · LLM = 뒤(생성기). 층 구조는 그 사이에 **언제 넘길지**를 더하는 것이지 LLM 을 빼는 것이 아니다.
- **정직 규칙**: 진짜 배선과 재배선에 **같은 층 구조**를 씌워 나란히 판정(R 2.0-6 그대로). 호출 조건 · 문턱은 **결과 전에** 설정 파일에 적는다.
- 값 · 문턱은 `config/control.yaml`(하드코딩 금지) · 무거운 실행은 요구자 확인 뒤 · 한 번에 하나.
- A(train-v7 성적표) · B(v6 성적표 씨앗 100)가 끝난 뒤 착수(요구자 순서 · 조율 세션 권고: C 보다 먼저).

### 2.2 기능 상세 및 인수 기준

- **인수 기준**:
  - [ ] 결정마다 어느 층이 행동을 정했는지(`tier` · `trigger`)가 결정 기록(scorecard-v3 decisions.jsonl)에 남는다
  - [ ] 게이트를 "늘 부름"으로 두면 지금 성적표와 **같은 결과**(회귀 시험 · 같은 씨앗)

#### F-002: 2층 빠른 정책
- **왜**: 조향 뉴런이 침묵해 회로 혼자 돌 수 없다 — 그 사이를 LLM 없이 메울 가장 가벼운 장치. 냄새 쪽은 이미 선형으로 읽힌다(R-7469 M4 · LN4 0.725).
- **어떻게**: 자료 fly-loop-v4 학습 나눔으로 압축 특징(시각 · smell_ln · 공간 · 필요하면 여러 창 누적) → 교사 행동(돌기 방향 · 걷기)을 능선 회귀로 · 출력에 확신도(여유 폭). 진짜 · 재배선 각각 따로 학습(같은 절차).
- **인수 기준**:
  - [x] 평가 나눔에서 교사 돌기 방향 일치율 · 확신도 보정 곡선 기록(진짜 대 재배선 셋) — **2026-10-01 fast-v1 · fly-loop-v4 평가 1,708**:
        돌기 진짜 **0.676** · 재배선 0.583/0.573/0.586 · 찍기 0.434 | 위험 진짜 **0.966** · 재배선 0.935/0.933/0.935 · 찍기 0.935 | 멈춤 0.964 · 0.954~0.958 · 찍기 0.902
        (`runs/fast-policy-fly-loop-v4-<뇌>-fast-v1/report.json` · 확신도 구간별 정확도 · 놀람 분위수는 meta)
  - [x] 결정 하나 추론 시간 < 5 ms(CPU) 실측 — **0.005 ms**(네 뇌 맞추기 3.2 s · 0.7 GB)

#### F-003: 호출 조건(사건)
- **어떻게(초안 · 문턱은 G1 뒤 설정에 적고 결과 전에 잠금)**:
  - **놀람**: 압축 특징의 직전 결정 대비 변화량이 학습 나눔 상위 q% 를 넘음(새 물체 · 냄새 사라짐)
  - **충돌**: 2층이 "위험 회피"와 "먹이 쪽"을 동시에 강하게 가리킴(시각 · 냄새 채널 불일치)
  - **애매함**: 2층 확신도 < 문턱
  - **시간 상한**: 마지막 호출 뒤 N 결정(예: 10 = 3 s)이 지남
  - **목표 변화**: 새 지시 · 과제 시작(첫 결정)
- **인수 기준**:
  - [ ] 조건마다 몇 번 불렸는지 · 그때 LLM 이 2층과 다른 행동을 냈는지(쓸모 있는 호출 비율) 기록
  - [ ] 문턱이 결과 전 커밋에 있다

#### F-004: 성적표 확장
- **새 구성**: `vector-gated`(진짜 · 층 구조) · `rewired-sK-gated` · `fast-only`(2층만 · LLM 없음) · 기존 `vector`(늘 부름)는 기준.
- **성공 기준(결과 전에 정함 · 초안)**:
  - (a) `vector-gated` 의 호출 비율 ≤ **30 %**(결정의) 이면서 먹이 도착 · 회피가 `vector`(늘 부름)보다 95 % 구간을 넘게 떨어지지 않음
  - (b) `vector-gated` 가 `rewired-sK-gated` 셋보다 높음(scorecard-v2 · 씨앗별 부호 뒤집기 p < 0.05) — 못 넘으면 R 2.0-6 그대로
  - (c) 벽시계 추정(호출 수 × 지연 + 결정 수 × 빠른 정책 시간)이 늘 부름의 1/3 이하
- **인수 기준**: [ ] 위 세 줄이 성적표 JSON · 대시보드 에피소드 쪽에 나온다

#### F-005: 1층 반사 늘리기
- 먹이 거리 ≤ 도착 문턱이면 멈춤 · 다가오는 물체 각 크기 ≥ 문턱이면 반대쪽 회피 — 지금은 교사 규칙에만 있는 것을 **회로 신호(시각 · 미각 채널)** 에서 읽는 규칙으로. 회로에 해당 신호가 없으면 "없음"을 기록하고 넘긴다.
- [ ] 반사로 처리된 결정 수 · 그중 틀린 반사(교사와 다름) 비율
