## 0. 한 장 요약

```
 세계(3D 공간 · 물리) ──물리 신호──▶ 감각기 모형 ──수용체 값──▶ 앞단(선언 모형) ──발화율──▶ 입구 뉴런 ──▶ 연결 지도(LIF) ──▶ 하강 뉴런 ──▶ 몸
   빛 · 냄새 분자 · 공기 떨림 ·        겹눈 · 더듬이 ·          (우리 LIF 가 못 돌리는       (우리 LIF 에서 진짜 배선을
   닿음 · 맛 · 온도 · 습도             존스턴 기관 · 털 · 맛털     앞층의 계산을 대신)          타는 가장 앞 층)
```

- **뇌에 넣는 것은 언제나 "입구 뉴런의 발화율(포아송 스파이크)"** 하나뿐이다. 좌표 · 거리 · 물체 이름 · 종류는 넣지 않는다(정답 기록용).
- **입구 층은 감각마다 재서 정한다** — 우리 LIF 에서 신호가 진짜 배선을 타고 행동 쪽으로 가는 가장 앞 층(시각은 T4/T5 · 10-16 [잼]).
- 그 앞 층들의 계산은 **선언 모형(앞단)** 이 대신한다 · 판 이름 · 결과 전 잠금 · 문구에 "앞단은 우리 계산"이라고 쓴다.
- 판정은 늘 **섞은 배선(전체 · 부분) · 뒤섞은 지도 · 뇌 없음**과 나란히.

### 2.4 시간 — 한 걸음씩(lockstep)

| 값 | 기본[선언] | 까닭 |
|---|---|---|
| 세계 · 그림 간격 `frame_ms` | 10 ms(100 Hz) | 초파리 움직임 감지의 시간 상수 수십 ms [문헌] · V1 에서 5 · 10 · 20 ms 비용 재기 |
| 뇌 창 | `frame_ms` 마다 `set_rates` → `run(frame_ms)` | 엔진은 이어 달리기 지원(`Engine.run` · 시각 유지) [잼] |
| 행동 결정 창 | 100 ms(10 걸음) — 지금 디코더 구간과 같음 | 디코더 · 반사 규칙을 그대로 씀 |
| 실시간 배율 | 재기 전 모름 · 뇌만 1 s = CPU 4.3 s [잼] | 한 걸음씩이라 느려도 결과는 같음 |

한 걸음 순서: ① 몸 명령 적용 → 세계 `dt` 진행(운동학 · 충돌 · 장) ② 자세 묶음 → 렌더러 → 눈 그림 ③ 감각마다 수용체 값 → 앞단 → 입구 발화율 ④ 주입(`set_rates`) → 뇌 `run(dt)` ⑤ 결정 창이 차면 디코더 → 다음 몸 명령 ⑥ 기록.

### 2.5 공통 계약 — 감각 하나를 끼우는 꼴

```python
class Sense(Protocol):                     # 감각마다 하나 · 판 이름을 가짐
    name: str                              # "vision" | "smell" | "sound" | "touch" | "taste" | "thermo" | "hygro"
    version: str                           # 예: "vision-frontend-v1"
    def entry(self, g: Graph) -> EntryMap  # 입구 뉴런 인덱스(연결 지도에서 · 종류 · 좌우 · 자리)
    def needs(self) -> set[str]            # 세계에 바라는 것: {"render.cube"} · {"field.odor"} · {"contacts"} …
    def step(self, obs: WorldObs, t_ms: float) -> np.ndarray   # 입구 뉴런마다 발화율 Hz(길이 = len(entry))
    def reset(self, seed: int) -> None
```

- `Injector` 가 모든 감각의 `entry` 를 합쳐 한 번 `set_poisson` · 걸음마다 `set_rates`(감각끼리 같은 뉴런이 겹치면 시작 때 거부).
- `WorldObs` = 그 감각이 바란 것만(그림 · 장 값 · 닿음 목록) — **정답 칸(좌표 · 거리 · 종류)은 넣지 않는다**(시험으로 막음).
- 상한 · 문턱 · 이득은 설정 파일(하드코딩 금지).

### 2.6 렌더러 통로(P1 ↔ P2)

- WebSocket(127.0.0.1 · `config/eyeworld.yaml render.ws_port`) · 메시지 = `[u32 머리 길이][머리 JSON(UTF-8)][본문 바이너리]`.

| 방향 | 종류 | 머리 칸 | 본문 |
|---|---|---|---|
| P2 → P1 | `ready` | `babylon`(예 "9.25.0") · `backend`(webgpu · webgl2) · `gpu` · `max_texture` | — |
| P1 → P2 | `scene.load` | `scene_id` · `items[{asset, pos, quat, scale}]` · `sky` · `ground` · `light` · `seed` | — |
| P2 → P1 | `scene.ready` | `loaded` · `missing[]` · `ms` | — |
| P1 → P2 | `render` | `tick` · `poses[{id, pos, quat, anim{clip, t}}]` · `eyes[{agent, side, pos, quat}]` · `face_px` · `channels`(["lum"] 또는 ["lum","depth"]) | — |
| P2 → P1 | `frames` | `tick` · `eyes` 순서 · `face_px` · `layout`("cube6": +x −x +y −y +z −z) · `dtype`(u8 밝기 · f32 깊이 m) · `render_ms` · `read_ms` | 눈 × 6 × face² × 채널 |
| 둘 다 | `error` | `code` · `msg` | — |

- 에러: 렌더 시간 초과(`render.timeout_ms`) → 한 번 다시 요청 → 렌더러 다시 띄우기 → 두 번 실패면 저장하고 멈춤(끝 코드 3).
- 밝기 = 초록 쪽 가중(R1-R6 의 흡수 봉우리 · [문헌]) 회색 · 깊이는 정답 기록용(뇌 입력 아님).

### 2.7 데이터 모형(세계)

| 칸 | 내용 |
|---|---|
| `Entity` | `id` · `kind`(agent · person · animal · prop) · `asset`(에셋 목록 키) · `pos`(m) · `yaw`/`quat` · `vel` · `collider`(원기둥 r · h / 상자) · `solid` · `anim{clip, t}` · `emit{odor[], sound[], taste, temp}`(나중) |

### 3.2 겹눈 기하(`eye-v1`)

- 낱눈 = 연결 지도 기둥(L1 공식 좌표 `assignedOlHex1/2` · 왼눈 875 · 오른눈 892 [그래프]).
- 방향: retino-v2 규약 그대로 — `h = hex1 − hex2`(앞 +) · `v = hex1 + hex2`(위 +) · 오른눈 h 범위 → 방위 [−170°, +10°] · 왼눈 거울 · v 범위 → 고도 [−70°, +90°] — **선형 근사 선언**(실제 눈 지도는 정면 쪽이 촘촘 · 연구 노트 13 §4).
- 받아들이는 각: 가우시안 반높이 폭 약 5° [문헌 · 선언] · 낱눈마다 큐브맵 픽셀 무게(희소 행렬 · 시작 때 한 번).
- 머리 위 자리: 사람 몸 NPC 의 머리(눈높이 = 키 × 0.936 · 에코월드 값) · 두 눈은 **옆을 향한 초파리식**(사람 눈처럼 앞으로 모으지 않음 · 선언).
- 시험: 알려진 방향의 점 → 맞는 기둥 · 눈마다 기둥 수 = L1 기둥 수 · 같은 그림 → 비트 같음.

### 3.3 시각 앞단(`vision-frontend-v1` · 선언 · 결과 전 잠금)

1. 낱눈 밝기 `x_i(t)` → 시간 고역(`τ_hp`) → ON = max(·, 0) · OFF = max(−·, 0).
2. 이웃 기둥 쌍(육각: 가로 Δh = ±2 · 세로는 대각 둘 평균)마다 지연 곱 국소 움직임: `m = LP(A)·B − A·LP(B)`(`τ_lp`) → 네 방향 → 양의 부분만.
3. 발화율 = `r_max · tanh(k · m)` · T4x ← ON · T5x ← OFF.
4. T4/T5 뉴런 → 기둥: 공식 좌표가 없으므로 **입력 기둥 가중 평균**(retino 모듈 두 단계) → 가장 가까운 기둥.
- `τ_hp` · `τ_lp` · `k` · `r_max` 는 문헌 값으로(research 일감 10-16) · 시험: 줄무늬를 한 방향으로 움직이면 그 방향 T4/T5 만.
- ⚠️ 라미나 · 수질(약 3 만 뉴런)의 계산을 우리 식이 대신한다 — "초파리 눈 전체로 본다"는 쓰지 않는다.
