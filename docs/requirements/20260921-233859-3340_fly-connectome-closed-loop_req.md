### 1.3 ⚠️ 연구 노트와 달라지는 점 — G1 에서 함께 승인받는다

1. **시각 입구는 광수용체가 아니라 시각 투사 뉴런(LC · LPLC)이다.**
   FLYCNS 가 측정했다: ON 시각 경로는 **이중 반전**이다(빛 → 광수용체 탈분극 → 히스타민이 L1 억제 → L1 의 글루탐산 감소 → Mi1 이 풀림).
   쉬는 상태가 침묵인 LIF 는 "억제를 푸는" 경로를 표현하지 못한다(연구 노트 09 §4 의 먹기 회로와 같은 부류).
   그래서 06 §2.2 의 "낱눈 → 광수용체 발화" 경로는 **퍼지지 않을 것으로 예상된다.**
   → 기본은 F1 모나코·FLYCNS 가 쓴 방식이다. 계산한 시각 특징(방위 · 각 크기 · 확대 속도)을 LC/LPLC 종류별 발화율로 넣는다.
   광수용체 경로는 A 단계에서 **한 번 재서 결과를 기록**만 한다(F-005).
2. **청각 → 거대섬유의 정답은 "발화"가 아니라 "문턱 아래 탈분극"이다.** 생체 기록이 그렇고, FLYCNS 도 그렇게 채점했다.
   연구 노트 10 의 *"도망·청각은 재현(1~2 회 발화, 10~60 ms 지연…)"* 은 두 결과를 섞어 적은 것이다.
3. 도망 반사 채점 가운데 **TTMn 1:1 항목에는 전기 시냅스(갭 결합) 모형이 필요하다.** 커넥톰에는 없는 것이다 → Could(F-006).
4. **시냅스당 세기 0.275 mV 는 FlyWire 에 맞춘 값이다.** FLYCNS 는 MaleCNS 에서 0.3 배로 다시 맞췄다(0.30~0.35 가 평탄).
   → 세기 배율은 **설정 값 하나**로 두고, **정해 둔 규칙(도망 반사 채점)으로만** 고른 뒤 잠근다(06 §2.4 원칙).
5. 06 안에서 판단 주기가 어긋난다. 0장·1장·2.5 는 "1~2 초", 5장은 "M4 32 GB 에서 결정당 7~10 초"다
   → 이 맥에서 **잰 값으로 바꾼다**(F-013).
6. 부호는 08 결론대로 정한다. `consensus_nt` 를 쓰고, 히스타민 −, 조절 3종(도파민·세로토닌·옥토파민) 0, 미정 0, 신경전달물질 행이 없는 뉴런 0 으로 둔다.
   각각의 수는 전부 메타데이터에 남긴다(F-002).
7. **C 의 중심은 "초파리 신호 벡터를 LLM 에 직접 넣는 구조"다**(요구자 · 06 §3.2 소프트 프롬프트).
   초판 R 은 글 요약(0단계)을 본 설계로, 벡터 주입을 범위 밖으로 두었다 → **뒤집는다.**
   - Qwen3.8-27B 가중치를 **우리 프로세스에서 직접**(mlx-lm) 불러온다 — 서버(oMLX · Ollama · `mlx_lm.server`)를 쓰지 않는다.
     서버 API 로는 임베딩 자리에 벡터를 넣을 수 없다.
   - 초파리의 여러 신경 신호(시각 · 촉각 · 청각 · 냄새 · 미각·페로몬 · 구애·성 회로 · 버섯체 출력 · 몸 상태 · 하강 뉴런 — F-012 채널 표)를 **채널별 벡터**로 만들고, 채널별 사영으로
     은닉 5,120 차원 토큰 몇 개씩으로 바꿔 Qwen 입력 임베딩 사이에 끼운다. **Qwen 은 얼리고 사영만 학습한다.**
   - 글 요약 방식은 **비교군**으로 남긴다 — 벡터가 글보다 나은지를 가른다.
   - 가중치는 oMLX 의 **Uncensored 파생판**이다(요구자 선택). 결과에는 "Qwen3.8-27B(orcarouter Uncensored MLX 8bit 파생판)"로 적는다.
   - 요구자 그림: ***"보통 생성형 이미지 모델의 반대로 내가 생각한 거지"*** — 이미지 생성은 글 → 임베딩 → 이미지,
     이것은 **초파리 신경 신호 → 임베딩 → LLM → 글·행동**이다. 구조는 Qwen3.8 이 이미지를 읽는 길(이미지 인코더 → 투영기 → LLM 토큰)과
     같고, **이미지 자리에 초파리 뉴런 활동이 들어간다**(LLaVA 식 투영기). 학습도 그 방식대로 ① 정렬(신호 → 상황 설명 캡션)
     ② 행동(신호 → 행동 JSON) 두 단계로 한다.
   - 요구자: *"LLM 텍스트 인코더가 앞으로 오고 뒤가 디퓨전 모델인데"* · ***"우리는 초파리가 앞이고 뒤가 LLM 인 경우"*** —
     **초파리 회로 = 인코더(앞) · LLM = 생성기(뒤).** 초파리 회로가 만든 임베딩이 LLM 의 생성을 조건 짓는다
     (디퓨전이 텍스트 임베딩을 조건으로 받듯, 여기서는 LLM 입력 앞에 끼운 소프트 토큰이 조건이다).
8. **몸 = FlyGym 1.x 를 별도 프로세스로**(요구자 선택 2026-09-22). 설치해 보니 FlyGym **2.1 에는 보행·회전 제어기와 냄새 모듈이 없다**

## 2. 기능 정의 — G1 게이트: 이 장이 사용자 승인되면 상태=확정

### 2.0 원칙 (연구 노트 06 · 07 에서)

1. **계산은 시뮬레이터가, 말은 언어 모델이** 한다 — 요약은 코드가 만들고 언어 모델은 읽기만 한다.
2. **배선은 고정**이다 — 어느 단계에서도 연결을 학습하거나 다시 잇지 않는다.
3. **매개변수는 출처가 있거나, 미리 정한 규칙으로 맞춘 것만** 쓴다 — 전부 한 파일에 출처와 함께 둔다.
4. **모든 실행은 다시 돌릴 수 있다** — 씨앗 · 매개변수 판 · 그래프 SHA · 원본을 실행 폴더에 남긴다.
5. **정직 목록** — 결과마다 "배선이 낸 것 / 코드가 더한 것"을 나눠 적는다(Lulzx · Fly.exe 방식).
6. **섞은 배선 대조를 못 이기면 "초파리 뇌"라 부르지 않는다.**

### 2.2 기능 상세 및 인수 기준

#### F-001: 공식 데이터 받기·검증

**사용자 시나리오**: 요구자가 받기 명령을 실행한다 → 시스템이 파일 3개를 받아 SHA-256 을 대조한다 → 통과한 파일만 `data/` 에 남는다.

**인수 기준**:
- [ ] 파일 3개의 크기와 SHA-256 이 공식 값과 같다(1.2 표의 크기)
- [ ] 두 번째 실행은 다시 받지 않고 SHA 만 대조한다(로그로 확인)
- [ ] SHA 가 다르면 파일을 남기지 않고 실패한다(시험: 깨진 파일 주입)
- [ ] 데이터 출처·라이선스(CC BY 4.0 · FlyEM/HHMI 자넬리아 · 케임브리지 · MRC LMB · 구글 리서치) 표기가 `NOTICE` 에 있다

**예외 케이스**: 받는 중에 끊기면 → 임시 파일(`.part`)을 지우고 다시 시작한다.

#### F-002: 그래프 컴파일

**인수 기준**:
- [ ] 기본 뉴런 집합 = `status == "Traced"` **165,122 개**. 다른 집합은 설정으로 고를 수 있고, 무엇을 썼는지 메타데이터에 적힌다
- [ ] 부호별 뉴런 수가 메타데이터에 있고 08 표와 대조된다: + 103,718 · − 57,261(GABA 22,055 · 글루탐산 29,296 · 히스타민 5,910) · 조절 541 · 미정 3,100 ·
  신경전달물질 행 없음(08 의 표에서 역산하면 502). **실측값을 적고, 다르면 W 에 차이를 적는다**
- [ ] 케니언 세포 4,064 개의 부호가 전부 + 다(`predicted_nt` 가 아니라 `consensus_nt` 를 썼다는 시험)

  | `vector` **본 설계** | 초파리 회로 → 벡터 → 투영기 | Qwen | — |
  | `text` 비교군 | 초파리 회로 → 글 요약 | Qwen | 벡터가 글보다 나은가 |
  | `no_circuit` 대조 1 | 세계의 원시 값(숫자 + 영상 한 장) | Qwen | 회로를 거치는 것이 도움이 되나 |
  | `rewired` 대조 2 | **섞은 배선** 회로 → 벡터 → 투영기(똑같이 학습) | Qwen | 초파리 배선 덕인가 |
  | `no_llm` 대조 3 | 초파리 회로 → 하강 뉴런 그대로 | 없음(반사만) | LLM 이 더한 것이 있나 |

- [ ] 같은 씨앗 목록(학습에 안 쓴 씨앗)으로 구성마다 **10 회 이상** 돌린다. 지표: 캡션 정확도(`vector`·`rewired`) · 냄새 원 도달률 · 도달 시간 · 회피 성공률 · 결정당 지연 — 평균과 흔들림을 함께 적는다
- [ ] 성적표 파일이 하나 나온다. `rewired` 를 이기지 못하면 보고서 문구에 "초파리 뇌"를 쓰지 않는다(시험: 문구 규칙)

### 2.3 비기능 요구사항

- **성능**: A 는 1,000 ms 모의 60 초 이하가 목표다(측정). C 는 비실시간이 기본이다.
- **자원(코드로 막는다)**: 무거운 실행 전 `memory_pressure` 여유 40 % 이상 · 한 번에 하나(잠금 파일) · Qwen 가중치(28 GB)를 올리기 전에도 같은 검사.
  무거운 실행(뇌 전체 반복 · Qwen 올리기 · 대조군 반복)은 **요구자께 먼저 알린다.**
- **보안**: 로컬 전용이다. MCP 는 stdio 라 포트가 없다(9200 · 9201 · 9210 · 9211 · 9212 · 8877 과 안 겹친다). 비밀 값도 없다(가중치는 로컬 파일).
- **재현성**: 매개변수 · 대응표 · 게인은 판 번호가 붙은 파일이다. 실행마다 어느 판을 썼는지 기록한다.
- **라이선스**: MaleCNS CC BY 4.0 · Shiu 모델 MIT 를 `NOTICE` 에 표기한다. 라이선스 없는 저장소(mps-malecns-model · FLYCNS)의 코드는 복사하지 않는다(사실·수치만 원 출처와 함께 인용).
