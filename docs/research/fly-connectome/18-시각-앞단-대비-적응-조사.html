18. 시각 앞단의 대비 적응 — V1 입력 부족 조사

2026-10-17 · 세션 echomind-fly-research · 조율 세션 일감(10-16 밤 · V1 막힘). 노트 17 의 V0 · V0b 다음 단계다. 이 노트는 문헌 · 원문만 읽었다. 시뮬레이션 · 렌더 · 코드 고침은 하지 않았다. [측정] 은 조율 세션이 잰 기록을 읽기만 한 것이다. 확인 수준: [P] 원문 · 원문 사본을 이 세션이 직접 열어 문구 확인 · [P*] 조사 에이전트가 원문에서 읽음(이 세션은 다시 열지 않음) · [A] 초록만 · [S] 2 차 · [측정] 조율 세션 기록 · [계산] 우리 셈 · [그림] 논문 그림에서 눈으로 읽은 값(몇 % 틀릴 수 있음) · [추론] 우리 해석.

0. 한눈에

물음 답
무엇이 막혔나 V1(렌더 → 앞단 v2 → 뇌)에서 제자리 90 °/s 돎에 T4/T5 평균 0.14 Hz(10 Hz 넘는 뉴런 0.3 %) → HS 0 · DNa02 0 [측정]. 앞단 v2 는 두 신호를 곱하는 상관 검출기라 출력이 대비의 제곱이고, 기준(ref)이 대비 1 줄무늬다 → 대비 0.2 면 기준의 0.04 [계산]
① 실제 초파리는 대비에 훨씬 덜 민감하다. 대비 0.2 에서 T4 약 0.81 · T5 약 0.37(Drews 2020 표 S1 맞춤식에서 계산) · HS 약 0.47(Schnell 2010 [그림]) · VS 는 대비 약 24 % 에서 반최대(Joesch 2008) · 날기 회전 반응은 대비 0.09~0.98 에서 차이 없음(p 0.375 · Duistermars 2012) · 꽃등에 HS 는 4 % 부터 반응 · 약 20 % 에서 포화(Harris 2000)
기전 상관 앞에서 일어난다. ① 수질 순간 세포(Mi1 · Tm3 · Tm1 · Tm2 · Tm4)의 나눗셈 대비 정규화 — 둘레 약 35° 까지 · 50 ms 안 · 움직이는 배경만(정지 배경은 누르지 않음) · Tm2 를 막으면 거의 사라짐(Drews 2020) ② Mi1 의 시간 대비 적응 — 이득 약 4 배 · 100~200 ms(Matulis 2020) ③ 국소 밝기 이득 조절 — Tm1 · Tm9 · 10~15° 에서 가장 큼(Gür 2024)
② 넣을 식 두 단계. (가) 밝기 → 국소 웨버 대비 c = (I_blur − Ī) / Ī · Ī = 가우시안 FWHM 25°(Matulis 2020 · Chen 2019 은 약 30° 에서 가장 이득) (나) 정류 뒤 · 곱하기 앞 나눗셈 정규화 r = x^p / (c50^p + x^p + (w_pool · P)^p) · P = 정류한 고역 신호의 가우시안 풀(FWHM 30°) · p 1.1~1.3 · w_pool 1.5~3(Drews 가 손으로 정한 값) · c50 은 우리 단위로 다시 정한다
③ 자연 장면에서 초파리는 회전하는 자연 파노라마를 잘 따라간다 — 걷기 돌기가 장면 속도와 개체별 r > 0.8(Leonhardt 2016 [P*]) · HS 는 장면 차이가 작다(Drews 2020 [P*]) · 꽃등에 HS 는 대비가 3 배 달라도 비슷(Straw 2008 [P*]). 자연 장면 실효 RMS 대비 봉우리 0.09(대역 통과) · 0.23(저역)(Dyakova 2015). 제자리 돎에는 가로 방향 대비만 쓰인다 — 하늘/땅 경계는 쓰이지 않는다
④ 판단 앞단에 (가)+(나)를 넣으면 제자리 돎 → DNa02 부호 = 중간~높음 · 사람 다가옴 → 같은 쪽 LC4 = 중간. 단 V1-b 에서 오른쪽 다가옴이 왼쪽 LC4 를 켰다(8/0 [측정]) — 대비가 아니라 좌우 대응 문제일 수 있어 먼저 확인. 경기장이 너무 성긴지는 가로 대비를 재야 안다(지금 잰 "기둥 밝기 표준편차 0.2"는 하늘/땅이 섞인 값)
가장 작은 시험 F0 — 앞단만(뇌 없음): ① 줄무늬 대비 곡선이 Drews T4 곡선 근처인가 ② 경기장의 가로 국소 대비 분포 ③ 렌더 제자리 돎에서 T4/T5 발화율과 방향 ④ 오른쪽 원판 → 오른눈만 바뀌나. 넘으면 V1-c(뇌 · 작은 시험 먼저 · 7 절)

1. 출발점 — 이미 잰 것 [측정 · 다시 재지 않음]

  • V0b 통과(runs/v0b-disk-20261016-214745): 다가옴 LC4 진짜 210.5 대 자리 섞기 0~0.2 · 재배선 0 · 같은 쪽 10/10. 단 움직임 없는 어두워짐도 200 → LC4 의 다가옴 선택성은 없다(노트 17 §10).
  • V1-a(runs/v1-check-20261016-230912 · 잠금 d7d406c): 모든 읽기 0 — 사람이 안 그려짐 · 무늬 없는 땅(고침 3c2c4ad).
  • V1-b 작은 시험(runs/v1-check-20261016-233448 · 장면 v2 = 잔디 사진 텍스처 + 나무 · 바위 · 씨앗 0 · 진짜만 · 판정 아님): 몸 돎 HS 0 · DNa02 0 · 다가옴 LC4 7/0(왼쪽 다가옴) · 8/0(오른쪽 다가옴 — 반대쪽). 앞단: 기둥 밝기 표준편차 0.2 · T4/T5 평균 0.14 Hz · V0 분석식(오른눈 a 대부분 약 100 Hz)과 큰 차.
  • 앞단 v2(src/moai_echomind_fly/eye/frontend.py · config/eyeworld.yaml · 읽기만): 기둥 밝기(낱눈 σ 2.12° · FWHM 약 5°) → 1 차 고역(τ 250 ms) → ON/OFF 정류 → 바로 옆 기둥끼리 상관(지연 저역 τ 30 ms) → r_max · clip(출력 ÷ ref, 0, 1) · ref = 대비 1 사인 줄무늬(λ 30°)를 100 °/s 로 흘린 출력. 소엽 기둥 세포(Tm2 · Tm4 · T2 · Tm3)는 흐린 밝기의 dL/dt ÷ (대비 1 가장자리 기준) — 대비에 1 차 비례.
  • 대비 제곱의 셈 [계산]: 상관 출력 ∝ c² → 기준 대비 1 로 자르면 c = 0.05 · 0.1 · 0.2 · 0.3 · 0.5 에서 0.003 · 0.010 · 0.040 · 0.090 · 0.25.

파노라마 대비 범위 표준편차 ÷ 평균 0.40~1.24(9 파노라마) Straw 2008 [P*]
순수 상관 검출기의 장면 변동 기본 모형 · 50 °/s: 영상 안 변동계수 "66.3±27.1%" · 14 영상 평균끼리 46.6 % · 전체 모형은 중앙 변동계수 "6.91%" Brinkworth & O'Carroll 2009 [G12][P]
상관 출력은 대비 제곱 · 보정 필요 출력이 C² 로 변해 "the visual system needs to compensate for these contrast variations" · tanh 포화로 영상끼리 모임 Dror, O'Carroll & Laughlin 2001 [G16][P*]
낱눈 간격 · 받아들이는 각 간격 Δφ 약 4.5° · 받아들이는 각(단일 광수용체 기록) 밝음 적응 7.70 ± 1.27° · 어둠 적응 9.47 ± 1.57° Juusola et al. 2017 [G17][P]
모형들이 쓴 흐림 FWHM 4°(Drews) · 5°(Leonhardt) · 5.3°(Chen) · 5.7°(Matulis · Fitzgerald & Clark) 각 논문 [P*] · Matulis 5.7° 는 [P]

읽은 것 [추론]: - 우리 낱눈 σ 2.12°(FWHM 약 5°)는 모형들이 쓴 값의 범위 안이다 — 흐림이 원인의 전부는 아니다. - 제자리 돎(yaw)의 흐름은 가로 방향이라 가로로 놓인 하늘/땅 경계는 움직임 신호를 거의 내지 않는다. 지금의 "기둥 밝기 표준편차 0.2"는 하늘/땅 차이가 대부분이라 yaw 에 쓰이는 대비가 아니다. 비교할 숫자는 "행 방향 국소 웨버 대비(5° 흐림 뒤)"이고, 자연 장면의 0.09~0.23 과 견준다. - 그래서 원인은 둘 다일 가능성이 크다 — 이득 조절 없음(가장 큼 · 10~20 배) + 가로 경계가 적은 장면.

6. ④ 판단

6.1 원인 나눔 [추론]

원인 무게 근거
상관 출력이 대비 제곱 · 기준이 대비 1 가장 큼 실제 T4 0.81 대 앞단 0.04(대비 0.2) — 2 절
가로 경계가 적은 장면 · 먼 나무줄기가 5° 흐림에 지워짐 중간 조율 진단 [측정] · yaw 에는 가로 대비만 쓰임
밝기 정규화 없음(하늘 밝음 · 땅 어두움이 한 척도) 중간 웨버 대비가 아니면 어두운 땅의 무늬가 작게 잡힌다 — M1 · C1
좌우 대응 LC4 쪽만 · 확인 필요 V1-b 오른쪽 다가옴 → 왼쪽 LC4 8/0 · V0b 분석식은 같은 쪽 10/10 → 뇌가 아니라 렌더 · 표본 쪽일 수 있다

6.2 앞단 v3 제안 (자리 · 식 · 값 · 선언)

  1. 밝기 → 국소 웨버 대비(고역 앞): c_i = (I_i − Ī_i) / Ī_i · Ī = 기둥 밝기의 가우시안 FWHM 25° 평균(M1 · C1). 소엽 기둥 세포(Tm2 · Tm4 · T2 · Tm3)의 dL/dt 도 이 c 로.
  2. 나눗셈 정규화(정류 뒤 · 곱하기 앞): r_i = x_i^p / (c50^p + x_i^p + (w_pool · P_i)^p) · P_i = 정류한 고역 신호 |x| 의 가우시안 FWHM 30° 합(정지 배경은 고역에서 사라지므로 문헌의 "움직이는 배경만"과 맞음) · p 1.2(D1 의 1.1~1.3 사이 · 선언) · w_pool 2(1.5~3 사이 · 선언) · c50 = 대비 0.08 줄무늬가 이 단계에 주는 x(Mi1 0.06 과 T4 0.11 사이 · 선언 · 우리 단위로 다시 잼).
  3. 기준(ref)은 그대로 "대비 1 줄무늬 · 100 °/s" 출력으로 다시 잰다 — 정규화가 들어가면 대비 0.2 의 출력이 기준에 가까워진다.
  4. 다른 것(옆쌍 상관 · τ 30 ms · 고역 250 ms · 방향 축)은 v2 그대로.

⚠️ 이 값들은 손으로 고른 앞단이다(Drews 도 "manually tuned"). 결과 전에 잠그고, 문구에 "앞단이 문헌의 대비 정규화를 계산으로 흉내 냄"을 적는다. 정규화는 약한 대비를 키우는 것이지 없는 경계를 만들지 않는다.

6.3 성공 가능성 [추론]

V1 칸 앞단 v3 를 넣으면 근거
R1 제자리 돎 → DNa02 부호 중간~높음 문헌상 정규화된 T4 는 대비 0.2 에서 0.8 · V0 분석식에서 진짜 배선이 DNa02 부호를 나름 [측정] · 남은 위험은 가로 경계가 아주 적은 장면
A1~A3 사람 다가옴 → 같은 쪽 LC4 · 자리 · 배선 중간 V0b 통과(분석식) · 소엽 세포는 대비에 1 차 비례라 웨버 대비만으로도 커짐 · 좌우 대응 확인이 먼저(오른쪽 → 왼쪽 8/0) · LC4 는 어두워짐에도 켜져 "다가옴"이라 부르지 않음(노트 17 §10)
대비 정규화만으로 장면이 충분한가 모름 → F0-2 로 잰다 자연 장면 0.09~0.23 대 우리 경기장(가로 대비 미측정)

7. 가장 작은 시험 — F0(앞단만 · 뇌 없음) → V1-c

실행 · 잠금은 조율 세션 몫. 숫자는 제안이고 잠글 때 바꿀 수 있다(바꾸면 결과 전에).

칸 무엇 기준(결과 전)
F0-1 대비 곡선 사인 줄무늬 λ 30° · 30 °/s(Drews 자극과 같음) · Michelson 0.05 · 0.1 · 0.2 · 0.5 · 1 → 앞단 v3 의 T4 선호 방향 출력 ÷ 대비 1 출력 Drews T4 맞춤식 c^2.47 / (0.11^2.47 + c^2.47) = 0.12 · 0.44 · 0.81 · 0.98 · 1.00 과 각 점 차 ≤ 0.2 · 그리고 대비 0.2 에서 ≥ 0.47(HS 값) · 방향 선택 지수 ≥ 0.5(30 · 90 °/s · v2 와 같은 기준)
F0-2 경기장 가로 대비(보고만) 렌더 경기장에서 기둥 밝기(5° 흐림)의 행 방향 국소 웨버 대비 |c| 분포 · 눈높이 ± 20° 띠 판정 아님 — 중앙값 · c50(대비 0.08) 넘는 기둥 비율을 자연 장면 0.09~0.23 과 나란히 적음
F0-3 렌더 제자리 돎 렌더 · 90 °/s 시계 · 반시계 · 앞단 v3 출력만 앞→뒤 흐름이 생기는 눈의 T4a+T5a 평균 발화율 ≥ 20 Hz 이고 같은 눈 b 아형의 ≥ 2 배 · 다른 눈은 반대 · 방향을 바꾸면 뒤집힘(V0 분석식은 약 100 Hz)
F0-4 좌우 대응 렌더에서 몸 기준 오른쪽 30° · 왼쪽 30° 에 어두운 원판 오른쪽 원판 → 오른눈 기둥만 밝기 변화(왼눈 변화 0) · 왼쪽은 반대. 못 넘으면 V1 전에 고침
  • F0 는 뇌를 돌리지 않는다 — 렌더 몇 초와 앞단 계산뿐 [추론].
  • F0-1 · F0-3 · F0-4 통과 → V1-c: V1 의 판정(R1 제자리 돎 → DNa02 부호 · A1~A3 사람 다가옴 → LC4 자리 · 배선 · 같은 쪽)을 그대로 두고 앞단만 v3 로 바꿔 다시 잠금 → 작은 시험(씨앗 0 · 진짜만) 먼저 → 가능성이 보이면 본 실행(메모리 규약 "가능성 먼저").
  • F0-1 을 못 넘으면: 매개변수를 결과 전에 한 번만 다시 고르고(F0 안에서), 그래도 못 넘으면 정규화 대신 Matulis 의 "영상마다 분산으로 나눔"(완전 적응 · 상한)을 비교용으로만 재고 멈춘다.
  • F0-2 에서 가로 대비가 자연 장면보다 훨씬 낮으면(중앙값 < 0.05 [제안]): 앞단과 별개로 눈높이에 세로 경계가 촘촘한 장면이 필요하다.
  • 문구: V1-c 통과 → "렌더한 3 차원 공간을, 문헌의 대비 정규화를 흉내 낸 계산 앞단으로 T4/T5 · 소엽 기둥 세포에 넣으면 우리 배선이 제자리 돎 방향과 다가오는 쪽을 하강 뉴런까지 나른다". "초파리가 본다"는 여전히 쓰지 않는다(앞단이 계산 · 대비 정규화 매개변수는 손으로 정함).
