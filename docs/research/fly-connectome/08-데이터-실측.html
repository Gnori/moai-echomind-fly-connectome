08. 데이터 실측 — 주석 파일과 신경전달물질 파일을 직접 열어 본 것

2026-09-16. 공식 저장소에서 body-annotations-male-cns-v1.0-minconf-0.5.feather(14MB)와 body-neurotransmitters-male-cns-v1.0.feather(43MB)를 내려받아 pandas 로 센 값이다. README 나 논문의 요약이 아니라 파일 그대로의 숫자다. FlyGym 겹눈 수는 저장소의 자산 파일(compound_eye.npz)에서 셌다.

1. 뉴런 수 — 166,700 과 165,122 가 왜 다른가

주석 파일은 211,577 행이다. 뉴런만이 아니라 신경아교세포·고아 조각·중요하지 않은 조각까지 들어 있다. 시뮬레이션이 쓰는 「뉴런」은 이 중 status 로 고른다.

status 행 수 뜻
Traced 165,122 추적이 끝난 뉴런 — Fly.exe·Lulzx 가 「165,122」라 부르는 집합
Orphan 15,925 세포체와 이어지지 않은 조각
Glia 11,864 신경아교세포
Unimportant 10,751 작은 조각
None 5,472 상태 없음
Assign 1,832 배정 대기
Anchor 611 앵커

논문·DOOMFLY·NeuroCraft 가 말하는 166,700(또는 166,691) 은 「주석된 뉴런」이고, Traced 165,122 에 Assign·Anchor 등을 얼마나 더 넣느냐로 갈린다. Fly.exe 의 결정 기록에는 「Traced+Assign+Anchor 로 넓히면 2,443 개(1.48%)·연결 60,281 개(0.24%)가 더해진다」고 적혀 있다. 어느 집합을 썼는지 적지 않은 숫자는 비교할 수 없다.

6. 신경전달물질 파일 — 예측·근거·합의

파일은 1,835,518 행이다. Traced 뉴런만이 아니라 모든 조각에 예측이 붙어 있어 행이 많다. 칸은 열 개다.

칸 뜻
predicted_nt 그 뉴런의 시냅스 이미지들에서 예측한 주된 물질
predicted_nt_confidence 그 예측의 확신
total_nt_predictions 예측에 쓴 시냅스 수
ground_truth 문헌에서 알려진 물질(있을 때만)
celltype_predicted_nt 같은 세포 종류 전체를 모아 낸 예측
consensus_nt 뉴런 예측·종류 예측·문헌을 합친 최종값 — 시뮬레이션에 이것을 쓴다

앞 문서에서 「여섯 가지」라고 한 것은 틀렸다 — 히스타민을 포함해 일곱 가지다. 히스타민은 광수용체가 쓰는 물질이고 시각엽 첫 단에서 억제로 작용한다.

뉴런 예측과 합의가 다른 곳 — 18,743 개

  • 12,343 개는 뉴런 예측이 「미정」이었다가 종류 예측으로 채워진 것.
  • 케니언 세포 4,058 개가 뉴런 예측에서는 「도파민」, 합의에서는 「아세틸콜린」이다. 실제 케니언 세포는 아세틸콜린이다 — 이미지 기반 분류기가 이 세포에서 체계적으로 틀리는 알려진 현상이고, 합의 칸이 그것을 바로잡는다. 뉴런 예측을 그대로 쓰면 버섯체 입력 4,000 개가 「조절 = 0」으로 꺼진다.
  • 광수용체 2,164 개는 뉴런 예측 「미정」 → 합의 「히스타민」.
  • 글루탐산 → GABA 375 개(둘 다 −라 부호는 같음), 아세틸콜린 → 글루탐산 108 개(부호가 뒤집힘).

결론: 부호는 predicted_nt 가 아니라 consensus_nt 로 붙인다. 그래도 미정 3,100 개와 조절 541 개, 그리고 신경전달물질 파일에 행이 없는 Traced 뉴런 502 개가 남는다(위 분포표 합이 164,620 인 까닭 · 아래 「?」 3,602 = 3,100 + 502 — 2026-09-22 다시 셈) — 0 으로 두든 빼든, 무엇으로 했는지 적는다.

7. 몸 쪽 — FlyGym 겹눈

flygym/assets/model/neuromechfly/compound_eye.npz 와 vision.yaml 에서 직접 확인:

  • 눈당 낱눈 721 개 — 창백형(pale, 자외선 R7·청색 R8) 216 · 노랑형(yellow) 505
  • 눈 하나의 원시 렌더 512 × 450 픽셀, 시야각 157°, 어안 왜곡 계수 3.8
  • 낱눈 하나 = 픽셀 묶음 평균. 낱눈 아이디 지도(ommatidia_id_map)로 어느 픽셀이 어느 낱눈인지 정해져 있다

MaleCNS 광수용체 4,107 개(한 눈에 약 2,050)와 FlyGym 낱눈 721 개는 수가 다르다. 실제 초파리는 눈당 약 750~800 낱눈이고 낱눈마다 R1–R8 여덟 개가 있으니, MaleCNS 는 재구성에서 광수용체 일부만 잡힌 것이다. 대응표는 「FlyGym 낱눈 → MaleCNS 의 assignedOlHex 격자 좌표」로 맞추고, 짝이 없는 낱눈은 비운다(06 의 2.2).

8. 이 실측이 설계에 주는 것

  1. 부호는 consensus_nt — 케니언 세포 4,058 개가 걸려 있다.
  2. 광수용체는 히스타민(−) — 빛이 들어오면 첫 단이 억제된다. 인코더는 「밝음 = 광수용체 발화 ↑」로 넣되, 다음 단이 억제로 반응하는 것이 맞는 동작이다. Fly.exe 는 부호 미정 정책 때문에 광수용체 출력 66,533 개를 0 으로 두고 한 단 아래에서 빛을 넣었다 — 합의 칸을 쓰면 그럴 필요가 없다.
  3. 하강 뉴런 484 종류 1,314 개 — 행동 카탈로그의 후보 크기.
  4. 낱눈 ↔ 광수용체 대응은 assignedOlHex1/2 로 만든다.
  5. 암수 차이 표시 약 2,400 개 — 수컷 데이터로만 할 수 있는 실험의 재료.

다시 세어 보는 법

# pip install pyarrow pandas
import pyarrow.feather as f
a  = f.read_feather("body-annotations-male-cns-v1.0-minconf-0.5.feather")
nt = f.read_feather("body-neurotransmitters-male-cns-v1.0.feather")
tr = a[a["status"] == "Traced"]                       # 165,122
tr["superclass"].value_counts()
m  = tr.merge(nt, left_on="bodyId", right_on="body", how="left")
m["consensus_nt"].value_counts()
m[m["class"] == "Kenyon_Cell"][["predicted_nt", "consensus_nt"]].value_counts()
