# 07. 지능은 누구 것인가

> [06 설계](06-설계-초파리-회로에-Qwen-뇌.md)를 두고 나온 다섯 질문 — 가중치가 있나 · LLM 과 같은 것인가 · 이 설계의 지능은 누구 것인가 · LLM 에 잇는 게 맞나 · 그래서 의미가 있는가.

## 1. 가중치가 있나 — 있다. 그런데 뜻이 다르다

| | 초파리 커넥톰 | Qwen3.8-27B |
|---|---|---|
| 가중치가 무엇인가 | 두 뉴런 사이 **시냅스 개수**(정수). 전자현미경 사진에서 **세어서** 얻음 | 실수 행렬. **경사하강으로 텍스트 예측을 위해 맞춘** 값 |
| 개수 | 연결 2,558만(시냅스 1.25억) | 매개변수 270억 |
| 부호(흥분·억제) | 신경전달물질을 **예측**해서 붙임 — 틀릴 수 있음 | 부호도 학습된 값 |
| 어떻게 생겼나 | **진화 + 발달 + 그 개체의 경험**이 만든 결과의 스냅샷 | 학습 데이터로 만든 결과 |
| 다시 학습시킬 수 있나 | **없음.** 학습 규칙(도파민 가소성 등)이 데이터에 없음 | 있음(미세조정) |

정확히 말하면 — **초파리 입장에서는 학습된 가중치가 맞다.** 수억 년 진화와 그 개체의 삶이 만든 것이다. 다만 **우리는 그 학습 과정을 손에 넣지 못했고, 결과인 배선만** 받았다. 시냅스 「개수」가 곧 「세기」인지도 근사다.

## 2. LLM 과 같은 것인가 — 부류는 같고 종류는 다르다

둘 다 「연결된 단위들이 신호를 주고받는 망」이다. 거기까지가 같다.

| | 초파리 뇌 | LLM |
|---|---|---|
| 하는 일 | **몸을 살리는 제어기** — 감각→운동의 닫힌 고리 | **다음 글자 맞히기** — 입력→출력 함수 |
| 시간 | 본질. 항상 돌고 있고, 스파이크의 **타이밍**이 정보 | 없음. 토큰 순서만 |
| 구조 | 희소(밀도 약 0.1%), 되먹임 고리투성이, 뉴런 종류마다 성질이 다름 | 밀집 행렬, 층을 차례로 통과 |
| 학습 | 내장(도파민 뉴런이 특정 시냅스를 바꿈) — 데이터에는 빠짐 | 밖에서 한 번 |
| 잘하는 것 | 항법·회피·냄새 추적·구애·냄새-보상 연합 학습 | 언어·지식·계획 |
| 언어 | **없음** | 전부 |

「초파리 뇌 = 작은 LLM」은 아니다. 초파리가 잘하는 지능은 LLM 이 못 하고, 그 반대도 마찬가지다.

## 3. 이 설계에서 지능은 누구 것인가 — LLM 의 것

[06 설계](06-설계-초파리-회로에-Qwen-뇌.md)에서 초파리 회로가 하는 일은 **감각 전처리**(보는 것·냄새 맡는 것을 요약)와 **타고난 반사**(도망)뿐이다. 「어디로 갈까」「피할까 먹을까」는 전부 Qwen 이 정한다.

초파리 회로에는 학습 규칙이 없으니 회로 혼자 낼 수 있는 행동은 타고난 반사 수준이다. 그 위에 얹은 판단은 LLM 것이므로, 이 구성은 정직하게 말하면 **「초파리 감각·반사 위에 얹은 LLM 지능」**이다.

## 4. LLM 에 잇는 게 맞나 — 목적에 따라 다르고, 의문이 맞다

| 목적 | LLM 연동이 맞나 | 맞는 길 |
|---|---|---|
| **초파리 뇌를 이해**하고 싶다 | **아니오.** LLM 이 판단을 가로채면 무엇이 회로 덕인지 흐려진다 | 회로만 돌리고 실험 기록과 비교. Shiu 모델·flyvis 가 하는 일 |
| **초파리의 지능**을 보고 싶다 | **아니오.** | LLM 을 빼고 **학습 규칙**(버섯체 가소성)을 넣어, 몸을 붙인 채 행동이 스스로 생기는지 보는 실험. 아직 아무도 제대로 못 한 어려운 과제 |
| 초파리 회로를 **재료로 무언가를 만들고** 싶다(에이전트·게임·데모) | 가능. 초파리의 기여는 작고 대체 가능할 수 있음 | [06 설계](06-설계-초파리-회로에-Qwen-뇌.md). 섞은 그래프 대조군(9장 대조 2)을 못 이기면 「초파리 뇌」라 부르지 않기 |
| LLM 을 초파리 **연구 도구**로 쓰고 싶다 | **예.** | [05 의 도구 호출 구성](05-LLM-연동-방식.md) — LLM 이 실험자, 초파리가 피험체 |

**판단**: 「초파리 회로에 Qwen 뇌 얹기」는 만들 수 있고 재미있는 데모가 되지만, 거기서 나오는 지능은 Qwen 의 것이다. 초파리의 지능이 보고 싶다면 방향이 반대다 — **LLM 을 빼고, 빠져 있는 학습 규칙을 채우는 쪽**이다.

## 5. 그래서 LLM 과 연동하는 게 의미가 있는가 — 판정

**「초파리 회로를 LLM 에 붙여서 지능을 얻는다」는 뜻이라면 없다.** 이유는 둘이다.

- 초파리 회로에는 학습 규칙이 없어서 혼자 낼 수 있는 것은 타고난 반사뿐이고, 판단은 전부 LLM 이 한다. 결과는 LLM 지능에 초파리 감각 전처리를 얹은 것이다.
- 공개된 사례가 증거다. FLYT3 는 같은 입력을 준 평범한 신경망이 85.7%, 초파리 회로가 60.8% 였다고 스스로 밝혔다. DOOMFLY 도 학습된 생존을 보이지 못했다([03](03-기대치와-사례.md)).

**의미가 있는 연동은 두 가지, 그리고 연구 방향 하나다.**

1. **LLM 을 실험자로 쓰기** — 실험을 설계하고, 시뮬레이터를 돌리고, 결과를 요약·보고하게 한다. 초파리는 피험체이고, LLM 은 사람 연구자의 손을 덜어 준다. [05 의 도구 호출 구성](05-LLM-연동-방식.md)이 이것이다.
2. **검증된 부품만 빌려 쓰기** — flyvis 처럼 실험 기록으로 검증된 시각 전처리 모델을 다른 시스템의 부품으로 쓴다. 「초파리 뇌」가 아니라 「초파리 눈에서 나온 필터」로 쓰는 셈이다.
3. **LLM 을 보상 판정자로 쓰기 (연구 방향)** — LLM 이 행동을 대신 정하지 않고, 결과를 보고 「잘했다 / 위험했다」만 판정해 **도파민 뉴런을 켠다.** 행동은 회로가 스스로 내고, 회로가 바뀌는 것도 회로 안의 조절 규칙이 한다([06 의 2.6](06-설계-초파리-회로에-Qwen-뇌.md#26-신경물질을-주입해야-하나--아니다-발화를-넣는다)). 판단의 주인이 회로 쪽으로 넘어가므로 「초파리가 배운다」에 가장 가깝다. 조건: 조절 규칙(도파민이 시냅스를 어떻게 바꾸나)을 문헌에서 가져와 가정으로 명시하고, 「무작위 보상」「규칙 없음」 대조군을 같이 돌린다. 아직 아무도 성공하지 못했다.

[06 의 「초파리 회로에 Qwen 뇌 얹기」](06-설계-초파리-회로에-Qwen-뇌.md)는 만들 수 있고 데모로는 재미있지만, **초파리의 지능을 보려는 목적이라면 답이 아니다.** 그때는 LLM 을 빼고, 데이터에 빠져 있는 **학습 규칙(버섯체 가소성)을 채워서 몸을 붙인 채 행동이 저절로 생기는지** 보는 실험이 맞다. 아직 아무도 제대로 성공하지 못한 문제이고, 그래서 연구 가치가 있는 쪽도 그쪽이다.

EchoMind 관점에서 하나를 고른다면 1번이다 — 「계산은 코드가, 말은 언어 모델이」라는 원칙과 같은 구조라서, 초파리 시뮬레이터를 도구로 붙이는 실험이 그 원칙을 시험해 보는 작은 본보기가 된다.

## EchoMind 에 주는 뜻

EchoMind 의 캐릭터도 같은 구조를 가진다 — 감정·기억·자율의지 **계산은 코드가 정본**이고, 언어 모델은 그 위에서 말하고 계획한다. 초파리 사례는 「고정된 회로 + 학습 규칙 없음」이 어디까지 가고 어디서 멈추는지를 보여 주는 대조군이다. 계산값을 언어 모델이 덮지 못하게 하는 원칙(형제 저장소 `moai-echomind/docs/domains/` 의 감정·기억 정본)이 여기서도 그대로 맞는다.
