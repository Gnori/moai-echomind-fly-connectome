# 04. 이 뇌로 다룰 수 있는 감각과 회로

> 데이터에 무엇이 들어 있고, 어디까지 시뮬레이션된 사례가 있나.

MaleCNS 는 뇌와 양쪽 시각엽, 복측신경삭이 목 연결부까지 한 개체로 이어져 있어서 **감각 입력에서 운동 출력까지 한 데이터 안에서 경로를 따라갈 수 있다.** FlyWire(암컷)는 뇌만 있고, 뇌로 들어오는 감각 축삭은 포함한다.

| 감각 · 회로 | 데이터에 어떻게 들어 있나 | 시뮬레이션·응용 사례 |
|---|---|---|
| **시각** | 광수용체(R1–R8) → 시각엽(라미나·메둘라·로불라). MaleCNS 는 양쪽 시각엽 포함, 수컷 오른쪽 시각엽은 별도 데이터(MAOL) | **가장 잘 모델링된 영역.** flyvis(연결 지도 제약 시각 모델, 학습된 모델 포함, 실험 검증) · DOOMFLY(화면 → R1–R6 밝기 3,335 + R8 색 811) · FlyGym 겹눈 |
| **후각** | 더듬이·아랫입술수염 감각뉴런 → 촉각엽(사구체 약 50종) → 버섯체·측각 | fly-brain 「위험 냄새(지오스민)」 자극 · FlyGym 은 더듬이 위치의 냄새 농도를 계산해 입력 |
| **미각** | 주둥이·다리 미각뉴런 → 식도하신경절 → 먹기 운동뉴런 | Shiu 모델의 대표 실험 — 단맛 뉴런을 켜면 주둥이 뻗기, 쓴맛은 거부. MaleCNS 동반 논문 중 하나가 미각 |
| **청각 · 기계감각** | 더듬이 존스턴 기관(진동·소리) → 청각 경로. 다리·날개의 기계감각은 신경삭 쪽 | fly-brain 「소리」 자극. 신경삭까지 있는 MaleCNS 에서는 다리 감각 → 운동 경로도 추적 가능 |
| **온도 · 습도** | 더듬이 온도·습도 수용기 → 뇌 | 데스크탑 초파리류 데모가 온도 입력을 넣음. 정량 검증 사례는 드묾 |
| **도망 반사** | 거대섬유(giant fiber) · 하강뉴런 DNp01 | mps-malecns-model 기본 예제(DNp01 자극) · NeuroTerrarium 의 거대섬유 소회로(51 뉴런) |
| **학습 · 기억** | 버섯체 케니언 세포(KC) → 출력뉴런(MBON), 도파민 뉴런(PPL1 등) | DOOMFLY 가 KC→MBON11 연결 4,184개에 가소성 규칙(학습 입증은 못 함). **연결은 있지만 학습 규칙은 데이터에 없다** |
| **항법 · 방향** | 중심복합체(타원체·부채꼴체 등) | 이론 연구는 많으나 공개 데모는 적음 |
| **구애 · 성행동** | 수컷 특이 회로(P1 등)와 암수 차이 — **수컷 데이터의 핵심 강점** | MaleCNS 암수 차이 탐색기 · Fruitless 저장소(mAL 출력을 막았을 때 구애 후보 뉴런 활동 변화) |
| **운동 출력** | 하강뉴런(DN, 약 1,300개) → 신경삭 운동뉴런 → 다리·날개 | DOOMFLY: DNp20 좌우 차 → 회전, DNpe017 → 이동·발사 · flybody·FlyGym 이 몸을 맡음 |

어느 감각이든 **바깥 세계 → 감각 뉴런 자극**으로 바꾸는 단계는 사람이 설계한다. 시각이 유독 앞선 이유는 광수용체 배열이 화면 픽셀과 대응시키기 쉽고, 시각엽 모델(flyvis)이 실험 기록으로 검증됐기 때문이다. 그 설계 방법은 [06 설계 2장](06-설계-초파리-회로에-Qwen-뇌.md#2-핵심--신경-신호를-초파리에게-어떻게-줄-것인가)에 있다.

## 신경전달물질과 부호 — 시뮬레이션의 셋째 기둥

시뮬레이션은 세 기둥 위에 선다. **배선**(누가 누구와, 2,558만 연결) · **세기**(연결마다 시냅스 개수 — 개수를 세기로 쓰는 것은 근사) · **부호**(흥분 + 인가 억제 − 인가). 신경전달물질이 정하는 것이 이 셋째, 부호다. 배선과 세기가 같아도 부호가 뒤집히면 신호가 퍼지는 대신 꺼지므로 핵심 입력이 맞다 — 그리고 셋 중 가장 불확실하다.

### 예측되는 일곱 가지

| 물질 | 시뮬레이션에서의 부호 | 역할 |
|---|---|---|
| 아세틸콜린 | **+ (흥분)** | 초파리 뇌의 주된 흥분성 물질. 뉴런의 절반 넘게 |
| GABA | **− (억제)** | 주된 억제성 물질 |
| 글루탐산 | **− (억제, 대개)** | 포유류와 반대로 초파리에서는 억제로 작용하는 경우가 많다. Shiu 모델도 − 로 둠 |
| **히스타민** | **− (억제)** | **광수용체의 물질.** 빛이 들어오면 시각엽 첫 단을 억제한다. 합의 기준 5,910 뉴런 |
| 도파민 | 조절 | 학습·보상·처벌 신호. 버섯체 가소성의 열쇠 |
| 세로토닌 | 조절 | 상태·각성 조절 |
| 옥토파민 | 조절 | 포유류 노르아드레날린에 해당. 각성·움직임 |

위 넷이 「빠른 전달(+/−)」이고 아래 셋이 「조절」이다. 조절 물질은 단순한 부호가 아니라 다른 시냅스의 세기와 학습을 바꾸므로, LIF 시뮬레이션에서는 대개 0 으로 두거나 뺀다.

### 왜 가장 불확실한가

- 전자현미경 사진에는 물질이 보이지 않는다. **시냅스 모양을 보고 기계학습으로 분류한 예측값**이다. 정확도가 높다고 보고돼 있지만 100% 는 아니고, 틀린 뉴런은 부호가 뒤집힌 채 시뮬레이션에 들어간다.
- 데이터 위치: `body-neurotransmitters`(뉴런 하나마다 주된 물질) · `tbar-neurotransmitters`(시냅스 자리마다). 시뮬레이션은 보통 뉴런 단위 예측을 써서 「이 뉴런이 내는 연결은 전부 +」처럼 부호를 붙인다.
- **실측([08](08-데이터-실측.md))**: 뉴런 예측(`predicted_nt`)을 그대로 쓰면 **케니언 세포 4,058 개가 「도파민」으로 잘못 붙어** 버섯체 입력이 꺼진다. 종류·문헌을 합친 `consensus_nt` 칸은 이를 아세틸콜린으로 바로잡는다 — **부호는 `consensus_nt` 로**. 문헌 근거가 있는 7.6만 뉴런에서 예측 일치율은 99.2%(미정 제외)지만, 근거 없는 8만 뉴런의 오류율은 이보다 높을 수 있다.
- 「전달」 과정 자체는 시뮬레이션에서 「발화 → 세기 × 부호를 상대 전압에 더함」 한 줄로 줄어 있다. 수용체 종류·시간 상수·단기 강화가 다 빠졌는데도 Shiu 모델이 실험과 91% 맞았다 — 거친 「어디로 퍼지나」 예측에는 부호와 세기로 충분했다는 뜻이다.

### 빠져 있어서 병목인 것

| 빠진 것 | 왜 중요한가 |
|---|---|
| **신경조절**(도파민 등) | 회로의 게인을 바꾸고 학습을 켠다 — 「행동이 바뀌는」 부분 |
| **학습 규칙** | 버섯체 가소성 등. 연결은 있는데 바뀌는 법이 없다 |
| **전기 시냅스**(갭 결합) | 전자현미경 커넥톰에 안 잡힌다 |
| **신경펩티드·공동 전달** | 한 뉴런이 물질을 둘 이상 낸다 |
| **뉴런 고유 성질** | 종류마다 다른 시간 상수·문턱 — 다 같은 LIF 로 둔다 |

한 줄로: **신경전달물질은 부호로서 핵심 입력이고, 예측이 틀린 곳이 시뮬레이션의 첫 번째 오류 원천이다. 그러나 행동과 학습을 못 만드는 진짜 병목은 신경조절과 학습 규칙이 빠진 것이다.** 대조군에 「부호를 무작위로 뒤섞은 그래프」를 하나 더 두면 결과가 배선 덕인지 부호 덕인지 갈라진다([06 의 9장](06-설계-초파리-회로에-Qwen-뇌.md#9-검증--초파리가-정말-기여했나) 에 더할 후보).

## 뉴런의 종류 — 세는 축이 셋

### (가) 역할로 — 신호가 어디서 어디로 가나

| 부류 | 무엇 | [06 설계](06-설계-초파리-회로에-Qwen-뇌.md)에서의 자리 |
|---|---|---|
| **감각 뉴런** | 바깥 신호를 받아 뇌로 넣음 — 광수용체 4,107 · 후각 2,639 · 미각 1,428 · 기계감각 5,756 ([08](08-데이터-실측.md)) | **입구** (신호를 주는 자리) |
| **중심 뉴런** | 뇌 안에서만 잇는 사이 뉴런 — 국소 뉴런, 투사 뉴런 | 처리 |
| **시각 투사 뉴런** | 시각엽 → 중심뇌 (LC·LPLC 계열 등) | **읽기** |
| **하강 뉴런** | 뇌 → 신경삭 — **1,314 개, 484 종류**(실측) | **출구** — 행동 명령 |
| **상행 뉴런** | 신경삭 → 뇌 | 몸 상태 되먹임 |
| **운동 뉴런** | 신경삭 → 근육 | 몸 |
| **내분비 뉴런** | 호르몬 분비 | 느린 상태 |

주석 파일(`body-annotations`)에는 이 부류가 상위 분류 칸으로 들어 있어, 대응표를 만들 때 「감각 뉴런만」「하강 뉴런만」으로 걸러 낼 수 있다.

### (나) 위치로

- **시각엽** — 뉴런 수로는 뇌의 절반을 넘는다. 광수용체 R1–R8, 움직임 감지 T4·T5, 컬럼 뉴런 등이 격자처럼 반복된다.
- **중심뇌** — 촉각엽(후각), 버섯체(학습), 중심복합체(항법), 측각, 식도하신경절(미각), 하강 뉴런의 출발점.
- **복측신경삭** — 다리·날개 운동 회로, 기계감각 입력. MaleCNS 에만 들어 있다.

### (다) 세포 종류(cell type) — 형태와 연결이 같은 뉴런 묶음

가장 세밀한 단위다. 암컷 FlyWire 에서 [8,453 종류](https://doi.org/10.1038/s41586-024-07686-5)로 나뉘었고, MaleCNS 는 추적 완료 뉴런에서 **11,751 종류**(그중 8,199 종류가 FlyWire 이름과 짝지어짐 — [08](08-데이터-실측.md)). 대개 좌우 한 쌍이거나 같은 종류가 수십~수천 개 반복된다. 이름이 곧 주소라서 자료·논문·시뮬레이션이 전부 이 이름으로 말한다.

| 자주 나오는 이름 | 무엇 | 대략 규모 |
|---|---|---|
| R1–R8 | 광수용체 | 낱눈마다 8개 · MaleCNS 에 4,107 |
| T4 · T5 | 움직임 방향 감지 | 13,585 |
| LC · LPLC | 시각 특징(다가옴·작은 물체) 투사 | 종류마다 수십 개 |
| ORN | 후각 수용 뉴런 | 약 50 종류 |
| PN | 후각 투사 뉴런(촉각엽 → 버섯체·측각) | 백여 개 |
| KC (케니언 세포) | 버섯체의 학습 자리 | 4,064 |
| MBON | 버섯체 출력 뉴런 | 97 |
| DAN (PAM · PPL1) | 도파민 뉴런 — 보상·처벌 | 340 |
| EPG 등 | 중심복합체 방향 나침반 | 수십 |
| DN (DNp01 · DNa02 …) | 하강 뉴런 | 1,314 (484 종류) |
| MN | 운동 뉴런 | 신경삭에 |

그 밖에 **발달 계보(hemilineage)**로도 나눈다 — 같은 줄기세포에서 나온 뉴런 묶음(백여 개)으로, 같은 계보는 신경전달물질이 같은 경향이 있어 예측을 검산하는 데 쓰인다.

### 설계와의 관계

- **입구** = 감각 뉴런(광수용체·ORN·미각·기계감각) — 06 의 2장 대응표
- **읽기** = 시각 투사 뉴런·PN·MBON·상행 뉴런 — 06 의 3장 대응표
- **출구** = 하강 뉴런 — 06 의 4장 카탈로그
- **학습이 있어야 할 자리** = KC → MBON 연결과 DAN — 데이터에 연결은 있고 규칙은 없는 곳

위 표의 MaleCNS 숫자는 [08](08-데이터-실측.md)에서 파일을 직접 세어 넣었다(추적 완료 뉴런 기준). FlyWire 종류 수 8,453 은 논문 값.
