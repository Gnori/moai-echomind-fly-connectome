초파리 커넥톰 연구 노트

2026년 9월 3일 공개된 수컷 초파리 뇌·중추신경계 연결 지도(MaleCNS v1.0)를 받아 쓰는 법, 언어 모델과 잇는 법, 그리고 그렇게 했을 때 지능은 누구 것인가를 조사·설계한 기록이다. 공식 문서·저장소 원문으로 확인한 사실과, 이 노트에서 처음 제안한 설계를 나눠 적었다. 조사 2026-09-15 ~ 16. 시뮬레이션은 직접 돌려 보지 않았다. 다만 08의 숫자는 공식 데이터 파일을 내려받아 직접 센 것이다.

세 줄 요약

  • 커넥톰은 「누가 누구와 이어졌나」의 지도다. 시냅스 개수가 세기의 근사이고, 발화 방정식·학습 규칙은 데이터에 없다.
  • 언어 모델과 이으면 판단은 언어 모델의 것이다. 초파리 회로는 감각 전처리와 타고난 반사만 낸다. 「초파리 뇌」라 부르려면 섞은 그래프 대조군을 이겨야 한다.
  • 초파리의 지능이 보고 싶으면 방향이 반대다 — 언어 모델을 빼고, 빠져 있는 학습 규칙을 채우는 실험이다.

이 프로젝트(EchoMind)와의 관계

EchoMind 는 감정·기억·자율의지를 가진 AI 캐릭터를 만든다. 초파리 커넥톰은 「고정 배선 + 학습 규칙 없음」이 어디까지 행동을 내는가를 보여 주는 대조 사례이고, 05·07 의 「판정은 시뮬레이터가, 말은 언어 모델이」 원칙은 EchoMind 의 「계산값은 코드가 정본, 에이전트는 덮지 못한다」 원칙과 같다. 제품 코드와 직접 이어지는 요구사항은 아직 없다.
