# 09. 발화 모델 — 배선도에 붙이는 방정식

> 대부분의 시뮬레이션이 따르는 Shiu 등(2024 Nature) 모델의 실제 코드(`model.py`)에서 읽은 값이다. 다른 프로젝트가 어디를 바꿨는지도 함께 적었다.

## 1. 뉴런 하나 — 누적·발화(LIF)

뉴런은 두 변수로 줄인다. 막전위 `v` 와 시냅스 입력 `g`.

```
dv/dt = (v_0 − v + g) / t_mbr        # 전압은 쉬는 값으로 돌아가려 하고, 입력 g 만큼 밀려 올라간다
dg/dt = −g / tau                     # 입력은 시간 상수 tau 로 사그라든다
발화 조건: v > v_th
발화 뒤:   v = v_rst, g = 0, 그리고 t_rfc 동안 쉼
```

| 매개변수 | 값 | 뜻 | 출처(코드 주석) |
|---|---|---|---|
| `v_0` | −52 mV | 쉬는 전위 | Kakaria & de Bivort 2017 |
| `v_rst` | −52 mV | 발화 뒤 초기화 전위 | 같음 |
| `v_th` | −45 mV | 발화 문턱 — 쉬는 값에서 **7 mV** 위 | 같음 |
| `t_mbr` | 20 ms | 막 시간 상수 | 같음 |
| `tau` | 5 ms | 시냅스 입력이 사그라드는 시간 | Jürgensen 등 |
| `t_rfc` | 2.2 ms | 발화 뒤 쉬는 시간 | Lazar 등 |
| `t_dly` | 1.8 ms | 시냅스 전달 지연 | Paul 등 2015 |
| **`w_syn`** | **0.275 mV** | **시냅스 하나가 밀어 올리는 전압 — 유일한 자유 매개변수** | 맞춘 값 |

모든 뉴런이 **같은 값**을 쓴다. 종류마다 다른 성질은 없다.

## 2. 연결 — 세기와 부호

```
w = (부호 × 시냅스 개수) × w_syn
발화가 도착하면: g += w   (1.8 ms 뒤에)
```

- 시냅스 개수가 세기다. 20개 시냅스로 이어진 연결은 발화 한 번에 5.5 mV 를 밀어 올린다 — 문턱 7 mV 의 대부분.
- 부호는 신경전달물질에서 온다: 아세틸콜린 +, GABA −, 글루탐산 −. 조절 물질은 0 이나 제외([08](08-데이터-실측.md) — `consensus_nt` 를 쓸 것).
- 데이터 표의 `Excitatory x Connectivity` 칸이 곧 「부호 × 개수」다.
- **이 저장소(2026-09-23 · `sim-v2`)**: 후각 수용 뉴런에서 **같은 쪽**으로 가는 연결만 세기 × 1.4 — 같은 쪽 가지가 스파이크마다 약 40 % 더 방출한다(Gaudry et al. 2013 Nature 493:424). 연결 수 · 부호 · 상대는 그대로다. 우리 그래프에서 이 뉴런들의 시냅스는 같은 쪽 51.7 % · 반대쪽 47.7 % 라 개수만으로는 좌우가 지워진다.

## 3. 자극 — 뉴런을 켜는 법

```
포아송 입력: 150 Hz 로 무작위 시각에 발화가 도착
입력 세기:   w_syn × 250 = 68.75 mV   → 도착할 때마다 반드시 발화
켠 뉴런의 쉬는 시간은 0 으로 둔다
```

즉 「뉴런을 150 Hz 로 켠다」는 것은 그 뉴런이 평균 150 Hz 로 발화하게 만드는 것이다. 광유전학 실험의 흉내다. 두 번째 집단을 다른 주파수(`r_poi2`)로 켤 수 있다.

**끄는 법**(침묵): 그 뉴런에서 나가는 연결의 `w` 를 전부 0 으로. 뉴런은 남고 영향만 사라진다.

**시험 길이**: 기본 1,000 ms × 30 회 반복. 결과는 뉴런마다 발화 시각·발화율.

## 4. 이 모델이 맞은 것과 못 맞춘 것

- Shiu 등은 이 단순한 모델로 실험(단맛 → 주둥이 뻗기 등)을 **91%** 예측했다고 보고했다. 「어디로 퍼지나」에는 배선·개수·부호로 충분했다는 뜻이다.
- **FLYCNS(2026-09)** 는 같은 모델을 MaleCNS 에 붙여 회로 셋을 수치 기준으로 시험했다. 도망 회로(looming → LC → DNp01 → 다리 운동뉴런)와 청각 → 거대섬유(**발화가 아니라 문턱 아래 탈분극** — 생체 기록이 그렇다)는 재현됐지만, **먹기 회로는 재현되지 않았고 그 이유를 측정했다**: 단맛 감각 뉴런이 주둥이 운동뉴런(MN9)의 억제 중계에 흥분 중계보다 세 배 강하게 닿아 **경로가 「억제를 푸는」 방식**인데, 쉬는 상태가 침묵인 LIF 는 풀 억제가 없어 표현할 수 없다. 균일한 배경 발화를 넣으면 특이성이 사라지고 도망 반사도 죽는다. **뉴런 종류별 자발 활동**이 빠진 것이 원인이고, Shiu 등도 같은 한계를 적었다.

이 발견은 설계([06 의 2.4](06-설계-초파리-회로에-Qwen-뇌.md#24-게인-보정--얼마나-세게))에 직접 닿는다 — 게인만으로는 안 되는 회로가 있고, 그때 필요한 것은 **종류별 배경 발화율**이라는 새 매개변수다.

## 5. 다른 프로젝트가 바꾼 자리

| 프로젝트 | 바꾼 것 | 이유 |
|---|---|---|
| **Fly.exe** (MaleCNS 165,122) | 부호가 미정인 뉴런의 출력을 **0** 으로. 광수용체 출력 66,533 개가 그렇게 꺼져 빛을 한 단 아래(라미나)에 넣음. GeNN/CUDA 로 GPU 한 장, 몸과 15 ms 마다 동기 | 「추측하지 않는다」 정책 |
| **F1 모나코** (MaleCNS 166,700) | 시냅스 **5 개 이상** 연결만 → 624만 연결. 스텝 2 ms. 스파이크 빈도 적응 0.6 mV 추가(0 이면 논문 모델). 맥 GPU 전용 Metal 커널, fp16 상태 | 속도 — M4 Max 에서 뇌 한 스텝 1.3~1.7 ms |
| **FastFly** (FlyWire 139,255) | CSR 희소 형식 · FP16 가중치 · 발화한 뉴런의 시냅스만 처리(push) | 엔비디아 GPU 한 장에서 실시간 |
| **ConnecTorch** (MaleCNS 164,587) | 스파이크 대신 **연속 값 재귀망**(tanh, 누수 0.5). 연결마다 가중치를 **학습 가능**하게. 배선은 못 만들고 세기만 바꿈. Dale 옵션(한 뉴런은 한 부호) | 경사하강으로 학습하려고 |
| **FlyGM** (FlyWire 139,246) | 커넥톰을 그래프 신경망의 구조로 쓰고, 뉴런을 들어옴 19,262 / 안 118,496 / 나감 1,488 으로 나눠 강화학습 | 걷기·돌기·날기 제어 학습 |
| **Eon** (FlyWire) | Shiu 모델 그대로 + 시각은 flyvis 출력을 해당 뉴런에 주입 | 몸 붙이기 |

세 갈래가 보인다. **① 스파이크 LIF 를 그대로 두고 빠르게 돌리기**(Fly.exe·F1·FastFly), **② 연속 값으로 바꿔 학습 가능하게**(ConnecTorch·FlyGM), **③ 둘레에 학습된 부품을 붙이기**(Eon 의 flyvis·모방학습 제어기). ②는 「초파리 배선 위에서 학습」이라 [07](07-지능은-누구-것인가.md) 의 질문이 그대로 따라온다 — 배운 것은 배선 덕인가, 큰 그래프면 되는가.

## 6. 계산량 감

- 뉴런 165,122 × 상태 2 개 → 수 MB. 연결 2,556만 × (출발·도착·세기) → 약 300~500 MB.
- 한 스텝(1 ms)은 「발화한 뉴런의 나가는 연결에 g 더하기」가 전부라, 활동이 1~5% 면 매 스텝 수십만~백만 번 더하기. 맥 GPU 로 밀리초 단위 스텝이 현실적이다(F1: 2 ms 스텝을 1.3~1.7 ms 에).
- 학습을 붙이면(ConnecTorch) 역전파가 `연결 수 × 배치 × 스텝` 만큼 메모리를 먹는다 — 배치 4·8 스텝에 7.8 GiB, 배치 32·16 스텝이면 104 GiB. 맥 32GB 로는 작은 배치만.
