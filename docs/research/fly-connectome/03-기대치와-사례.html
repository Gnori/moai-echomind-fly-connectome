03. 기대치와 사례

화제가 된 데모들이 실제로 무엇을 보였는지 — 각 저장소가 스스로 밝힌 결과 기준.

되는 것

  • 뉴런을 켜고 꺼서 신호가 어디로 퍼지는지 예측
  • 회로 분석 — 경로 찾기, 암수 차이 비교, 세포 종류별 연결
  • 스파이킹 신경망·신경형 칩 실험의 실제 배선 재료
  • 보여 주기 좋은 데모

안 되는 것

  • 언어 모델처럼 「지능」을 앱에 가져다 붙이기
  • 배선도만으로 행동을 재현하기 — 시냅스 세기는 시냅스 수로 근사하고, 흥분·억제는 예측값이며, 신경조절물질과 학습 규칙은 들어 있지 않다
  • 시뮬레이션 결과를 「초파리가 실제로 그렇게 한다」로 읽기 — 방정식은 프로젝트마다의 가정

사례 — 입출력 대응은 사람이, 학습은 출력층만

사례 한 것 저장소가 밝힌 결과
DOOMFLY 게임 화면을 광수용체 입력(R1–R6 밝기 3,335 + R8 색 811)으로 넣고, 16.67만 뉴런·2,558만 연결로 전파. DNp20 좌우 차를 회전, DNpe017 을 이동·발사에 대응. 손상 시 도파민 뉴런(PPL101)에 200ms 혐오 입력, KC→MBON11 연결 4,184개에 가소성 규칙 「학습된 생존을 보이지 못했다」고 명시. v6 후보가 시각·조건화·생존 검증 관문을 통과 못 함. 음성 결과와 대조군을 함께 공개
Stonkfly 시세 차트를 입력으로 넣은 모의 거래 수익이 나는 학습은 입증되지 않았다고 명시
Fly Dino 80뉴런 회로 + 243개 매개변수 출력층만 학습(교차 엔트로피 방법) 회로 자체는 고정. 회로 절단 대조군 포함
FLYT3 같은 회로로 위성 영상 분류 초파리 회로 60.8%, 같은 입력을 쓴 평범한 신경망(MLP) 85.7% — 스스로 불리한 대조 결과를 공개
Fly Chess · FlyPong 등 회로 일부만 골라 쓴 게임 「circuit subset」 — 부분 회로

새로 나온 사례(F1 모나코 · Fly.exe 열두 마리 · 브라우저 전체 중추신경계 · FLYCNS 수치 시험 · ConnecTorch · 마인크래프트 · Strandbeest 로봇)와 각각 어떻게 이었는지는 10 적용 사례 상세에 있다.

데모를 볼 때 확인할 세 가지

  1. 배선도를 통째로 썼나, 일부 회로만 골랐나
  2. 감각 입력과 운동 출력의 대응을 누가 정했나
  3. 학습이 있었다면 무엇이 학습됐나 — 배선인가, 출력층인가

셋을 밝히지 않은 데모는 「초파리 뇌가 게임을 했다」는 말로 읽히기 쉽다.

DOOMFLY 실행 요건 (참고)

Python 3.11, C++ 컴파일러, 수 GB 메모리. MaleCNS 입력 파일 3개를 doom/datasets.json 등록명대로 받고 source.lock.json 의 SHA-256 으로 검증한 뒤 doom.connectome → prepare → audit_data → build_kernel → server 순서. 「소프트웨어 시험 통과는 생물학적 타당성의 증거가 아니다」라고 README 가 적어 두었다.
