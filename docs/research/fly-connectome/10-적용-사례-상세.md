# 10. 적용 사례 상세 — 어떻게 이었고, 무엇을 얻었나

> 2026-09-16 기준. 각 저장소 README·문서 원문에서 옮겼다. 9월 3일 공개 뒤 하루에도 몇 개씩 새 저장소가 생기므로, 이 목록은 그날의 단면이다. [03](03-기대치와-사례.md)이 「기대치」라면 이 문서는 「방법」이다.

## 공통 구조 — 다섯 칸

모든 사례가 같은 다섯 칸을 채운다. 사례를 볼 때 이 칸이 비어 있으면 무엇을 한 건지 알 수 없다.

| 칸 | 물음 |
|---|---|
| **입력** | 세계의 무엇을, 어느 뉴런에, 어떤 발화율로 |
| **회로** | 어느 데이터, 뉴런 몇 개, 어떤 모델, 부호를 어떻게 |
| **출력** | 어느 뉴런을 읽어, 무엇으로 바꾸나 |
| **학습** | 무엇이 학습됐나 — 배선인가, 입출력 대응인가, 둘레 부품인가 |
| **결과** | 스스로 밝힌 성적과 한계 |

## 사례별

### Eon Systems — 몸 붙인 초파리 (2026-03, FlyWire)

| 칸 | 내용 |
|---|---|
| 입력 | **시각**: flyvis(연결 지도 제약 시각 모델, 64 종류·수만 뉴런)의 출력을 LIF 의 해당 뉴런에 주입. **미각**: 다리·주둥이가 설탕·쓴맛에 닿으면 미각 수용 뉴런 켬. **접촉**: 「가상 먼지」가 더듬이 기계감각(존스턴 기관) 켬 |
| 회로 | FlyWire 약 14만 뉴런 · 5천만 시냅스, Shiu 모델 LIF, 신경전달물질 예측으로 부호 |
| 출력 | **하강 뉴런 7 개 남짓만** 읽음 — DNa01·DNa02(방향), oDN1(전진 속도), 더듬이 하강뉴런(다듬기), MN9(먹기). 이 활동이 **모방학습된 제어기**를 구동 → NeuroMechFly v2(관절 87 개, MuJoCo). 뇌·몸 동기 15 ms |
| 학습 | 배선 고정. 뇌·몸 대응은 **손으로 정함**. 걷기 제어기는 기존 NeuroMechFly 제어기를 초파리 걷기 영상으로 모방학습 |
| 결과 | 다듬기·먹기·냄새 찾기 행동. 시각 입력은 「장식에 가깝고 행동에 거의 영향 없음」이라고 스스로 적음. 내부 상태·가소성·학습·신경조절은 「대부분 빠짐」. 「연구 플랫폼으로 이해해야 한다」 |

**우리 설계와의 관계**: [06](06-설계-초파리-회로에-Qwen-뇌.md) 의 (나) 갈래 — 하강 뉴런 몇 개 → 행동 프리미티브 — 를 이미 한 번 간 사례다.

### FlyGM — 커넥톰 구조의 그래프 신경망으로 걷기·날기 학습 (2026-02 arXiv, FlyWire)

| 칸 | 내용 |
|---|---|
| 입력 | 몸 시뮬레이터(flybody 계열)의 관절·접촉 관측 → **들어오는 뉴런 19,262 개** 노드에 |
| 회로 | FlyWire 139,246 뉴런의 배선을 **그래프 신경망의 구조**로 고정. 부호 있는 가중치. 뉴런을 들어옴 19,262 / 안 118,496 / 나감 1,488 으로 나눔 |
| 출력 | 나가는 뉴런 1,488 개 → 관절 명령 |
| 학습 | 배선은 고정, **노드 임베딩·전달 함수를 학습**. 전문가 궤적 모방학습 → PPO 강화학습 |
| 결과 | 걷기·돌기·날기에서 안정. 그래프가 아닌 기준 모델보다 **표본 효율이 좋다**고 보고 |

**뜻**: 배선을 「학습의 뼈대」로 쓴 사례. 연속 값 모델이라 스파이크·시간은 버렸고, 초파리 배선이 무작위 그래프보다 나은지는 대조군을 봐야 한다.

### F1 모나코 — 초파리 뇌가 F1 차를 운전 (2026-09-14, MaleCNS)

| 칸 | 내용 |
|---|---|
| 입력 | **라이다 9 줄**(180°, 150 m) → 거리와 「다가옴(looming)」 → 포아송 발화로 **시각 투사 뉴런 9,201 개**에. 거리는 「직선 도로 가운데서 보일 거리에 대한 상대값」의 로그로 부호화 — 절대 거리로 넣었을 때는 4 m 와 7 m 차이가 하강 뉴런에서 안 보였다(d′ 0.6 → 상대값으로 33) |
| 회로 | MaleCNS 166,700 뉴런, 시냅스 5 개 이상 연결 624만, Shiu 매개변수, 신경전달물질로 부호, 스텝 2 ms. 맥 GPU Metal 커널 |
| 출력 | **하강 뉴런 1,314 + 신경삭 운동뉴런 815** 의 발화율 → 저역 통과 → 고정 무작위 사영 64 채널 → 조향·가감속 두 값 |
| 학습 | 배선 고정. **매개변수 144 개**만 진화 전략(ES)으로: 시선 방향별 게인 9, 다가옴 게인, 배경 발화, 속도 감각 게인, 읽기 방향 64×2, 읽기 게인·편향. 먼저 라이다 교사가 운전하는 것을 보며 능형 회귀로 읽기를 맞추고(DAgger 3 회), 그 뒤 ES |
| 결과 | 모나코 한 바퀴(3.29 km)를 **어느 출발점에서든 충돌 없이** 돎. 보상 해킹 탐지기·102 개 시험 포함. 「배선은 절대 다시 잇지 않는다」 |

**뜻**: 우리 설계의 **입구(감각 → 시각 투사 뉴런)와 출구(하강 뉴런 → 명령)** 를 그대로 구현한 가장 가까운 사례. 두 가지를 배운다 — ① 감각은 **기대값에 대한 차이**로 부호화해야 회로가 구분한다(순응과 같은 원리), ② 출력 읽기는 **고정 무작위 사영 + 작은 학습**으로 충분하다.

### Fly.exe — 열두 마리, 한 GPU, 닫힌 고리 (2026-09-12, MaleCNS)

| 칸 | 내용 |
|---|---|
| 입력 | **해석적 시각**: 물체의 위치·반지름에서 방위와 각 크기를 계산해 라미나 뉴런에 — 카메라 픽셀 없음. 광수용체 출력 66,533 개는 부호 미정 정책으로 0 이라 **한 단 아래에서** 빛을 넣음 |
| 회로 | MaleCNS **Traced 165,122 뉴런 · 연결 25,563,197 개 전부**. 부호 미정은 0(추측 안 함). GeNN/CUDA, 열두 마리가 연결 배열 하나를 공유하고 상태만 따로 |
| 출력 | **하강 뉴런 집단 발화율 두 개**만 → NeuroMechFly 몸(qpos 133, 구동 42)의 걷기 패턴 생성기. 15 ms 동기 |
| 학습 | 없음. 대응은 선언된 두 숫자 |
| 결과 | 12 마리 모두 걷기 시작·물체 앞에서 멈춤(자극 없는 대조군은 0 마리). **「멈춘 게 아니라 물체에 막힌 것」**, 「사회 행동 아님」, 「먹이 찾기 아님」을 영상 위에 글로 박음. 자체 검증 등급 V0(구조만) |

**뜻**: 정직성의 본보기. 무엇이 회로 덕이고 무엇이 규칙인지 목록으로 적는다.

### Lulzx fly-brain — 브라우저 안의 전체 중추신경계 (2026-09-10, MaleCNS)

| 칸 | 내용 |
|---|---|
| 입력 | flyvis 시각엽 런타임 + 감각 인코더 |
| 회로 | 165,122 뉴런 LIF 를 **WebAssembly·WebGPU** 로 브라우저에서. 원본 10 GB → 브라우저용 27 MB 로 전처리 |
| 출력 | MuJoCo(웹) 몸 |
| 학습 | 걷기 걸음새 맞춤, 보정 |
| 결과 | 「배선이 스스로 내는 행동」과 「바깥에서 코드로 더한 행동」을 **두 목록으로 갈라 문서화**. 전체 문서 30 편과 교과서 형식 논고 |

### FLYCNS — 회로 셋을 수치 기준으로 시험 (2026-09, MaleCNS)

| 칸 | 내용 |
|---|---|
| 입력 | 도망: 다가옴에 반응하는 LC 종류 9 개를 **실험 논문(Turner 등 2022)에서 측정한 세기**로. 청각: 존스턴 기관 A/B 를 150 Hz. 먹기: 미각 감각 뉴런을 해부학 소분류로 |
| 회로 | MaleCNS 166,700, Shiu 매개변수 그대로, **맞춘 게인 없음** |
| 출력 | DNp01·다리 운동뉴런 TTMn·PSI / 주둥이 운동뉴런 |
| 학습 | 없음 |
| 결과 | 16/16 기준 채점. 도망은 재현(GF 1~2 회 발화 · 10~60 ms 지연 · 무작위 배선 대조군은 침묵), 청각은 **GF 문턱 아래 탈분극**으로 재현(생체 기록이 발화가 아니다 — 처음 적은 「1~2 회 발화」는 두 결과를 섞은 것). **먹기는 실패하고 이유를 측정** — 억제를 푸는 경로라 침묵 상태 LIF 로는 안 됨([09 의 4절](09-LIF-모델.md#4-이-모델이-맞은-것과-못-맞춘-것)) |

**뜻**: 「무엇이 안 되는지」를 숫자로 낸 유일한 사례. 우리 설계의 검산 절차(알려진 반사 3 개)와 같은 발상이고, 먹기 회로는 그 검산에서 **빼거나 배경 발화를 넣어야** 한다는 것을 알려 준다.

### ConnecTorch — 커넥톰을 PyTorch 모듈로 (2026-09-11, MaleCNS)

| 칸 | 내용 |
|---|---|
| 입력·출력 | 사용자가 `where(cell_class="visual")` 같은 식으로 입력·출력 뉴런 집합을 고름 |
| 회로 | Traced 164,587 노드 · 연결 25,563,197 → `torch.nn.Module`. 연속 값 재귀망(tanh, 누수). 연결마다 가중치 학습 가능, **배선은 못 만듦**. Dale 옵션(한 뉴런 한 부호) |
| 학습 | 연결 가중치 2,556만 개 전부 |
| 결과 | 엔비디아 GB10 에서 로드 9.5 s, 배치 4·8 스텝 순전파+역전파 1.1 s·7.8 GiB. 밀집 행렬은 100.9 GiB 라 거부. 자유 가중치로 학습하면 100 개 중 93 개 뉴런이 흥분과 억제를 동시에 내게 됨 — Dale 옵션이 그것을 막음 |

**뜻**: 「배선 위에서 학습」의 도구. [07](07-지능은-누구-것인가.md) 의 질문 — 배운 것이 배선 덕인지 — 를 시험할 재료이기도 하다.

## 사례를 가로지르는 관찰

| 관찰 | 근거 |
|---|---|
| **입구는 거의 다 시각 투사 뉴런이나 라미나**다. 광수용체에 직접 넣은 사례는 DOOMFLY 정도 | 광수용체 부호(히스타민) 처리와 낱눈 대응이 번거롭기 때문. [08](08-데이터-실측.md)의 `consensus_nt`·`assignedOlHex` 로 풀 수 있다 |
| **출구는 하강 뉴런**으로 수렴한다 — 7 개(Eon), 2 집단(Fly.exe), 1,314 전체(F1) | 우리 설계 4장과 같음 |
| **학습되는 것은 언제나 둘레**다 — 읽기 사영(F1 144 개), 어댑터(FLM 27.8만), 제어기(Eon), 임베딩(FlyGM). 배선을 학습한 것은 ConnecTorch 만 | 배선 고정이 「초파리」라는 말의 조건 |
| **정직한 사례는 대조군을 낸다** — 무작위 배선(FLYCNS), 자극 없음(Fly.exe), 셔플 가중치(NeuroCraft 예정) | 우리 설계 9장의 대조군 셋과 같음 |
| **감각 부호화가 성패를 가른다** — F1 의 절대 거리 → 상대 거리 전환(d′ 0.6 → 33) | 설계 2.2 의 순응·로그 압축이 같은 원리 |
| **침묵 LIF 가 못 하는 회로가 있다** — 먹기(FLYCNS) | 설계 2.4 게인만으로는 안 되고 종류별 배경 발화가 필요 |
| **표제와 원문이 다르다** — Strandbeest | 저장소 README 를 읽기 전에는 사례로 세지 않는다 |
