## 세 줄 요약

- **커넥톰은 「누가 누구와 이어졌나」의 지도**다. 시냅스 개수가 세기의 근사이고, 발화 방정식·학습 규칙은 데이터에 없다.
- **언어 모델과 이으면 판단은 언어 모델의 것**이다. 초파리 회로는 감각 전처리와 타고난 반사만 낸다. 「초파리 뇌」라 부르려면 섞은 그래프 대조군을 이겨야 한다.
- **초파리의 지능이 보고 싶으면 방향이 반대**다 — 언어 모델을 빼고, 빠져 있는 학습 규칙을 채우는 실험이다.

## 이 프로젝트(EchoMind)와의 관계

EchoMind 는 감정·기억·자율의지를 가진 AI 캐릭터를 만든다. 초파리 커넥톰은 **「고정 배선 + 학습 규칙 없음」이 어디까지 행동을 내는가**를 보여 주는 대조 사례이고,
[05](05-LLM-연동-방식.md)·[07](07-지능은-누구-것인가.md) 의 「판정은 시뮬레이터가, 말은 언어 모델이」 원칙은 EchoMind 의 「계산값은 코드가 정본, 에이전트는 덮지 못한다」 원칙과 같다.
제품 코드와 직접 이어지는 요구사항은 아직 없다.
